`docs/design.md`의 결정을 숫자로 옮긴 문서. 모든 값은 플레이 테스트로 조정한다. 구현에서는 이 값을 데이터 파일로 옮긴다.
최종 수정 2026-11-03

단위: 거리 px(화면 960×540, 전장 길이 2400), 시간 초, 속도 px/초, 공격 간격 = 공격 사이 시간(초).

## 1. 전투 공통

| 항목 | 값 |
|------|-----|
| 전장 길이 | 2400 (서낭당 x=80, 원귀의 성 x=2320) |
| 서낭당 체력 | 1000 |
| 원귀의 성 체력 | 1200 + 150 × 스테이지 번호(0~24) → 1200 ~ 4800 |
| 아군 유닛 최대 수 | 30 (넘으면 소환 불가) |
| 적 유닛 최대 수 | 60 (보스 제외). 상한에 닿으면 웨이브의 남은 적은 버리지 않고 대기했다가 자리가 나면 나온다. 보스 졸개 소환은 상한을 넘는 만큼 생략 |
| 위협 단계 | 전투 시작 후 30초마다 +1 (1부터). 영웅 부활 시간에만 영향 |
| 데미지 최소값 | 1 |
| 양쪽 기지 동시 파괴 | 같은 순간에 서낭당과 원귀의 성이 함께 부서지면 **승리** |
| 결과 화면 입력 | 결과가 나온 뒤 1초 동안 입력 무시. 재시작은 R 키 또는 "다시 하기" 버튼으로만 (빈 곳 클릭으로는 재시작하지 않음) |

### 피해 계산 순서
```
최종 피해 = 기본 공격력
          × (1 + 공격력 버프 합)          // 축원, 삼족오 오라, 연계 등
          × 적 특성 배율                  // 아래 표
          × 보스 상성 배율                // 보스만: 약점 2, 저항 0.2
          × (1 + 받는 피해 증가 − 받는 피해 감소)   // 방어 파괴, 해태 보호 등
```
- 보스 상성: 약점과 저항이 동시에 해당하면 곱한다 (2 × 0.2 = 0.4). 약점이 여러 개 해당해도 ×2는 한 번만.
- 받는 피해 감소는 최대 70%.

### 적 특성 배율
| 특성 | 효과 |
|------|------|
| 무리 | 마법(범위) 피해 ×1.5 |
| 영체 | 근접 피해 ×0.5, 불 피해 ×1.5 |
| 갑옷 | 원거리·마법 피해 ×0.5. 방어 파괴 3중첩 이상이면 갑옷 무효 |
| 비행 | 근접 공격 불가(대상이 안 됨). 바람 피해 ×1.5 |

### 상태 효과
| 효과 | 규칙 |
|------|------|
| 화상 | 초당 피해, 지속 3초. 다시 걸리면 시간만 갱신(중첩 안 함, 연계로 2중첩 가능). 불 태그 유닛의 공격은 모두 화상을 건다 |
| 감속 | 이동 속도 감소. 여러 개면 가장 강한 것만 |
| 넉백 | 뒤로 밀림. 보스는 무효 |
| 기절·붙잡기 | 이동·공격 정지. 보스는 0.5초 경직으로 대체 |
| 방어 파괴 | 중첩당 받는 피해 +10%, 최대 5중첩, 지속 6초(맞을 때마다 갱신) |
| 버프 해제 | 대상의 버프와 오라 효과를 지정 시간 동안 끈다 |
| 회복 차단 | 지정 시간 동안 회복 불가 |

## 7. 스테이지

### 구성
- 스테이지 번호 0~24. 장 c(1~5), 장 안 순서 s(1~5). s = 5는 보스 스테이지.
- 웨이브: 첫 웨이브 5초, 이후 20초 간격.
- 일반 스테이지는 9웨이브. 9번째 웨이브에 정예가 **한 번만** 나온다. 이후에도 마지막 웨이브 구성(정예 제외)으로 20초마다 계속 나온다.
- 보스 스테이지는 웨이브가 계속 나오며, 60초에 보스가 등장한다.
- 웨이브 예산(점수) = 6 + 2 × 웨이브 순서(0부터) + 3 × (c − 1) + (s − 1). 예산 안에서 그 장의 적 목록에서 무작위로 고르고, 0.8초 간격으로 내보낸다. 장 테마 적은 뽑힐 확률 2배.

### 장별 적 목록
| 장 | 등장 적 (괄호는 처음 나오는 스테이지) | 테마 적 (확률 2배) |
|----|---------------------------------------|---------------------|
| 1 | 달걀귀신, 물귀신 투척병, 처녀귀신(1-3), 그슨대(1-4) | 처녀귀신 (영체 → 불 유리, 보스 대비) |
| 2 | 1장 + 장승 망령, 어둑시니(2-3) | 장승 망령 |
| 3 | 2장 + 손각시, 강철이(3-3) | 강철이 |
| 4 | 3장 + 저승사자, 두억시니(4-2) | 어둑시니 |
| 5 | 전부 | 저승사자 |

### 별 조건

|----|------|
| ★1 | 클리어 |
| ★2 | 서낭당 체력 50% 이상 |

## 8. 판 밖 재화

| 항목 | 값 |
|------|-----|
| 신명 | 별 1개 = 1 (처음 얻은 별만, 최대 75) |
| 엽전 (클리어마다) | 30 + 10 × (c − 1) + 별 1개당 10. 보스 스테이지 ×1.5. 반복 클리어도 동일 |
| 신명 구매 | n번째 구매 가격 = 100 + 50 × (n − 1) 엽전. 최대 25회 |
| 최대 신명 | 75 + 25 = 100 |
| 업그레이드 전체 비용 | 약 198 → 최대로 모아도 절반 정도만 찍을 수 있음 |

## 9. 업그레이드 트리

공통 규칙:
- 무당·연계·살림 트리: 그 노드보다 낮은 단들에 쓴 신명이 5점이면 2단, 12점이면 3단, 20점이면 4단이 열린다.
- 요괴 트리: 단 기준 없음. 같은 유닛의 ① → ② → ③ 순서만 지키면 된다 (유닛 하나 각성까지 10점).
- 초기화는 무료이며 전투 중이 아니면 언제든 가능하다.

### 무당 (영웅 강화형, 합계 31)
| 단 | 항목 | 효과 | 비용 |

### 요괴 (특정 유닛 강화형, 유닛당 10 × 10종 = 합계 100)
유닛마다 ① 기본(2점) → ② 핵심(3점) → ③ 각성(5점) 순서로 찍는다. 트리 단 기준은 적용하지 않는다.
- ① 기본: 모든 유닛 공통으로 체력·공격력 +25%.

| 유닛 | ② 핵심 | ③ 각성 |
|------|--------|--------|
| 방망이병 | 비용 −20%, 쿨타임 −30% | 뚝딱: 적을 처치하면 10% 확률로 방망이병 1마리 추가 소환 |
| 외다리 도깨비 | 돌격 피해 ×3 → ×4 | 돌격이 지나가는 길의 적 모두에게 피해 |
| 씨름 도깨비 | 메치기 3타 → 2타마다 | 메친 적이 뒤의 적과 부딪혀 둘 다 피해 40 |
| 여우불 사수 | 화상 초당 4 → 7 | 화살 2갈래 (대상 2명) |
| 구미호 | 범위 +40% | 불꽃 3연발 |
| 불가사리 | 방어 파괴 최대 5 → 8중첩 | 갑옷 적을 처치하면 체력 30% 회복, 그 판 동안 공격력 +5%(중첩) |
| 해태 | 붙잡기 2 → 3.5초 | 정의의 수호: 반경 120 아군 받는 피해 −20% |
| 삼족오 | 오라 +20% → +35% | 태양 불꽃: 10초마다 화면 안 적 전체에 화상 |
| 까치 떼 | 소환 시 2무리 | 비행 적에게 ×2 → ×3, 맞은 비행 적 0.3초 경직 |
| 영등 바람 | 오라 +15% → +25% | 빗나감 25% → 50%, 빗나간 투사체는 적에게 되돌아감 |
