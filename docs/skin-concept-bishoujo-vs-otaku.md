# 별도 테마팩 기획: 미소녀 VS 오타쿠

작성일: 2026-11-04 · 상태: 콘셉트 기획 초안 · 범위: 문서 작성

상세 제작 문서: [28종 개별 명세·이미지 생성 프롬프트 목록](art/bishoujo-vs-otaku/README.md) · [공통 이미지 생성 콘셉트](art/bishoujo-vs-otaku/image-generation-concept.md)

## 1. 핵심 콘셉트

**취향에 맞는 미소녀 주인공 3종 중 하나를 골라, 오타쿠 군단과 불쾌한 관계를 강요하는 적들을 밀어내는 풀 일러스트 라인 디펜스.**

현재의 「꼬마 무당 대소동」과 세계관·캐릭터·화풍이 다른 별도 스킨 콘셉트다. 영웅의 옷만 교체하는 수준을 넘어 주인공, 아군, 적, 보스, 배경, 기지, UI, 효과와 대사를 함께 바꾸는 **테마팩**으로 설계한다. 가제는 「미소녀 VS 오타쿠」다.

- 플레이 감정: 마음에 드는 캐릭터를 고르고, 몰려오는 성가신 적을 시원하게 물리치는 재미.
- 분위기: 현대 서브컬처 코미디와 화려한 액션. 주인공은 매력적으로, 적은 행동과 소품이 한눈에 읽히게 그린다.
- 적의 소재: 오타쿠 군단, 음침하게 접근하는 아저씨, 집착하는 멘헤라 남친, 훈수와 통제를 강요하는 인물 등.
- 적의 불쾌함은 무단 촬영, 사생활 간섭, 연락 강요, 거절 무시 같은 행동으로 보여 준다. 주인공은 이를 제압하고 자기 공간을 되찾는다.
- 그래픽: SD 대신 정상적인 신체 비율의 애니메이션풍 전신 일러스트. 전투 중에도 이 비율을 사용한다.
- 캐릭터 감상: 선택 화면의 큰 전신 일러스트, 전투 중 움직이는 본체, 스킬 상반신 컷인, 승리 포즈를 연결한다.

## 3. 주인공 3종과 선택 방식

### 공통 규칙

- 세 주인공은 모두 성인 여성이고 한 전투에 한 명을 선택한다.
- 타입별 지정 무기는 **츤데레 AK / 상냥한 형 M4 / 누님계 바렛**이다. 전신 원화·선택 카드·동작 컷·컷인에서 같은 총기를 유지한다.
- 세 타입 모두 원거리 발사로 설계한다. 현재 영웅의 근접 공격을 원거리 타격·투사체 이벤트로 확장하는 구현 작업이 필요하다.
- 처음에는 공통 성능 기준을 두되 사거리·탄속·공격 간격·타격 시점을 별도 수치 설계에서 확정한다. 이번 문서는 코드 구현이나 밸런스 변경 완료를 뜻하지 않는다.
- AK·M4·바렛의 외형 차이는 총열·몸체·탄창·스코프·지지 자세와 반동 연기로 읽히게 한다. 무기 이름만으로 재장전·탄약·연사·관통 같은 새 규칙을 추가하지 않는다.
- 테마 선택 → 주인공 미리보기 → 선택 확정 → 스테이지·빌드 선택 → 전투 순서다. 처음부터 세 타입을 모두 선택할 수 있다.

| 보조 모션 | 세 주인공 중 가슴의 후행이 가장 뚜렷하다. 몸통이 먼저 멈춘 뒤 무게감 있게 짧게 감쇠하며, 재킷 지지력과 팔 간격을 지킨다. 긴 머리와 재킷 끝도 별도 후행을 둔다. |

세 타입은 체형뿐 아니라 얼굴·눈매·의상·총기·말투·반동·보조 모션에서 구분한다.

## 4. 적 군단

일반 적은 기존 10종의 역할에 대응시키며, 총기·곤봉·방패·해머 등의 무기 계열로 구성한다. 적의 행동과 소품으로 무리·급습·성장·통제·기지 압박을 읽히게 한다.

기존 불 계열은 스포트라이트, 화상은 잔광 지속 피해로 표시한다. 기존 공격 유형·상태 효과를 유지하는 적과 아군은 외형만으로 새 사거리·추가 피해·반사·무적 규칙을 만들지 않는다. 적은 피격 후 당황하고 패배 시 장비를 챙겨 후퇴하는 코미디 톤이다.

## 6. 풀 일러스트 전투와 화면 구성

**풀 일러스트는 선택 화면과 컷인에만 쓰는 것이 아니라, 전장 본체에도 적용한다.** 주인공·일반 적·인간형 아군은 정상 비율의 전신 일러스트가 실제로 이동하고 공격한다.

- 화풍: 선명한 애니메이션풍 채색, 얼굴과 의상 디테일이 있는 상업 일러스트 느낌. 머리를 크게 줄인 SD 비율은 사용하지 않는다.
- 전투 본체: 기본 스킨과 같은 동작별 낱장 PNG를 필수로 준비한다. 모든 스킨의 공통 본체는 19컷이고 스킬·바스트·비행·착지 등은 지정된 추가 컷을 만든다. 리깅은 이 프레임 제작을 돕는 선택 방식이다.
- 기존 문서의 일반 유닛 약 20~52px 표시는 이번 화풍의 목표와 맞지 않는다. 이 테마는 카메라 배율·전장 여백·UI를 함께 조정하는 별도 화면 검증이 필요하다.
- 960×540 화면의 시안 목표는 주인공 높이 약 170~210px, 인간형 일반 유닛 110~150px, 보스 230~300px다. 확정값이 아니라 가독성 검증용 범위다.
- 체형·무기·옷자락이 커져도 전투 판정은 기존 몸체 기준으로 유지한다. 발밑 위치 표시와 목표 강조로 실제 위치를 읽게 한다.
- 몸체는 동일 비율로 확대하고, 공격 시 앞으로 뻗는 팔·무기의 여백을 확보한다. 발을 화면 하단 UI에 가리지 않는다.
- 아군과 적이 겹치면 지면 기준 정렬, 외곽선, 선택 대상 강조, 가려진 개체의 옅은 표시를 사용한다. 시각적 인원 제한을 위해 실제 전투 개체를 삭제하지 않는다.
- 주인공에 가까운 전투 시점과 전체 전선을 보는 시점을 검토한다. 기본 시야에서 다수 교전이 읽히지 않으면 표시 크기와 카메라를 함께 조정한다.
- 스킬 컷인은 화면 한쪽의 짧은 상반신 일러스트로 제안한다. 공격 경고와 조작 버튼을 가리지 않고 전투 시간을 임의로 멈추지 않는다.
- 선택 화면에는 큰 전신과 상반신 확대 미리보기를 제공하고, 승리 화면에는 타입별 대표 포즈를 사용한다.

## 7. 바스트 모션과 캐릭터 애니메이션

여기서 바스트 모션은 **상반신 일러스트의 호흡·표정·자세 변화와, 가슴의 물리적 후행 움직임**을 함께 뜻한다. 전신 전투 본체에도 같은 움직임을 적용한다.

### 움직임의 원칙

- 몸통의 이동·회전이 먼저 일어나고, 가슴·머리카락·옷자락이 약간 늦게 따라와 감쇠한다.
- 가슴은 좌우 파츠와 의상의 연결을 고려해 움직인다. 상반신 전체를 고무처럼 늘였다 줄이는 방식은 피한다.
- 츤데레는 작은 반응, 상냥한 형은 완만한 반응, 누님계는 무게감과 후행이 뚜렷한 반응으로 구분한다.
- 체형마다 진폭·지연·감쇠·좌우 비대칭의 허용 범위를 따로 둔다. 같은 설정을 단순 확대해 쓰지 않는다.
- 의상의 지지력에 맞춰 움직이고, 가슴과 팔·옷깃·재킷이 서로 뚫고 지나가지 않도록 제한한다.
- 대기는 작은 호흡, 걷기는 디딤에 따른 움직임, 공격은 몸통 회전 뒤의 반동, 정지는 짧은 잔여 흔들림으로 구분한다.
- 연속 피격에 흔들림이 계속 누적되지 않도록 최대 진폭을 둔다. 화면 흔들림과 캐릭터의 후행 움직임은 별도 제어한다.
- 옵션에 `보조 모션 강도: 끄기 / 약하게 / 기본`을 제안한다. 끄기에서도 이동·공격·표정은 유지한다.

### 필요한 동작

| 동작 | 본체 연기 | 보조 모션 |
| --- | --- | --- |
| 대기 | 호흡, 눈깜빡임, 작은 체중 이동 | 가슴·머리·소매의 작은 움직임 |
| 이동 | 실제 발 디딤, 상체 균형, 방향 전환 | 머리·의상·가슴의 후행과 정지 감쇠 |
| 기본 공격 | 준비, 타격, 회수 | 팔과 몸통 회전에 따른 반동 |
| 스킬 3종 | 밀어내기 / 지원 / 광역 필살의 타입별 포즈 | 큰 동작 뒤 짧은 감쇠, 컷인 표정 연동 |
| 피격 | 짧은 움찔과 표정 변화 | 제한된 반동, 연타 시 진폭 제한 |
| 등장·부활 | 전장 진입과 준비 자세 | 착지 또는 자세 전환 뒤 안정화 |
| 퇴장 | 기지로 물러나거나 연출 후 사라짐 | 퇴장 완료 시 모션 종료 |
| 승리 | 타입별 자신감·미소·쑥스러움 | 포즈 정착 뒤 작은 호흡 |

공격의 피해 판정은 전투 이벤트에 맞춘다. 원화의 준비 동작 때문에 기존 공격을 늦추거나, 모션 종료를 기다리느라 다음 행동을 막지 않는다. 일시정지 때 보조 모션도 멈추고, 부활·장면 재진입 시 남은 속도와 흔들림을 초기화한다.

## 8. 에셋 제작 규격 초안

- 주인공 기준 원화: 투명 배경 1536×2048px 전신. 세 타입의 기준 발 위치·캔버스 규격은 통일한다.
- 일반 인간형: 1024×1536px, 보스: 1536×2048px 이상을 시작점으로 검토한다. 실제 게임용 출력은 표시 크기와 메모리에 맞춰 축소·아틀라스화한다.
- 원본은 레이어가 있는 PSD 등으로 보관하고, 실행용은 PNG 파츠·아틀라스와 리깅 메타데이터로 내보낸다.
- 기본 분리: 얼굴·눈·눈썹·입, 앞머리·뒷머리, 목·몸통·골반, 좌우 가슴과 대응 의상, 상완·전완·손, 허벅지·종아리·발, 무기, 재킷·소매·옷자락.
- 파츠 경계는 움직여도 빈틈이 보이지 않도록 겹쳐 그린다. 기본 포즈에 가려진 영역도 필요한 범위까지 복원한다.
- 상반신 확대는 전신 원본의 얼굴·가슴 디테일이 충분하면 재사용한다. 부족한 경우에만 별도 컷인 원화를 만든다.
- 오른쪽을 보는 원본을 기준으로 하며, 반전 시 읽어야 하는 글자는 별도 표시한다. 발 기준점과 효과 부착점을 기록한다.
- 가슴 모션은 컷별 몸통 선행·가슴과 의상 후행·감쇠 위상을 일관되게 그린다. 여성 주인공·아군은 전신 바스트 대기 4컷을 추가하며 리깅·변형은 제작 보조로 사용할 수 있다.
- 특정 외부 리깅 도구는 아직 확정하지 않는다. 현재 Phaser 표시 구조와 연결 가능한 방식으로 대표 캐릭터를 먼저 검증한다.

에셋 경로 제안:

```text
public/assets/themes/bishoujo-vs-otaku/
  heroes/tsundere/<skinId>/
  heroes/gentle/<skinId>/
  heroes/oneesan/<skinId>/
  allies/<외형ID>/<skinId>/
  enemies/<외형ID>/<skinId>/
  bosses/<외형ID>/<skinId>/
  backgrounds/
  bases/
  ui/
  effects/
```

스킨마다 대기 2 + 이동 4 + 공격 4 + 피격 2 + 등장·부활 3 + 퇴장 4 = 공통 본체 19컷을 납품한다. 주인공은 스킬 4·3·4컷, 승리 3컷, 바스트 대기 4컷을 추가한다. 상반신 컷인·표정·미리보기·아이콘·효과는 별도다. 각 캐릭터 MD의 파일별 표가 최종 제작 목록이다.

## 9. 기존 시스템과 연결할 설계

참조: [게임 설계](design.md), [스킨·애니메이션 설계](skins-and-animation.md), [기존 민담 아트 가이드](art/default/README.md).

- 기존 개별 스킨 위에 테마 선택 계층을 제안한다. 테마는 캐릭터 외형 매핑, 표시 용어, 배경, UI와 효과 묶음을 참조한다.
- 예시 선택값은 `themeId: bishoujo-vs-otaku`, `heroAppearanceId: tsundere | gentle | oneesan`이다. 현재 코드에 구현된 필드라는 뜻은 아니다.
- 새 주인공 세 타입은 꼬마 무당의 인물 설정을 공유하지 않는다. 전투 영웅의 공통 규칙을 재사용하는 별도 외형·인물로 등록한다.
- 테마의 기본 외형 매핑을 먼저 적용하고, 그 테마 안에서 허용한 개별 스킨 선택을 적용한다. 미선택 적에 기존 귀신 이미지가 자동으로 섞이지 않게 한다.
- 저장된 테마·주인공 선택은 전투 시작 시 고정한다. 테마 전환 후에도 원래 테마의 개별 스킨 선택은 보관한다.
- 진행도·재화·빌드는 공통으로 유지하는 방향이다. 기존 저장에 새 선택값이 없으면 기존 무당 테마로 시작한다.
- 새 테마의 이미지가 없으면 같은 테마의 실루엣 임시 표시와 이름을 사용한다. 누락 파일 때문에 빈 전장을 만들지 않는다.
- 전투 수치와 충돌은 기존 데이터, 표시 이름과 외형·모션은 테마 데이터에서 관리한다. 그림 크기로 판정 크기를 계산하지 않는다.
- 기존 26종용 작은 카툰 원화 규격을 이 테마에 그대로 강제하지 않는다. 선택·저장·이벤트 연결 원칙을 공유하고, 원화·표시·모션 규격은 이 문서를 따른다.

## 10. 제작 순서와 완료 기준

### 1차: 콘셉트 비교

- 주인공 3종의 정면·전투 자세·표정 시트를 만든다.
- 돌격 오타쿠, 음침한 접근 아저씨, 집착 멘헤라 남친의 대표 원화를 만든다.
- 배경 1개 위에 실제 크기로 배치해 풀 일러스트 전투 화면 시안을 만든다.
- 완료 기준: 세 주인공과 적의 성격이 구분되고, 전장에서도 SD가 아닌 전신 일러스트로 보인다.

### 2차: 대표 모션 검증

- 상냥한 형 1종으로 대기·이동·공격·피격과 바스트 모션을 검증한다.
- 츤데레와 누님계에도 같은 시험 동작을 적용해 체형별 설정 차이를 확인한다.
- 발 미끄러짐, 좌우 반전, 가슴·팔·의상 겹침, 정지 후 감쇠, 일시정지를 확인한다.
- 완료 기준: 세 체형의 움직임이 구분되고, 전투 판정과 화면 연출의 타이밍이 맞는다.

### 3차: 작은 전투 구간

- 선택 가능한 주인공 3종, 아군 2종, 적 3종, 보스 1종, 배경·기지 1세트를 연결한다.
- 주인공 선택 → 전투 → 승리 → 재실행 후 선택 복원을 확인한다.
- 다수 교전 때의 가독성과 모바일 성능을 측정한다. 전장 개체는 축소 출력한 공통 텍스처를 공유하고, 큰 원화는 선택·컷인에 필요한 것부터 로딩한다.
- 완료 기준: 한 판 안에서 캐릭터 감상, 모션, 전선 판단, 조작을 함께 확인할 수 있다.

### 4차: 전체 테마 확대

- 아군 10종·일반 적 10종·보스 5종과 5개 장의 배경으로 확장한다.
- 자원·태그·스킬·보스 설명·결과 화면까지 테마 용어를 맞춘다.
- 기존 무당 테마와 왕복 전환, 저장 호환, 누락 이미지 대체 표시를 확인한다.

현재 문서 범위는 이 테마 기획과 연결된 28종 개별 명세·이미지 생성 프롬프트·공통 아트 콘셉트다. 다음 제작 대상은 **주인공 3종 원화 시트와 풀 일러스트 전투 화면 시안**이다. 실제 이미지 생성과 게임 기능 구현은 별도 작업이다.
