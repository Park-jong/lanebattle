## 1. 콘셉트 (결정)

### 테마
**요괴 마을 축제**. 동양(한국) 민담 분위기에 익살스러운 톤을 입힌다.

### 제목 (가제)
**꼬마 무당 대소동**. 나중에 바꿀 수 있다.
- 다른 후보: 부적 한 장 도깨비 한 마리, 등불 지키기, 서낭당 사수기

### 이야기
일 년에 한 번 열리는 마을 요괴 축제 날 밤, 축제 등불을 탐낸 원귀가 성을 세우고 잡귀들을 몰고 내려온다.
견습 꼬마 무당이 서낭당을 지키며 부적으로 마을의 착한 요괴들을 불러내고, 등불을 되찾으러 원귀의 성까지 밀고 올라간다.

- 톤: 무섭지 않고 익살스럽다. 적은 쓰러지면 겁먹은 얼굴로 연기처럼 사라진다.

### 등장 요소 (초안, 4번 유닛 설계에서 확정)
| 구분 | 내용 |
|------|------|
| 영웅 | 꼬마 무당 |
| 자원 | 부적 (기운으로 충전) |
| 아군 | 도깨비 방망이병, 여우불 사수, 해태 |
| 적 | 달걀귀신, 물귀신 투척병, 거대 원귀 |
| 아군 기지 | 마을 서낭당 |
| 적 기지 | 원귀의 성 |

### 아트 방향
- 기본: **둥글고 귀여운 2D 카툰**. 굵은 외곽선과 단순한 형태를 쓴다.
- 포인트: **오방색**(청·적·황·백·흑)과 **한지 질감**을 배경과 UI에 살짝 섞는다.
- 이유: 개성은 살리면서 에셋 제작 부담을 줄인다.

## 2. 핵심 루프 (결정)

### 한 판의 흐름
1. 시작할 때 부적을 조금 가지고 있고, 시간이 지나면 기운이 차오르며 부적이 충전된다.
2. 꼬마 무당이 앞으로 나가 싸우고, 부적을 써서 아군 요괴를 소환한다.
3. 아군 요괴는 자동으로 전진하며 싸운다. 적은 원귀의 성에서 웨이브 단위로 몰려온다.
4. 전선을 밀고 당기다가 원귀의 성을 부수면 승리, 서낭당이 무너지면 패배한다.

### 규칙
| 항목 | 결정 |
|------|------|
| 승리 조건 | 원귀의 성 파괴 |
| 패배 조건 | 서낭당 파괴 |
| 영웅 사망 | 몇 초 뒤 서낭당에서 부활한다. 패배는 아니다 (부활 시간은 3번 영웅 설계에서 정한다) |
| 한 판 길이 | 3~5분 |
| 적 등장 | 시간이 갈수록 강해지는 웨이브. 마지막에 보스(거대 원귀)가 등장한다 |
| 판 끝 보상 | 별 1~3개(남은 서낭당 체력, 걸린 시간 기준)와 재화 (세부 기준은 6번 판 밖 성장에서 정한다) |

### 넣지 않기로 한 것
- 축제 등불 거점(맵 가운데 거점을 차지하면 기운 충전 속도가 달라지는 방식): 넣지 않는다.

## 3. 영웅: 꼬마 무당 (결정)

### 조작과 공격
- 좌우 이동만 한다. 점프는 없다.
- 기본 공격: 짧은 거리의 **방울 휘두르기**. 가까운 적에게 자동으로 나간다.

### 스킬 (신력 소모)
| 스킬 | 효과 | 역할 |
|------|------|------|
| 부채 바람 | 앞쪽 적을 뒤로 밀어내고 약한 피해를 준다 | 전선이 밀릴 때 숨 돌리기 |
| 축원 | 주변 아군 요괴의 체력을 회복하고 잠시 공격력을 올린다 | 아군 밀기 |
| 작두 타기 (궁극기) | 큰 범위 피해. 쿨타임이 길다 | 위기 탈출, 보스전 |

### 자원 분리
- **부적**: 유닛 소환에 쓴다.
- **신력**: 영웅 스킬에 쓴다.
- 의도: "유닛을 더 뽑을지, 스킬을 아낄지" 고민하게 만든다.

### 사망과 부활
- 부활 시간은 5초다. 위협 단계가 오를수록 늘어나며 최대 10초다.
- 영웅이 없는 동안에는 아군 요괴만으로 버텨야 한다.

### 넣지 않기로 한 것
- 판 안 레벨업(처치 경험치로 그 판에서만 강해지는 방식). 성장은 판 밖 업그레이드 빌드로 다룬다.

## 설계 전반의 전제: 업그레이드 빌드 (방향 결정, 세부는 6번)

- 판 밖에서 업그레이드를 골라 **빌드**를 만든다. 빌드는 **언제든 초기화**할 수 있다 (재화 손실 없이 다시 분배하는 방식을 기본으로 가정).
- 빌드 콘셉트 (최소 3가지, 더 추가할 수 있음):
  1. **영웅 강화형**: 꼬마 무당의 공격, 스킬, 생존력을 키워 영웅이 전선을 직접 이끈다.
  2. **특정 유닛 강화형**: 한두 종류의 요괴를 집중적으로 키운다.
  3. **유닛 연계형**: 서로 다른 요괴가 함께 있을 때 효과가 생기는 시너지를 키운다.
- 다른 항목 설계에 주는 영향:
  - 영웅 스킬과 수치는 업그레이드로 갈래가 나뉠 수 있게 만든다 (예: 스킬마다 강화 분기).
  - 유닛마다 따로 강화할 수 있는 항목이 있어야 한다.
  - 유닛에 연계용 속성(태그)을 두어 시너지 조건을 만들 수 있게 한다.
  - 어느 빌드를 골라도 스테이지를 깰 수 있도록 밸런스를 맞춘다.

## 4. 유닛 (결정)

### 상성의 기준
- 공격 유형: **근접 / 원거리 / 마법(범위)**

**아군 태그** (연계 빌드의 기준)
| 태그 | 성격 |
|------|------|
| 도깨비 | 근접. 모일수록 강해진다 |
| 불 | 화상 지속 피해 |
| 신수 | 소수 정예. 보호와 버티기 |
| 바람 | 빠른 속도, 비행, 지원 |

**적 특성**
| 특성 | 효과 | 약점 |
|------|------|------|
| 무리 | 한 마리는 약하고 수가 많다 | 범위 공격 |
| 영체 | 근접 피해 50% 감소 | 불 |
| 갑옷 | 원거리·마법 피해 50% 감소 | 근접, 방어 파괴 |
| 비행 | 근접 공격이 닿지 않는다 | 원거리, 비행 유닛, 바람 |

### 아군 요괴 (10종)
| # | 유닛 | 태그 | 유형 | 역할 | 비용 |
|---|------|------|------|------|------|
| 1 | 도깨비 방망이병 | 도깨비 | 근접 | 기본 전열 | 낮음 |
| 2 | 외다리 도깨비 | 도깨비·바람 | 근접 | 돌격. 첫 타가 강하다 | 중간 |
| 3 | 씨름 도깨비 | 도깨비 | 근접 | 적을 메쳐서 뒤로 밀어낸다 | 중간 |
| 4 | 여우불 사수 | 불 | 원거리 | 화상 | 중간 |
| 5 | 구미호 | 불 | 마법 | 범위 불꽃. 무리 처리 | 높음 |
| 6 | 불가사리 | 신수 | 근접 | 적 방어 파괴 | 높음 |
| 7 | 해태 | 신수 | 근접 | 탱커. 적을 붙잡아 둔다 | 높음 |
| 8 | 삼족오 | 신수·불 | 원거리(비행) | 공격력 오라 | 높음 |
| 9 | 까치 떼 | 바람 | 원거리(비행) | 싸고 빠르다. 비행 적 요격 | 낮음 |
| 10 | 영등 바람 | 바람 | 마법 | 아군 속도 증가, 적 투사체를 빗나가게 한다 | 중간 |

- 외다리 도깨비와 삼족오는 두 태그를 가져서 서로 다른 계열을 잇는다.
- 연계 효과 예시 (세부는 6번 업그레이드 빌드에서 정한다):
  - 도깨비 3마리 이상이 함께 있으면 서로 공격 속도가 올라간다.
  - 화상이 걸린 적을 도깨비가 치면 추가 피해를 준다.
  - 해태가 앞에 서 있으면 뒤의 원거리 유닛이 받는 피해가 줄어든다.

### 적군 (10종)
| # | 적 | 특성 | 역할 | 견제하는 대상 |
|---|------|------|------|---------------|
| 1 | 달걀귀신 | 무리 | 근접 기본 | – |
| 2 | 물귀신 투척병 | – | 원거리. 맞으면 느려진다 | 돌격 유닛 |
| 3 | 처녀귀신 | 영체 | 후열로 돌진 | 원거리 유닛 |
| 4 | 장승 망령 | 갑옷 | 느린 탱커 | 원거리 빌드 |
| 5 | 어둑시니 | 비행 | 근접 공격이 닿지 않는다 | 도깨비 빌드 |
| 6 | 그슨대 | – | 살아 있을수록 점점 커지고 강해진다 | 느린 빌드 |
| 7 | 손각시 | 영체 | 원거리 저주. 회복 차단 | 축원, 회복 빌드 |
| 8 | 저승사자 | – | 주변 아군의 버프 해제 | 연계 빌드 |
| 9 | 강철이 | 갑옷 | 불 피해 무효 | 불 빌드 |
| 10 | 두억시니 | – | 유닛을 무시하고 서낭당으로 직진 | 영웅이 앞에만 있는 빌드 |

### 보스 (5종, 장마다 1종)
상성 극대화: 약점이면 **2배**, 저항이면 **20%만** 받는다 (0은 아니므로 어떤 빌드로도 깰 수는 있다).

| 장 | 보스 | 약점 (2배) | 저항 (20%) | 특수 패턴 | 유리한 빌드 |
|----|------|-----------|-----------|-----------|-------------|
| 1 | 거대 원귀 | 불 | 근접 | 달걀귀신 무리를 소환한다 | 불 연계 |
| 2 | 철갑 장승왕 | 근접, 방어 파괴 | 원거리·마법 | 갑옷이 쌓여 점점 단단해진다 (불가사리로 깎는다) | 도깨비, 불가사리 강화 |
| 3 | 이무기 강철이 | 바람, 근접 | 불 (불 피해로 회복한다) | 가뭄: 부적 충전 속도 감소 | 바람·도깨비 연계 |
| 4 | 어둑시니 대왕 | 원거리, 비행 | 근접 (닿지 않는다) | 하늘에 떠 있다가 가끔 내려와 강타한다 | 까치 떼, 삼족오 강화 |
| 5 | 차사왕 (최종) | 영웅 공격 | 유닛 연계 효과 무효 | 주기적으로 모든 버프를 해제한다 | 영웅 강화 |

- 장마다 유리한 빌드가 달라서, 3가지 빌드 콘셉트가 모두 한 번씩 주인공이 된다.
- 보스의 약점과 저항은 스테이지 선택 화면에서 미리 보여 준다. 그걸 보고 빌드를 다시 짜게 만드는 것이 목표다.

### 해금과 출전
- 현재 결정: **해금 없음**(처음부터 10종 모두 사용), **출전 제한 없음**(한 판에 10종 모두 소환 가능).
- 플레이 테스트 후 다시 검토할 수 있다.

## 5. 자원·경제 (결정)

### 판 안 자원
| 자원 | 용도 | 충전 방식 |
|------|------|-----------|
| 부적 | 유닛 소환 | 시간에 따라 자동 충전, 적 처치 시 조금 더 |
| 신력 | 영웅 스킬 | 시간에 따라 자동 충전, 영웅이 공격을 맞히면 추가 |

### 판 안 투자: 기운 모으기
- 부적을 써서 단계를 올린다. 최대 5단계이고 단계마다 비용이 오른다.
- **한 단계마다 부적 최대치와 충전 속도가 함께 오른다** (묶음 방식).
  - 최대치와 충전 속도를 따로 고르는 선택은 판 밖 업그레이드 빌드로 넘긴다 (예: 비싼 유닛 위주 빌드는 최대치, 물량 빌드는 충전 속도).

### 적 처치 보상
- 처치하면 부적을 조금 준다. 강한 적일수록 많이 준다.
- 전선을 밀수록 자원이 더 들어와서, 앞으로 나갈 이유가 된다.

### 판 밖 재화
- 스테이지를 클리어하면 별과 엽전을 얻는다. 업그레이드 포인트의 출처는 6번에서 정한다.

### 수치 (초안, 플레이 테스트로 조정)
| 항목 | 값 |
|------|-----|
| 부적 시작 / 최대 | 50 / 200 |
| 부적 충전 | 초당 8. 기운 모으기 1단계마다 충전 +3, 최대치 +60 |
| 신력 시작 / 최대 | 50 / 100 |
| 신력 충전 | 초당 5, 영웅 타격 1회당 +2 |
| 유닛 비용대 | 낮음 25~35 · 중간 50~70 · 높음 90~150 |

## 6. 판 밖 성장 (결정)

### 스테이지 구성
- **5장 × 5스테이지 = 25스테이지**. 장마다 일반 스테이지 4개와 보스 스테이지 1개(4번의 보스 5종)로 이루어진다.
- 별 조건:
  - ★1: 클리어
  - ★2: 서낭당 체력 50% 이상 남기고 클리어
  - ★3: ★2 조건 + 제한 시간 안에 클리어 (제한 시간은 스테이지마다 정한다)

### 업그레이드 포인트: 신명
- 별 1개 = 신명 1. 별로 얻는 신명은 최대 75다.
- **엽전**: 클리어할 때마다 얻는다(반복 플레이 가능). 엽전으로 신명을 살 수 있고, 살수록 가격이 오른다. 막힌 스테이지를 반복 플레이로 넘기 위한 장치다.
- **초기화**: 무료, 언제든 가능(전투 중 제외). 쓴 신명을 전부 돌려받는다.
- **빌드 저장 칸 3개**: 보스별 빌드를 저장해 두고 바로 바꿔 끼운다.

### 업그레이드 트리 (4갈래)
- 신명을 다 모아도 전체 트리의 약 절반만 찍을 수 있게 해서 선택을 강제한다.
- 무당·연계·살림 트리는 낮은 단들에 찍은 신명 수로 다음 단이 열린다 (5점 → 2단, 12점 → 3단, 20점 → 4단).
- 요괴 트리는 단 기준 없이 같은 유닛의 ① → ② → ③ 순서만 지키면 된다 (유닛 하나 각성까지 10점).

| 트리 | 빌드 콘셉트 | 항목 |
|------|-------------|------|
| 무당 | 영웅 강화형 | 공격력·체력, 부활 시간 감소, 신력 충전. 스킬마다 갈래 선택(예: 부채 바람 → 더 넓게 / 더 세게) |
| 요괴 | 특정 유닛 강화형 | 유닛마다 3단계: ① 기본 능력치 ② 핵심 능력 강화(예: 해태 붙잡기 시간 증가) ③ 각성(특수 효과, 예: 구미호 불꽃 연속 발사) |
| 연계 | 유닛 연계형 | 태그 시너지 단계(예: 도깨비 3/5/7마리), 교차 연계(화상 + 도깨비 추가 피해, 해태 뒤 원거리 보호 등) |
| 살림 | 경제 (모든 빌드 공통) | 시작 부적, 부적 최대치·충전 속도(따로 선택), 기운 모으기 비용 할인 |

- 트리별 세부 항목, 비용, 수치는 구현 전에 별도 표로 정리한다.

### 빌드와 보스 공략의 연결
- 스테이지 선택 화면에 보스의 약점과 저항을 보여 주고, 그 화면에서 바로 빌드를 바꿀 수 있다.
- 예: 2장 철갑 장승왕 앞에서 "연계(불)" 빌드를 "요괴: 불가사리 각성 + 도깨비" 빌드로 바꾼다.

### 저장
- 진행도(별), 신명, 엽전, 빌드 3칸을 브라우저(localStorage)에 저장한다.

## 7. 화면·조작 (결정)

### 화면 흐름
```
타이틀 → 지도(장·스테이지 선택) ⇄ 빌드(업그레이드 트리, 저장 칸 3개)
              ↓
            전투 → 결과(별, 엽전, 신명) → 지도
```
- 지도: 스테이지를 고르면 보스의 약점과 저항이 보이고, "빌드 바꾸기" 버튼이 있다.
- 설정: 소리 크기, 조작 안내. 타이틀과 일시정지 화면에서 연다.

### 전투 화면 배치 (960×540 기준, 가로 화면)
```
┌──────────────────────────────────────────────┐
│ 부적 ■■■■□ 120/200   [미니맵 ─●──▲──]   ⏸ │
│ 신력 ■■■□□  60/100   서낭당 ▬▬▬  원귀 성 ▬▬ │
│                                              │
│          (전장: 영웅, 요괴, 적)               │
│                                              │
├──────────────────────────────────────────────┤
│ ◀ ▶ │ [1][2][3][4][5]  │ [기운↑] (Q)(W)(E) │
│     │ [6][7][8][9][0]  │                    │
└──────────────────────────────────────────────┘
```
- 소환 버튼 10개: 2줄 × 5칸 아이콘. 비용 숫자와 쿨타임 덮개를 표시하고, 부적이 부족하면 흐리게 보인다.
- 버튼 순서는 빌드 화면에서 바꿀 수 있다.

### PC 조작
| 동작 | 키 |
|------|-----|
| 이동 | A / D 또는 ← / → |
| 유닛 소환 | 1 ~ 0 |
| 스킬 (부채 바람 / 축원 / 작두 타기) | Q / W / E |
| 기운 모으기 | R |
| 일시정지 | Esc 또는 P |

- 마우스로 버튼을 눌러도 모두 동작한다.

### 모바일 조작
- 가로 화면 전용. 세로로 들면 "화면을 돌려 주세요" 안내를 띄운다.
- 왼쪽 아래 ◀ ▶ 버튼을 누르고 있는 동안 이동한다.
- 가운데는 소환 아이콘 2줄, 오른쪽은 스킬 3개와 기운 모으기 둥근 버튼.
- 버튼은 최소 44px 이상. 화면이 작으면 전장 높이를 줄여 버튼 공간을 확보한다.

### 피드백 표시
- 보스 등장 시 화면 위에 큰 보스 체력바와 약점·저항 아이콘을 표시한다.
- 데미지 숫자 색으로 상성을 알린다: 약점이면 노란색 큰 숫자, 저항이면 회색 작은 숫자.

## 8. 아트·사운드 (결정)

### 그래픽 제작 방식
1. **구현 초반**: 도형과 색으로 만든다. 재미와 밸런스를 먼저 확인한다.
2. **교체**: 그림을 데이터로 분리해 두고, 이미지 파일만 바꿔 끼운다.
- 이미지 에셋은 **사용자가 따로 구해 온다**.
- 애니메이션은 **종이 인형 방식**: 몸통, 머리, 팔, 무기를 따로 그리고 코드로 흔들고 늘리고 줄여서 움직인다. 프레임을 많이 그릴 필요가 없다.

### 에셋 준비 가이드 (구해 올 때 참고)
- 형식: 배경이 투명한 PNG
- 크기: 유닛 높이 기준 약 128px로 그린 것(화면에는 그 절반 정도로 표시). 보스는 2~4배 크기
- 방향: 모든 캐릭터가 **오른쪽을 바라보는** 그림 (적은 코드에서 좌우를 뒤집는다)
- 종이 인형용 부위: 몸통 / 머리 / 앞팔 / 뒷팔 / 무기를 각각 따로 둔 파일. 부위 분리가 어려우면 통짜 한 장도 쓸 수 있다
- 배경: 장마다 원경 / 중경 / 근경 3장. 가로로 이어 붙여도 이음새가 없는 그림이 좋다
- 아이콘: 유닛 10종, 스킬 3종, 태그 4종, 적 특성 4종. 정사각형 약 96px
- 라이선스: 상업적 이용 가능 여부와 출처를 함께 기록한다

### 색 규칙 (오방색 = 태그)
| 대상 | 색 |
|------|-----|
| 도깨비 | 청 (파랑) |
| 불 | 적 (빨강) |
| 신수 | 황 (노랑·금색) |
| 바람 | 백 (흰색·하늘색) |
| 적 (귀신) | 흑 (먹색·보라 톤) |
- 두 태그를 가진 유닛은 두 색을 섞어 쓴다.

### 배경 (장마다 다르게, 3겹 패럴랙스)
| 장 | 배경 |
|----|------|
| 1 | 축제 밤의 마을 (등불, 초가) |
| 2 | 장승이 늘어선 고개 |
| 3 | 가뭄으로 마른 강바닥 |
| 4 | 어둠이 내린 대나무 숲 |
| 5 | 저승 문 앞 |

### 사운드
- 배경음: 국악풍의 가벼운 리듬(장구, 꽹과리, 태평소 느낌). 평소용 1곡과 보스전용 1곡으로 시작한다.
- 효과음: 방울 공격, 부적 소환, 타격, 귀신이 사라지는 소리, 버튼 클릭
- 출처: 무료(CC0) 라이브러리를 기본으로 쓴다. 출처와 라이선스를 기록한다.
- 설정에서 배경음과 효과음 크기를 따로 조절한다.

### 연출
- 적이 쓰러지면 겁먹은 얼굴로 연기처럼 사라진다.
- 유닛을 소환하면 부적이 펑 터지며 등장한다.
- 보스가 등장하면 화면이 어두워지고 보스 이름이 붓글씨 느낌으로 나타난다.
