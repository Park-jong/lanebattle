# 캐릭터 아트·스킨 테마 목록

최종 수정: 2026-11-05

기본 무당 테마와 별도 스킨 테마를 같은 깊이의 폴더로 관리한다. 이 문서는 전체 테마의 공통 목차이며, 각 테마의 화풍·캐릭터·생성 지침은 해당 폴더에 둔다.

[게임 설계](../design.md) · [스킨·애니메이션 설계](../skins-and-animation.md)

| `default/` | 기본 꼬마 무당·한국 민담 요괴, SD 카툰 | [26종 명세·아트 가이드](default/README.md) · [이미지 생성·적용 기록](default/GENERATED.md) |

## 폴더 구성

```text
docs/art/
  README.md                       전체 테마 목록·공통 제작 규칙
  default/                        기본 무당·요괴 테마
    README.md                     테마 아트 가이드·26종 목록
    GENERATED.md                  기본 이미지 생성·적용 기록
    hero/
    ally/
    enemy/
    boss/
  bishoujo-vs-otaku/               미소녀 VS 오타쿠 테마
    README.md                     28종 목록·제작 순서
    image-generation-concept.md  공통 이미지 생성 콘셉트
    units/                        캐릭터·동작 컷별 명세
    prompts/                      이미지 생성 프롬프트·컷 목록
```

새 세계관·화풍의 스킨 테마는 `docs/art/<themeId>/`에 같은 깊이의 폴더로 추가한다. 같은 캐릭터의 추가 의상 스킨은 해당 테마의 캐릭터 문서에서 관리한다. 실제 이미지 경로와 코드의 스킨 ID는 각 테마의 납품 명세를 따른다.

## 모든 테마·추가 스킨의 공통 동작 컷

| 동작 | 파일 범위 | 컷 수 |
| --- | --- | --- |
| 대기 | `idle_00.png` ~ `idle_01.png` | 2 |
| 이동·롤러·비행 | `walk_00.png` ~ `walk_03.png` | 4 |
| 기본 공격 | `attack_00.png` ~ `attack_03.png` | 4 |
| 피격 | `hit_00.png` ~ `hit_01.png` | 2 |
| 등장·부활 | `spawn_00.png` ~ `spawn_02.png` | 3 |
| 퇴장 | `death_00.png` ~ `death_03.png` | 4 |
| 공통 본체 합계 | 모든 스킨에 동일하게 적용 | **19** |

고유 스킬·비행·착지·성장·바스트 등은 개별 MD에 지정된 추가 파일을 준비한다. 모든 추가 스킨도 자체 의상에 맞는 전체 컷을 갖춘다. 한 PNG에는 한 포즈를 담고, 한 스킨은 여러 동작 PNG의 묶음으로 납품한다. 프레임마다 방향·캔버스·배율·피벗을 유지한다.

화풍·인체 비율·원화 해상도·무기·컷별 자세는 테마별 지침을 따른다. 리깅은 프레임 제작 보조로 사용할 수 있으며, 최종 납품은 개별 동작 이미지와 클립 목록을 포함한다.
