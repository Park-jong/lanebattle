- 기준 외형: 23세·172cm 성인 여성, 약 7.5등신. 자주색 포니테일·청록 눈·흰 장교 재킷·자주색 짧은 망토·전술 세이버·지휘 건틀릿.

- 무기·장비: 지휘도 아스트라, 왼팔 통합 지휘 건틀릿, 의료 미스트 카트리지, 축전 모듈
- 팔레트 제안: 흰색 #EDEFF3 / 자주 #6D365F / 검정 #202533 / 청록 #5BC9C3 / 은색 #AEB8C8
- 대표 자세: 오른발을 반 보 앞으로 두고 지휘도 아스트라를 낮게 전방으로 향한다. 왼손은 건틀릿을 확인한 뒤 몸 옆 경계 위치로 돌아온다.

아군은 약 7~8등신의 성인 전신 비율을 유지하고, 적은 인간형 원형 또는 명시된 변이·기계 비율을 따른다. SD·치비로 축약하지 않는다. 화면 식별은 큰 머리 대신 실루엣·장비·색 배치로 확보한다.

## 기준 원화 제작 설명

> 현대 밀리터리와 일본 서브컬처를 결합한 횡스크롤 게임용 2D 캐릭터. 낮게 묶은 자주색 포니테일, 흰 장교 재킷, 짧은 자주색 망토, 길고 곧은 한손 세이버. 왼팔 지휘 건틀릿을 반대쪽 식별점으로 둔다. 오른발을 반 보 앞으로 두고 지휘도 아스트라를 낮게 전방으로 향한다. 왼손은 건틀릿을 확인한 뒤 몸 옆 경계 위치로 돌아온다. 성인 일반 등신의 전신과 주요 장비를 끝까지 포함한다. 오른쪽을 바라보는 측면 또는 약한 3/4 측면, 투명 배경, 한 이미지에 한 포즈. 위 팔레트를 따르고 이후 동작은 같은 얼굴·체형·복장·장비를 유지한다.

피할 요소: 23세를 유지한다. 해태·바이크에 탑승한 전투 외형, 드론, 영웅을 구별하려고 머리만 키우는 표현은 사용하지 않는다. 공통적으로 배경 풍경·UI 문자·워터마크·다른 전투 개체를 본체에 합성하지 않는다.
