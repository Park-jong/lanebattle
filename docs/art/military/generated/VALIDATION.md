각 캐릭터는 개별 커밋으로 저장했다. 이후 보정한 이미지는 같은 캐릭터의 추가 커밋에 기록했다. 공용 배경·기지·UI는 각각 별도 커밋이다. 원본 이미지와 개별 JSON에는 실제 출력 크기, 알파 범위, 참조 파일, 실행 프롬프트, 수행한 육안 검수를 기록했다.

시온의 기본 원본 70개는 자주색 포니테일·세이버를 사용한 이전 디자인 이력이다. 분홍 장발·전류 대검을 사용하는 새 리비전은 `output/art-generation/revisions/shion-electromagnetic-v2/`에서 별도 관리하며 이 문서의 수량·검증 대상에 포함하지 않는다. 현재 컨셉 문서와 기본 원본의 시온 외형이 다르므로 기본 폴더를 새 디자인으로 간주하면 안 된다.

## 수행한 검사

- 1,476개 PNG를 모두 디코딩했고 누락·읽기 오류가 없었다. 계획의 투명 이미지에는 알파가 있었으며 완전히 불투명한 배경으로 저장된 결과는 없었다.
- 본체의 알파 최댓값이 255인지 검사했고, 의도하지 않은 전체 반투명 처리가 검출되지 않았다.
- 생성 도구의 보존 원본과 작업별 메타데이터가 모두 존재했다.
- 본체 1,135개의 최외곽 행·열을 검사했다. 한 변에 알파 128 이상인 픽셀이 6개를 초과하는 결과는 0개였다. 이 검사는 잘림 후보를 찾는 보조 검사이며 모든 외형 오류의 부재를 보증하지 않는다.
- 계획된 1,476개 이미지가 Git에 추적되며, 이미지 작업 트리는 검사 시점의 `HEAD`와 일치했다. 캐릭터 26종의 개별 기록은 모두 `all` 상태이고 생성 수가 계획 수와 일치했다.
- 작업 스크립트 7개의 Python 구문 검사를 통과했다.

워커 대기 자세의 신발 여백, 아카네 방향 전환·아오이 피격·저거너트 장갑 자세의 상하 여백, 호버·후우카 일부 동작의 불필요한 효과 등 발견한 문제는 내장 이미지 생성 도구로 다시 생성하고 육안 확인했다. 교체 전 파일과 도구 원본은 보존했다. 이미지 픽셀을 일괄 리사이즈하거나 배경 제거로 가공하지 않았다.

재검사 명령:

```powershell
python -X utf8 scripts/military-art-audit.py
python -X utf8 scripts/military-art-edges.py
```

로컬 상세 결과는 `output/art-generation/military-run/audit.json`, `edge-review.json`, `generated.jsonl`, `qa.jsonl`에 있다. 버전 관리되는 검증 요약은 이 폴더의 `validation.json`이다.

## 현재 전달 상태

이 묶음은 생성 원본이다. 출력 크기는 계획의 목표 해상도와 다를 수 있으며 실제 크기를 개별 기록에 남겼다. 본체의 발 위치·피벗·축척 통일, 연속 프레임의 외형 일관성과 발 미끄러짐 검수, 프레임 순서·재생 시간 조정, 아틀라스와 런타임 연결은 별도 적용 작업이다.

머리카락·의복·체형에 따른 후속 움직임은 모션 이미지의 제작 지침에 반영했다. 실제 게임의 바스트 모핑이나 머리카락 물리 기능을 구현·검증한 상태는 아니다. 배경·기지·UI 역시 이 묶음의 생성만으로 실행 게임에 자동 적용되지 않는다.
