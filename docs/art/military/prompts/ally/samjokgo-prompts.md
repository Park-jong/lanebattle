# 레이카 (レイカ) — 이미지 생성 프롬프트

[공통 사용법·전체 목록](../README.md) · [개별 컨셉](../../ally/samjokgo.md)

대상 키 `ally:samjokgo`, 스킨 `military`. 파일별 블록은 그 자체로 사용할 수 있는 전체 프롬프트다. 먼저 idle_00을 확정하고 이후 본체·아이콘·미리보기에는 그 원화를 첨부한다. 효과 연속 컷은 같은 효과의 첫 컷을 첨부한다.

아래 크기·피벗은 납품 목표다. 생성 결과의 실제 해상도·알파·기준점·인체와 장비 수는 검수 후 정렬한다. 프롬프트 작성만으로 해당 이미지·프레임·기능이 생성된 것은 아니다.

기본 제작 프롬프트 30개, 보간·전환 확장 23개. 확장은 자연스러운 동작을 위한 제작안이며 별도 클립·전환 연결이 필요하다.

## 보간·전환 재생 순서

추가 번호를 파일 이름순으로 재생하지 않는다. 기준 키프레임 사이에 다음 순서로 넣는다. 기존 최소 프레임만 먼저 연결하는 경우에는 확장 프레임을 읽지 않는다.

- `idle`: `idle_00` → `idle_02` → `idle_03` → `idle_04` → `idle_01` → `idle_05` → `idle_06` → `idle_07`
- `walk`: `walk_00` → `walk_04` → `walk_01` → `walk_05` → `walk_02` → `walk_06` → `walk_03` → `walk_07`
- `attack`: `attack_00` → `attack_01` → `attack_02` → `attack_04` → `attack_03` → `attack_05`
- `hit`: `hit_00` → `hit_02` → `hit_01` → `hit_03`

`start`·`stop`·`turn`은 각각 00 → 01 → 02. 기존 렌더러에서 자동으로 호출되는 상태가 아니다. 회전 원본은 오른쪽 방향으로 유지하고 실제 반전 시점을 보상 포즈와 연결한다.
