## 외형·식별 기준

- 기준 외형: 시간이 지날수록 근육과 신체가 비대해지는 돌연변이 좀비
- 실루엣: 부푼 어깨·비대한 팔과 팽팽하게 당겨진 낡은 옷. 초기에 인간형임이 읽히며 성장해도 같은 개체의 특징을 유지한다.
- 무기·장비: 비대해지는 근육·팔·찢어진 의복
- 팔레트 제안: 회갈 피부 #989079 / 근육 음영 #686F59 / 천 #595B50 / 변이 강조 #936B63
- 대표 자세: 무거운 두 팔을 몸 옆에 늘이고 굽은 무릎으로 하중을 받는다.

아군은 약 7~8등신의 성인 전신 비율을 유지하고, 적은 인간형 원형 또는 명시된 변이·기계 비율을 따른다. SD·치비로 축약하지 않는다. 화면 식별은 큰 머리 대신 실루엣·장비·색 배치로 확보한다.

## 전투·강화·효과 연결

- 현재 기능 기준: 5초마다 최대 체력·공격력 +15% (최대 6회). 몸집도 커짐
- 개별 주의점: 성장 자체는 기존 배율·중첩을 사용한다. 성장 단계마다 모든 본체 컷을 다시 만들거나 원화에 성장 배율을 중복 적용하지 않는다.

표의 본체 19컷은 최소 동작 목록이다. 자연스러운 호흡·발 디딤·정지·반전·모핑에 필요한 중간·전환 프레임을 추가하고 실제 클립 순서·fps를 기록한다. 프레임 수 때문에 전투 속도·판정 시점을 바꾸지 않는다.

보조 움직임: 늘어진 옷과 근육의 하중 반응은 같은 골격에 종속한다. 전체 확대 중 얼굴·팔 길이·발 기준점이 갑자기 바뀌지 않게 한다. 바스트 모핑 없음.

적은 위의 질량·재질별 보조 움직임을 사용하고 아군 9종의 바스트 모핑 규칙을 자동 적용하지 않는다.

가속·정지·공격 회수 후 머리카락·천·케이블이 서로 다른 지연으로 따라오고 감쇠한다. 고정 장비·총기·방패는 강체로 유지한다. 일시정지·결과 화면에서는 모든 움직임이 함께 멈춘다.

## 파일·캔버스·연결

- 본체 원본 캔버스 제안: **768×1024px**, 투명 RGBA·sRGB.
- 기준점: **(0.5, 0.875)**. 모든 본체 동작의 캔버스·배율·피벗을 통일한다.
- 방향: 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면. 반전할 수 있게 읽을 수 있는 문자·계급 텍스트를 본체에 넣지 않는다.
- 원본 보관 예정: `output/art-generation/source-assets/enemy/geuseundae/military/`.
- 런타임 예정: `public/assets/characters/runtime/military/enemy-geuseundae.png`·`.json`.
- `skin.json`에 canvas·origin·bodyBounds·클립·fps·loop 및 필요 시 displayHeight·displayTop을 기록한다. 무기 여백을 충돌 크기로 쓰지 않는다.
- 정적 미리보기·아이콘은 본체의 최종 원화를 기준으로 파생하고, UI 이름·비용·체력바·그림자·투사체·큰 효과는 분리한다.

고유 클립·효과는 파일만 추가해도 자동 재생되지 않는다. 일반 공격·투사체·상태 표시의 기존 연결점을 사용하고 필요한 호출·방향 전환·효과 좌표를 별도로 연결한다. 최초 투사체 연결은 종류별 대표 `projectile_*` 하나를 사용한다. 출처·도구·제작일·수정 이력도 함께 기록한다.

## 기준 원화 제작 설명

> 현대 밀리터리와 일본 서브컬처를 결합한 횡스크롤 게임용 2D 캐릭터. 부푼 어깨·비대한 팔과 팽팽하게 당겨진 낡은 옷. 초기에 인간형임이 읽히며 성장해도 같은 개체의 특징을 유지한다. 무거운 두 팔을 몸 옆에 늘이고 굽은 무릎으로 하중을 받는다. 설정된 변이체·기계의 전체 실루엣과 주요 장비를 끝까지 포함한다. 오른쪽을 바라보는 측면 또는 약한 3/4 측면, 투명 배경, 한 이미지에 한 포즈. 위 팔레트를 따르고 이후 동작은 같은 얼굴·체형·복장·장비를 유지한다.

피할 요소: 성장 자체는 기존 배율·중첩을 사용한다. 성장 단계마다 모든 본체 컷을 다시 만들거나 원화에 성장 배율을 중복 적용하지 않는다. 공통적으로 배경 풍경·UI 문자·워터마크·다른 전투 개체를 본체에 합성하지 않는다.
