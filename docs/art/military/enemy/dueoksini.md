## 외형·식별 기준

- 기준 외형: 거대한 팔과 두꺼운 머리뼈를 가진 돌격형 변이 좀비
- 실루엣: 두꺼운 머리뼈·큰 팔·앞으로 쏠린 돌격형 상체. 머리와 팔이 하나의 쐐기처럼 전진하는 실루엣.
- 무기·장비: 두꺼운 머리뼈·큰 팔·기지 파괴용 신체
- 팔레트 제안: 회갈 피부 #9B907C / 경화골 #B3AA91 / 어두운 조직 #5A5951 / 적갈 #8B6259
- 대표 자세: 고개를 낮추고 두꺼운 팔을 몸 앞에 둔 전진 준비 자세.

아군은 약 7~8등신의 성인 전신 비율을 유지하고, 적은 인간형 원형 또는 명시된 변이·기계 비율을 따른다. SD·치비로 축약하지 않는다. 화면 식별은 큰 머리 대신 실루엣·장비·색 배치로 확보한다.

## 전투·강화·효과 연결

- 현재 기능 기준: 유닛과 영웅에 막히지 않고 굿당으로 직진, 굿당에 피해 x2
- 개별 주의점: 유닛·영웅을 무시하고 기지로 향한다. 유닛에 닿을 때 새 충돌 피해·밀치기·폭발을 추가하지 않는다.

표의 본체 19컷은 최소 동작 목록이다. 자연스러운 호흡·발 디딤·정지·반전·모핑에 필요한 중간·전환 프레임을 추가하고 실제 클립 순서·fps를 기록한다. 프레임 수 때문에 전투 속도·판정 시점을 바꾸지 않는다.

보조 움직임: 목·팔의 질량과 찢어진 옷자락이 돌격 후 늦게 안정된다. 전신을 눌렀다 늘이는 방식은 피한다. 바스트 모핑 없음.

적은 위의 질량·재질별 보조 움직임을 사용하고 아군 9종의 바스트 모핑 규칙을 자동 적용하지 않는다.

가속·정지·공격 회수 후 머리카락·천·케이블이 서로 다른 지연으로 따라오고 감쇠한다. 고정 장비·총기·방패는 강체로 유지한다. 일시정지·결과 화면에서는 모든 움직임이 함께 멈춘다.

## 파일·캔버스·연결

- 본체 원본 캔버스 제안: **768×1024px**, 투명 RGBA·sRGB.
- 기준점: **(0.5, 0.875)**. 모든 본체 동작의 캔버스·배율·피벗을 통일한다.
- 방향: 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면. 반전할 수 있게 읽을 수 있는 문자·계급 텍스트를 본체에 넣지 않는다.
- 원본 보관 예정: `output/art-generation/source-assets/enemy/dueoksini/military/`.
- 런타임 예정: `public/assets/characters/runtime/military/enemy-dueoksini.png`·`.json`.
- `skin.json`에 canvas·origin·bodyBounds·클립·fps·loop 및 필요 시 displayHeight·displayTop을 기록한다. 무기 여백을 충돌 크기로 쓰지 않는다.
- 정적 미리보기·아이콘은 본체의 최종 원화를 기준으로 파생하고, UI 이름·비용·체력바·그림자·투사체·큰 효과는 분리한다.

고유 파일 제안:

| 파일 범위 / 클립 | 크기 | 내용·연결 |
| --- | --- | --- |
| `fx_base_breach_00.png`~`fx_base_breach_02.png` / `fx_base_breach` | 512×256 | 실제 아군 기지 타격의 충격·파편 |

고유 클립·효과는 파일만 추가해도 자동 재생되지 않는다. 일반 공격·투사체·상태 표시의 기존 연결점을 사용하고 필요한 호출·방향 전환·효과 좌표를 별도로 연결한다. 최초 투사체 연결은 종류별 대표 `projectile_*` 하나를 사용한다. 출처·도구·제작일·수정 이력도 함께 기록한다.

## 기준 원화 제작 설명

> 현대 밀리터리와 일본 서브컬처를 결합한 횡스크롤 게임용 2D 캐릭터. 두꺼운 머리뼈·큰 팔·앞으로 쏠린 돌격형 상체. 머리와 팔이 하나의 쐐기처럼 전진하는 실루엣. 고개를 낮추고 두꺼운 팔을 몸 앞에 둔 전진 준비 자세. 설정된 변이체·기계의 전체 실루엣과 주요 장비를 끝까지 포함한다. 오른쪽을 바라보는 측면 또는 약한 3/4 측면, 투명 배경, 한 이미지에 한 포즈. 위 팔레트를 따르고 이후 동작은 같은 얼굴·체형·복장·장비를 유지한다.

피할 요소: 유닛·영웅을 무시하고 기지로 향한다. 유닛에 닿을 때 새 충돌 피해·밀치기·폭발을 추가하지 않는다. 공통적으로 배경 풍경·UI 문자·워터마크·다른 전투 개체를 본체에 합성하지 않는다.
