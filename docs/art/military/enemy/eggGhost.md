## 외형·식별 기준

- 기준 외형: 찢어진 일상복, 창백한 피부, 느린 움직임의 일반 감염자
- 실루엣: 찢어진 회갈색 일상복, 창백한 성인 피부, 기울어진 어깨와 늘어진 두 팔. 가장 단순한 인간형 감염자.
- 무기·장비: 빈손·낡은 일상복. 늘어진 팔로 근접 공격
- 팔레트 제안: 창백 #ABB4A6 / 회갈 #746C62 / 먹회 #333B3C / 감염 강조 #8A565B
- 대표 자세: 한쪽 어깨가 내려가고 턱이 기운 채 두 팔을 무겁게 늘어뜨린다.

아군은 약 7~8등신의 성인 전신 비율을 유지하고, 적은 인간형 원형 또는 명시된 변이·기계 비율을 따른다. SD·치비로 축약하지 않는다. 화면 식별은 큰 머리 대신 실루엣·장비·색 배치로 확보한다.

## 전투·강화·효과 연결

- 현재 기능 기준: 없음 (수가 많음)
- 개별 주의점: 느린 인상의 보행과 실제 속도 65를 구분한다. 여성형 고유 캐릭터·중장갑·특수 무기를 추가하지 않는다.

가속·정지·공격 회수 후 머리카락·천·케이블이 서로 다른 지연으로 따라오고 감쇠한다. 고정 장비·총기·방패는 강체로 유지한다. 일시정지·결과 화면에서는 모든 움직임이 함께 멈춘다.

## 파일·캔버스·연결

- 본체 원본 캔버스 제안: **768×1024px**, 투명 RGBA·sRGB.
- 기준점: **(0.5, 0.875)**. 모든 본체 동작의 캔버스·배율·피벗을 통일한다.
- 방향: 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면. 반전할 수 있게 읽을 수 있는 문자·계급 텍스트를 본체에 넣지 않는다.
- 원본 보관 예정: `output/art-generation/source-assets/enemy/eggGhost/military/`.
- 런타임 예정: `public/assets/characters/runtime/military/enemy-eggGhost.png`·`.json`.
- `skin.json`에 canvas·origin·bodyBounds·클립·fps·loop 및 필요 시 displayHeight·displayTop을 기록한다. 무기 여백을 충돌 크기로 쓰지 않는다.
- 정적 미리보기·아이콘은 본체의 최종 원화를 기준으로 파생하고, UI 이름·비용·체력바·그림자·투사체·큰 효과는 분리한다.

고유 파일 제안:

| 파일 범위 / 클립 | 크기 | 내용·연결 |
| --- | --- | --- |
| `fx_walker_hit_00.png`~`fx_walker_hit_01.png` / `fx_walker_hit` | 256×256 | 짧은 타격·흙먼지, 공용 근접 효과 재사용 가능 |

고유 클립·효과는 파일만 추가해도 자동 재생되지 않는다. 일반 공격·투사체·상태 표시의 기존 연결점을 사용하고 필요한 호출·방향 전환·효과 좌표를 별도로 연결한다. 최초 투사체 연결은 종류별 대표 `projectile_*` 하나를 사용한다. 출처·도구·제작일·수정 이력도 함께 기록한다.

## 기준 원화 제작 설명

> 현대 밀리터리와 일본 서브컬처를 결합한 횡스크롤 게임용 2D 캐릭터. 찢어진 회갈색 일상복, 창백한 성인 피부, 기울어진 어깨와 늘어진 두 팔. 가장 단순한 인간형 감염자. 한쪽 어깨가 내려가고 턱이 기운 채 두 팔을 무겁게 늘어뜨린다. 설정된 변이체·기계의 전체 실루엣과 주요 장비를 끝까지 포함한다. 오른쪽을 바라보는 측면 또는 약한 3/4 측면, 투명 배경, 한 이미지에 한 포즈. 위 팔레트를 따르고 이후 동작은 같은 얼굴·체형·복장·장비를 유지한다.

피할 요소: 느린 인상의 보행과 실제 속도 65를 구분한다. 여성형 고유 캐릭터·중장갑·특수 무기를 추가하지 않는다. 공통적으로 배경 풍경·UI 문자·워터마크·다른 전투 개체를 본체에 합성하지 않는다.
