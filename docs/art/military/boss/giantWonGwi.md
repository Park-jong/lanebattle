## 외형·식별 기준

- 기준 외형: 거대한 감염낭을 가진 모체형 좀비. 몸에서 소형 감염체 생성
- 실루엣: 거대한 등·복부 감염낭과 낮게 버틴 두꺼운 다리. 모체형 변이체이며 작은 워커와 같은 몸으로 합성하지 않는다.
- 무기·장비: 거대한 감염낭·전방 타격 팔·지지 다리
- 팔레트 제안: 회갈 #8A8771 / 감염낭 #9F7C68 / 조직 #5D6351 / 감염 강조 #BC9566
- 대표 자세: 감염낭의 하중을 받쳐 넓게 서고 양팔을 전방 지지점처럼 둔다.

아군은 약 7~8등신의 성인 전신 비율을 유지하고, 적은 인간형 원형 또는 명시된 변이·기계 비율을 따른다. SD·치비로 축약하지 않는다. 화면 식별은 큰 머리 대신 실루엣·장비·색 배치로 확보한다.

## 전투·강화·효과 연결

- 현재 기능 기준: 주기적으로 일반 적 5마리 소환, 근접 저항
- 개별 주의점: 소환수는 기존 eggGhost=워커 5기다. 본체 PNG에 워커들을 합성하거나 새 소환 적 ID를 만들지 않는다.

| 항목 | 유지할 내용 |

| 약점 | 소이 |

패턴 수치는 현재 기본 정의를 옮긴 참고값이다. 보스 출현·기지 잠금·보상은 기존 규칙을 사용한다. 여러 약점 조건이 동시에 맞아도 약점 배율을 다시 곱하지 않는다.

## 파일·캔버스·연결

- 본체 원본 캔버스 제안: **1536×1536px**, 투명 RGBA·sRGB.
- 기준점: **(0.5, 0.875)**. 모든 본체 동작의 캔버스·배율·피벗을 통일한다.
- 방향: 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면. 반전할 수 있게 읽을 수 있는 문자·계급 텍스트를 본체에 넣지 않는다.
- 원본 보관 예정: `output/art-generation/source-assets/boss/giantWonGwi/military/`.
- 런타임 예정: `public/assets/characters/runtime/military/boss-giantWonGwi.png`·`.json`.
- `skin.json`에 canvas·origin·bodyBounds·클립·fps·loop 및 필요 시 displayHeight·displayTop을 기록한다. 무기 여백을 충돌 크기로 쓰지 않는다.
- 정적 미리보기·아이콘은 본체의 최종 원화를 기준으로 파생하고, UI 이름·비용·체력바·그림자·투사체·큰 효과는 분리한다.

## 기준 원화 제작 설명

> 현대 밀리터리와 일본 서브컬처를 결합한 횡스크롤 게임용 2D 캐릭터. 거대한 등·복부 감염낭과 낮게 버틴 두꺼운 다리. 모체형 변이체이며 작은 워커와 같은 몸으로 합성하지 않는다. 감염낭의 하중을 받쳐 넓게 서고 양팔을 전방 지지점처럼 둔다. 설정된 변이체·기계의 전체 실루엣과 주요 장비를 끝까지 포함한다. 오른쪽을 바라보는 측면 또는 약한 3/4 측면, 투명 배경, 한 이미지에 한 포즈. 위 팔레트를 따르고 이후 동작은 같은 얼굴·체형·복장·장비를 유지한다.

피할 요소: 소환수는 기존 eggGhost=워커 5기다. 본체 PNG에 워커들을 합성하거나 새 소환 적 ID를 만들지 않는다. 공통적으로 배경 풍경·UI 문자·워터마크·다른 전투 개체를 본체에 합성하지 않는다.
