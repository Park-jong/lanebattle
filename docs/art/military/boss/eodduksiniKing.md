## 외형·식별 기준

- 기준 외형: 감염체가 기계와 융합된 거대 공중 전투 병기
- 실루엣: 감염 조직과 항공 장갑이 융합된 거대 비행 병기. 넓은 추진부·붉은 센서·지상 지지 다리가 공중과 착지 모두에서 읽힌다.
- 무기·장비: 항공 동체·센서·포신·추진부·착지 지지 다리
- 팔레트 제안: 항공 회색 #616D79 / 먹청 #2B3745 / 감염 자주 #805E82 / 센서 적색 #D6655C
- 대표 자세: 공중에서는 지지 다리를 접고 수평을 유지한다. 착지 중에는 다리를 펼쳐 본체를 받친다.

아군은 약 7~8등신의 성인 전신 비율을 유지하고, 적은 인간형 원형 또는 명시된 변이·기계 비율을 따른다. SD·치비로 축약하지 않는다. 화면 식별은 큰 머리 대신 실루엣·장비·색 배치로 확보한다.

## 전투·강화·효과 연결

- 현재 기능 기준: 긴 사거리, 주기적 광역 공격
- 개별 주의점: 공중·착지의 캔버스와 중심 피벗을 통일한다. 착지 포즈의 바닥을 중심 기준점에 맞춘다. 호버의 일반 드론을 단순 확대하지 않는다.

| 항목 | 유지할 내용 |
| --- | --- |
| 약점 | 원거리 / 비행 공격자 |
| 저항·특수 대응 | 근접 |
| 패턴 | `descend`: 15초마다 강하·3초 지상 상태. 반경 120 피해 120 |

패턴 수치는 현재 기본 정의를 옮긴 참고값이다. 보스 출현·기지 잠금·보상은 기존 규칙을 사용한다. 여러 약점 조건이 동시에 맞아도 약점 배율을 다시 곱하지 않는다.

## 파일·캔버스·연결

- 본체 원본 캔버스 제안: **1536×1536px**, 투명 RGBA·sRGB.
- 기준점: **(0.5, 0.5)**. 모든 본체 동작의 캔버스·배율·피벗을 통일한다.
- 방향: 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면. 반전할 수 있게 읽을 수 있는 문자·계급 텍스트를 본체에 넣지 않는다.
- 원본 보관 예정: `output/art-generation/source-assets/boss/eodduksiniKing/military/`.
- 런타임 예정: `public/assets/characters/runtime/military/boss-eodduksiniKing.png`·`.json`.
- `skin.json`에 canvas·origin·bodyBounds·클립·fps·loop 및 필요 시 displayHeight·displayTop을 기록한다. 무기 여백을 충돌 크기로 쓰지 않는다.
- 정적 미리보기·아이콘은 본체의 최종 원화를 기준으로 파생하고, UI 이름·비용·체력바·그림자·투사체·큰 효과는 분리한다.

## 기준 원화 제작 설명

> 현대 밀리터리와 일본 서브컬처를 결합한 횡스크롤 게임용 2D 캐릭터. 감염 조직과 항공 장갑이 융합된 거대 비행 병기. 넓은 추진부·붉은 센서·지상 지지 다리가 공중과 착지 모두에서 읽힌다. 공중에서는 지지 다리를 접고 수평을 유지한다. 착지 중에는 다리를 펼쳐 본체를 받친다. 설정된 변이체·기계의 전체 실루엣과 주요 장비를 끝까지 포함한다. 오른쪽을 바라보는 측면 또는 약한 3/4 측면, 투명 배경, 한 이미지에 한 포즈. 위 팔레트를 따르고 이후 동작은 같은 얼굴·체형·복장·장비를 유지한다.

피할 요소: 공중·착지의 캔버스와 중심 피벗을 통일한다. 착지 포즈의 바닥을 중심 기준점에 맞춘다. 호버의 일반 드론을 단순 확대하지 않는다. 공통적으로 배경 풍경·UI 문자·워터마크·다른 전투 개체를 본체에 합성하지 않는다.
