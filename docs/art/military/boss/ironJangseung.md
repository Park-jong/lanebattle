## 외형·식별 기준

- 기준 외형: 중장갑과 신체 조직이 융합된 초대형 군인 좀비
- 실루엣: 군용 중장갑과 신체 조직이 융합된 초대형 군인. 네모난 어깨·흉갑·두꺼운 발목으로 일반 아머드보다 큰 위계를 만든다.
- 무기·장비: 융합 중장갑·잠금 장치·장갑 팔
- 팔레트 제안: 철회 #58646B / 먹색 #2D353B / 군용 녹색 #69735D / 경고 황색 #B8A45E
- 대표 자세: 두꺼운 장갑 팔을 낮게 둔 채 발을 넓게 벌린다. 몸통 중심은 흔들리지 않는다.

아군은 약 7~8등신의 성인 전신 비율을 유지하고, 적은 인간형 원형 또는 명시된 변이·기계 비율을 따른다. SD·치비로 축약하지 않는다. 화면 식별은 큰 머리 대신 실루엣·장비·색 배치로 확보한다.

## 전투·강화·효과 연결

- 현재 기능 기준: 시간이 지날수록 피해 감소 중첩, 원거리·특수 저항
- 개별 주의점: 장갑 누적은 현재 10초 주기·최대 6중첩 패턴을 따른다. 프레임마다 갑옷 개수가 임의로 늘지 않게 한다.

| 항목 | 유지할 내용 |
| --- | --- |
| 약점 | 근접 / 방어 파괴 |
| 저항·특수 대응 | 원거리 / 특수 |
| 패턴 | `armor`: 10초마다 피해 감소 8%p 중첩, 최대 6회 |

패턴 수치는 현재 기본 정의를 옮긴 참고값이다. 보스 출현·기지 잠금·보상은 기존 규칙을 사용한다. 여러 약점 조건이 동시에 맞아도 약점 배율을 다시 곱하지 않는다.

## 파일·캔버스·연결

- 본체 원본 캔버스 제안: **1536×1536px**, 투명 RGBA·sRGB.
- 기준점: **(0.5, 0.875)**. 모든 본체 동작의 캔버스·배율·피벗을 통일한다.
- 방향: 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면. 반전할 수 있게 읽을 수 있는 문자·계급 텍스트를 본체에 넣지 않는다.
- 원본 보관 예정: `output/art-generation/source-assets/boss/ironJangseung/military/`.
- 런타임 예정: `public/assets/characters/runtime/military/boss-ironJangseung.png`·`.json`.
- `skin.json`에 canvas·origin·bodyBounds·클립·fps·loop 및 필요 시 displayHeight·displayTop을 기록한다. 무기 여백을 충돌 크기로 쓰지 않는다.
- 정적 미리보기·아이콘은 본체의 최종 원화를 기준으로 파생하고, UI 이름·비용·체력바·그림자·투사체·큰 효과는 분리한다.

## 기준 원화 제작 설명

> 현대 밀리터리와 일본 서브컬처를 결합한 횡스크롤 게임용 2D 캐릭터. 군용 중장갑과 신체 조직이 융합된 초대형 군인. 네모난 어깨·흉갑·두꺼운 발목으로 일반 아머드보다 큰 위계를 만든다. 두꺼운 장갑 팔을 낮게 둔 채 발을 넓게 벌린다. 몸통 중심은 흔들리지 않는다. 설정된 변이체·기계의 전체 실루엣과 주요 장비를 끝까지 포함한다. 오른쪽을 바라보는 측면 또는 약한 3/4 측면, 투명 배경, 한 이미지에 한 포즈. 위 팔레트를 따르고 이후 동작은 같은 얼굴·체형·복장·장비를 유지한다.

피할 요소: 장갑 누적은 현재 10초 주기·최대 6중첩 패턴을 따른다. 프레임마다 갑옷 개수가 임의로 늘지 않게 한다. 공통적으로 배경 풍경·UI 문자·워터마크·다른 전투 개체를 본체에 합성하지 않는다.
