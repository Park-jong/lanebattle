## 외형·식별 기준

- 기준 외형: 산업시설에서 변이한 거대 감염체. 몸속 고열 코어와 용융 금속 장갑
- 실루엣: 몸속 주황 고열 코어, 용융 금속 장갑, 두꺼운 산업 장비 조각이 융합된 대형 변이체. 코어와 넓은 장갑 팔이 식별점.
- 무기·장비: 고열 코어·용융 금속 장갑·광역 타격 팔
- 팔레트 제안: 슬래그 #414347 / 철색 #6A6B65 / 코어 주황 #E89A4B / 고열 미색 #F0CD8B
- 대표 자세: 코어를 전방에 드러내고 장갑 팔을 낮게 둔 무거운 지상 자세.

아군은 약 7~8등신의 성인 전신 비율을 유지하고, 적은 인간형 원형 또는 명시된 변이·기계 비율을 따른다. SD·치비로 축약하지 않는다. 화면 식별은 큰 머리 대신 실루엣·장비·색 배치로 확보한다.

## 전투·강화·효과 연결

- 현재 기능 기준: 광역 피해·밀치기, 부적 충전 속도 감소, 화염 피해 시 회복
- 개별 주의점: 코어를 이유로 상시 피해 장판·새 화상·자폭을 추가하지 않는다. 불 면역만 있는 아이언클래드와 달리 불 피해 시 회복한다.

| 항목 | 유지할 내용 |
| --- | --- |
| 약점 | 기동 / 근접 |

패턴 수치는 현재 기본 정의를 옮긴 참고값이다. 보스 출현·기지 잠금·보상은 기존 규칙을 사용한다. 여러 약점 조건이 동시에 맞아도 약점 배율을 다시 곱하지 않는다.

## 기준 원화 제작 설명

> 현대 밀리터리와 일본 서브컬처를 결합한 횡스크롤 게임용 2D 캐릭터. 몸속 주황 고열 코어, 용융 금속 장갑, 두꺼운 산업 장비 조각이 융합된 대형 변이체. 코어와 넓은 장갑 팔이 식별점. 코어를 전방에 드러내고 장갑 팔을 낮게 둔 무거운 지상 자세. 설정된 변이체·기계의 전체 실루엣과 주요 장비를 끝까지 포함한다. 오른쪽을 바라보는 측면 또는 약한 3/4 측면, 투명 배경, 한 이미지에 한 포즈. 위 팔레트를 따르고 이후 동작은 같은 얼굴·체형·복장·장비를 유지한다.

피할 요소: 코어를 이유로 상시 피해 장판·새 화상·자폭을 추가하지 않는다. 불 면역만 있는 아이언클래드와 달리 불 피해 시 회복한다. 공통적으로 배경 풍경·UI 문자·워터마크·다른 전투 개체를 본체에 합성하지 않는다.
