## 외형·식별 기준

- 기준 외형: 청흑색 트윈테일, 흰색 크롭 제복 셔츠, 짧은 남색 재킷, 초미니 플리츠 스커트, 헤드셋, 전술 부츠. 장난기 많은 빈유 대공사수
- 실루엣: 청흑색 트윈테일·흰 크롭 셔츠·짧은 남색 재킷·헤드셋. 어깨에 받친 다연장 미사일 발사관으로 대공 병과를 구별한다.
- 무기·장비: 휴대용 다연장 대공 미사일 발사기, 자동 추적 조준경
- 팔레트 제안: 청흑 #243747 / 남색 #354F70 / 흰색 #EDF0EE / 조준광 #75C7D5
- 대표 자세: 미사일 발사기를 어깨에 받치고 두 발로 서서 전방 상공을 확인한다.

아군은 약 7~8등신의 성인 전신 비율을 유지하고, 적은 인간형 원형 또는 명시된 변이·기계 비율을 따른다. SD·치비로 축약하지 않는다. 화면 식별은 큰 머리 대신 실루엣·장비·색 배치로 확보한다.

## 전투·강화·효과 연결

- 현재 기능 기준: 비행. 비행 적에게 피해 x2
- 개별 주의점: 신규 컨셉은 지상이다. 현재 magpieFlock은 비행이므로 지상화 구현·회귀 검증 전 적용 완료로 표시하지 않는다. 복수 소환은 지상 대공사수 2명이며 드론으로 대체하지 않는다.
- 핵심 강화: 소환 시 같은 병과 2명
- 각성 강화: 비행 적에게 x2 -> x3, 맞은 비행 적 0.3초 경직

## 파일·캔버스·연결

- 본체 원본 캔버스 제안: **768×1024px**, 투명 RGBA·sRGB.
- 기준점: **(0.5, 0.875)**. 모든 본체 동작의 캔버스·배율·피벗을 통일한다.
- 방향: 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면. 반전할 수 있게 읽을 수 있는 문자·계급 텍스트를 본체에 넣지 않는다.
- 원본 보관 예정: `output/art-generation/source-assets/ally/magpieFlock/military/`.
- 런타임 예정: `public/assets/characters/runtime/military/ally-magpieFlock.png`·`.json`.
- `skin.json`에 canvas·origin·bodyBounds·클립·fps·loop 및 필요 시 displayHeight·displayTop을 기록한다. 무기 여백을 충돌 크기로 쓰지 않는다.
- 정적 미리보기·아이콘은 본체의 최종 원화를 기준으로 파생하고, UI 이름·비용·체력바·그림자·투사체·큰 효과는 분리한다.

## 기준 원화 제작 설명

> 현대 밀리터리와 일본 서브컬처를 결합한 횡스크롤 게임용 2D 캐릭터. 청흑색 트윈테일·흰 크롭 셔츠·짧은 남색 재킷·헤드셋. 어깨에 받친 다연장 미사일 발사관으로 대공 병과를 구별한다. 미사일 발사기를 어깨에 받치고 두 발로 서서 전방 상공을 확인한다. 성인 일반 등신의 전신과 주요 장비를 끝까지 포함한다. 오른쪽을 바라보는 측면 또는 약한 3/4 측면, 투명 배경, 한 이미지에 한 포즈. 위 팔레트를 따르고 이후 동작은 같은 얼굴·체형·복장·장비를 유지한다.

피할 요소: 신규 컨셉은 지상이다. 현재 magpieFlock은 비행이므로 지상화 구현·회귀 검증 전 적용 완료로 표시하지 않는다. 복수 소환은 지상 대공사수 2명이며 드론으로 대체하지 않는다. 공통적으로 배경 풍경·UI 문자·워터마크·다른 전투 개체를 본체에 합성하지 않는다.
