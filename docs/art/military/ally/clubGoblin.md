## 외형·식별 기준

- 기준 외형: 붉은 트윈테일, 흰색 반팔 제복 셔츠, 느슨한 넥타이, 초미니 플리츠 스커트, 오픈형 재킷, 니하이 부츠. 활발하고 호전적인 빈유 미소녀
- 실루엣: 붉은 트윈테일·흰 반팔 셔츠·느슨한 넥타이·열린 재킷, 오른손의 짧은 진압봉. 작지만 성인 비율의 가벼운 전열 병사.
- 무기·장비: 전기 충격 진압봉, 경량 방탄복
- 팔레트 제안: 적색 #C94E50 / 흰색 #EEF0EE / 남색 #29344D / 금속 #8795A4
- 대표 자세: 한쪽 무릎을 살짝 풀고 진압봉을 어깨보다 아래에 세운 자신만만한 경계 자세.

아군은 약 7~8등신의 성인 전신 비율을 유지하고, 적은 인간형 원형 또는 명시된 변이·기계 비율을 따른다. SD·치비로 축약하지 않는다. 화면 식별은 큰 머리 대신 실루엣·장비·색 배치로 확보한다.

## 전투·강화·효과 연결

- 현재 기능 기준: 없음
- 개별 주의점: AA·153cm·21세 유지. 진압봉에 상시 기절이나 방어 파괴를 추가하지 않는다. 같은 외형의 증원을 허용한다.
- 핵심 강화: 비용 -20%, 쿨타임 -30%
- 각성 강화: 적을 처치하면 10% 확률로 아카네 병과 1마리 추가 소환

가속·정지·공격 회수 후 머리카락·천·케이블이 서로 다른 지연으로 따라오고 감쇠한다. 고정 장비·총기·방패는 강체로 유지한다. 일시정지·결과 화면에서는 모든 움직임이 함께 멈춘다.

## 파일·캔버스·연결

- 본체 원본 캔버스 제안: **768×1024px**, 투명 RGBA·sRGB.
- 기준점: **(0.5, 0.875)**. 모든 본체 동작의 캔버스·배율·피벗을 통일한다.
- 방향: 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면. 반전할 수 있게 읽을 수 있는 문자·계급 텍스트를 본체에 넣지 않는다.
- 원본 보관 예정: `output/art-generation/source-assets/ally/clubGoblin/military/`.
- 런타임 예정: `public/assets/characters/runtime/military/ally-clubGoblin.png`·`.json`.
- `skin.json`에 canvas·origin·bodyBounds·클립·fps·loop 및 필요 시 displayHeight·displayTop을 기록한다. 무기 여백을 충돌 크기로 쓰지 않는다.
- 정적 미리보기·아이콘은 본체의 최종 원화를 기준으로 파생하고, UI 이름·비용·체력바·그림자·투사체·큰 효과는 분리한다.

고유 클립·효과는 파일만 추가해도 자동 재생되지 않는다. 일반 공격·투사체·상태 표시의 기존 연결점을 사용하고 필요한 호출·방향 전환·효과 좌표를 별도로 연결한다. 최초 투사체 연결은 종류별 대표 `projectile_*` 하나를 사용한다. 출처·도구·제작일·수정 이력도 함께 기록한다.

## 기준 원화 제작 설명

> 현대 밀리터리와 일본 서브컬처를 결합한 횡스크롤 게임용 2D 캐릭터. 붉은 트윈테일·흰 반팔 셔츠·느슨한 넥타이·열린 재킷, 오른손의 짧은 진압봉. 작지만 성인 비율의 가벼운 전열 병사. 한쪽 무릎을 살짝 풀고 진압봉을 어깨보다 아래에 세운 자신만만한 경계 자세. 성인 일반 등신의 전신과 주요 장비를 끝까지 포함한다. 오른쪽을 바라보는 측면 또는 약한 3/4 측면, 투명 배경, 한 이미지에 한 포즈. 위 팔레트를 따르고 이후 동작은 같은 얼굴·체형·복장·장비를 유지한다.

피할 요소: AA·153cm·21세 유지. 진압봉에 상시 기절이나 방어 파괴를 추가하지 않는다. 같은 외형의 증원을 허용한다. 공통적으로 배경 풍경·UI 문자·워터마크·다른 전투 개체를 본체에 합성하지 않는다.
