## 외형·식별 기준

- 기준 외형: 민트색 장발, 연보라색 눈, 흰색 제복 블라우스, 느슨한 넥타이, 남색 타이트 미니스커트, 짧은 연구원 코트. 차분하고 부드러운 거유 기술장교
- 실루엣: 민트색 장발·연보라 눈·흰 블라우스·느슨한 넥타이·남색 스커트·짧은 연구원 코트. 휴대 교란기와 왼손 통신 단말기.
- 무기·장비: 휴대용 전파 교란기, 전술 통신 단말기, 광역 EMP 발생기
- 팔레트 제안: 민트 #8CBFAE / 흰색 #EEF0EE / 남색 #35425C / 연보라 #B6A6D2
- 대표 자세: 단말기를 가슴 아래에 들고 다른 손으로 교란기 출력을 조절하는 차분한 지상 자세.

아군은 약 7~8등신의 성인 전신 비율을 유지하고, 적은 인간형 원형 또는 명시된 변이·기계 비율을 따른다. SD·치비로 축약하지 않는다. 화면 식별은 큰 머리 대신 실루엣·장비·색 배치로 확보한다.

## 전투·강화·효과 연결

- 현재 기능 기준: 오라: 반경 180 아군 이동·공격 속도 +15%, 적 투사체 25% 빗나감. 범위 반경 40
- 개별 주의점: 드론·공중 부유·물리 방패를 넣지 않는다. 내부 magic 판정 유지. 빗나감은 확률 효과이며 모든 투사체 차단이 아니다.
- 핵심 강화: 오라 +15% -> +25%
- 각성 강화: 빗나감 25% -> 50%, 빗나간 투사체는 적에게 되돌아감

## 파일·캔버스·연결

- 본체 원본 캔버스 제안: **768×1024px**, 투명 RGBA·sRGB.
- 기준점: **(0.5, 0.875)**. 모든 본체 동작의 캔버스·배율·피벗을 통일한다.
- 방향: 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면. 반전할 수 있게 읽을 수 있는 문자·계급 텍스트를 본체에 넣지 않는다.
- 원본 보관 예정: `output/art-generation/source-assets/ally/yeongdeungWind/military/`.
- 런타임 예정: `public/assets/characters/runtime/military/ally-yeongdeungWind.png`·`.json`.
- `skin.json`에 canvas·origin·bodyBounds·클립·fps·loop 및 필요 시 displayHeight·displayTop을 기록한다. 무기 여백을 충돌 크기로 쓰지 않는다.
- 정적 미리보기·아이콘은 본체의 최종 원화를 기준으로 파생하고, UI 이름·비용·체력바·그림자·투사체·큰 효과는 분리한다.

## 기준 원화 제작 설명

> 현대 밀리터리와 일본 서브컬처를 결합한 횡스크롤 게임용 2D 캐릭터. 민트색 장발·연보라 눈·흰 블라우스·느슨한 넥타이·남색 스커트·짧은 연구원 코트. 휴대 교란기와 왼손 통신 단말기. 단말기를 가슴 아래에 들고 다른 손으로 교란기 출력을 조절하는 차분한 지상 자세. 성인 일반 등신의 전신과 주요 장비를 끝까지 포함한다. 오른쪽을 바라보는 측면 또는 약한 3/4 측면, 투명 배경, 한 이미지에 한 포즈. 위 팔레트를 따르고 이후 동작은 같은 얼굴·체형·복장·장비를 유지한다.

피할 요소: 드론·공중 부유·물리 방패를 넣지 않는다. 내부 magic 판정 유지. 빗나감은 확률 효과이며 모든 투사체 차단이 아니다. 공통적으로 배경 풍경·UI 문자·워터마크·다른 전투 개체를 본체에 합성하지 않는다.
