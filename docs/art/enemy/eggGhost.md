# 달걀귀신 이미지 제작 명세

## 식별과 제작 범위

- 분류: 일반 적
- 대상 키: `enemy:eggGhost`
- 기본 스킨: `default`
- 코드 기준: `src/data/enemies.ts`
- 현재 게임의 기준 외형 영역: **20×28px**. 원화 해상도와 구별하며, 실제 충돌·사거리는 변경하지 않는다.
- 원본 PNG 캔버스: **256×320px**, 투명 RGBA, 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면.
- 예정 이미지 경로: `public/assets/characters/enemy/eggGhost/default/`

## 캐릭터 콘셉트

축제 음식을 기웃거리다 몰려드는 작고 말랑한 달걀 모양 잡귀. 얼굴이 없는 매끈한 면과 몸짓만으로 놀람과 장난기를 보여 주는 가장 단순한 적이다.

- 전투 역할과 읽혀야 할 특징: 수가 많은 기본 근접 적.
- 실루엣: 위가 좁고 아래가 둥근 달걀형 몸, 작은 먹빛 천 발 두 개, 짧은 팔 같은 옆 돌기.
- 얼굴과 성격: 기본은 눈·코·입 없는 매끈한 면. 표정은 고개와 몸 찌그러짐으로 표현한다.
- 의상·재질·소품: 차가운 미색의 얇은 보자기 같은 몸, 밑부분에 작은 보라빛 주름.
- 기본 팔레트: 미색 #E4E0D7 / 연보라 #B9B0CA / 먹보라 #554862 / 외곽 먹 #2E293B.
- 소형 화면에서 남길 요소: 얼굴 없는 달걀형 몸·두 작은 천 발

### 고유 동작·효과 파일

| 파일명 | 이미지와 사용 조건 |
| --- | --- |
| `fx_egg_puff_00.png / fx_egg_puff_01.png` | 128×128. 달걀형 몸을 닮은 둥근 보라 안개가 부풀었다 사라지는 퇴장 보조 효과. |

고유 클립은 공통 `AnimationState`에 아직 등록되지 않은 확장 제안이다. 구현 때 별도 클립 매핑과 실제 능력 이벤트를 연결한다. 효과 이미지는 몸체에 합성하지 않고 별도 에셋 키로 등록한다. 오라·파동 이미지는 현재 전투의 실제 범위에 맞춰 화면에서 크기를 정한다.

## 방향·기준점·동작 주의점

표정 제작을 위해 눈이나 입을 갑자기 넣지 않는다. 다른 귀신보다 낮고 짧은 보폭을 사용한다. 대량 등장 시 개체별 애니메이션 시작 시점을 달리하되 프레임 그림은 공유한다.

공격 프레임의 “준비 → 타격/발사 → 회수”는 자세 제작 순서다. 현재 즉시 판정을 유지하는 첫 구현에서는 실제 판정 순간에 타격/발사 자세를 맞추고 앞 준비 프레임은 생략하거나 별도 예고에 사용한다. 피해를 주기 위해 애니메이션 종료를 기다리지 않는다.

추가 스킨의 파일명·클립 구성은 기본 스킨과 맞추고, 경로의 `default/`를 해당 스킨 ID로 바꾼다. 능력·속도·비행 여부·판정은 스킨 때문에 바꾸지 않는다.

## 제작용 설명문

> 한국 민담을 재해석한 요괴 마을 축제 게임용 2D 캐릭터. 둥근 카툰 형태, 굵고 일정한 먹색 외곽선, 단순한 면 채색과 약한 한지 느낌. 눈 코 입이 없는 매끈한 미색 달걀 모양의 작고 말랑한 귀신, 아래쪽에 보라색 천 주름과 두 작은 천 발, 몸짓이 익살스럽다. 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면, 투명 배경, 캐릭터 전체와 소품이 캔버스 안에 들어온다. 한 장에는 한 포즈만 그린다. 프레임 변형 시 확정된 기준 원화의 체형·얼굴·색·소품을 유지한다.

피할 요소: 현실적인 달걀 껍데기 파손, 눈·입을 추가해 얼굴을 만드는 것, 유혈. 공통 제외 사항은 사실적인 공포·유혈, 화면을 가리는 광원, 배경 풍경, 글자·워터마크, 다른 캐릭터 혼입이다.

## 검수 기준

- [ ] 콘셉트·실루엣·기본 팔레트가 확정된 기준 원화와 일치한다.
- [ ] 작은 게임 표시 크기에서 위의 식별 요소가 남는다.
- [ ] 프레임 간 크기·기준점·소품 개수와 위치가 의도 없이 달라지지 않는다.
- [ ] 좌우 반전해도 문양·소품·실루엣이 깨지지 않는다.
- [ ] 알파 배경에 흰 테두리나 잘린 무기·꼬리·날개가 없다.
- [ ] 파일명·해상도·색상 프로필과 출처·사용 조건 기록을 확인했다.
