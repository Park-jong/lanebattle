## 식별과 제작 범위

- 분류: 일반 적
- 대상 키: `enemy:dueoksini`
- 기본 스킨: `default`
- 코드 기준: `src/data/enemies.ts`
- 현재 게임의 기준 외형 영역: **32×48px**. 원화 해상도와 구별하며, 실제 충돌·사거리는 변경하지 않는다.
- 원본 PNG 캔버스: **320×384px**, 투명 RGBA, 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면.
- 예정 이미지 경로: `public/assets/characters/enemy/dueoksini/default/`

## 캐릭터 콘셉트

축제 문짝을 밀고 들어오려는 고집 센 큰머리 요괴. 작은 다리에 비해 큰 이마와 넓은 어깨로 기지 돌파 역할을 읽게 한다.

- 전투 역할과 읽혀야 할 특징: 아군 전열을 지나 서낭당으로 직진하는 기지 공격 적.
- 실루엣: 사각에 가까운 큰 둥근 머리, 낮은 목, 넓은 어깨, 짧은 팔과 굵은 발.
- 얼굴과 성격: 짙게 모인 눈썹, 볼을 빵빵하게 부풀린 고집 센 표정.
- 의상·재질·소품: 먹보라 피부, 낡은 자주색 짧은 조끼, 이마에 미색 천 띠, 작은 허리 매듭.
- 기본 팔레트: 먹보라 #67536F / 자주 #956982 / 미색 #D7C9BC / 황토 #A48A65 / 먹 #30293A.
- 소형 화면에서 남길 요소: 큰 이마·짧은 목·미색 이마띠

### 고유 동작·효과 파일

| 파일명 | 이미지와 사용 조건 |
| --- | --- |
| `fx_gate_bump_00.png / fx_gate_bump_01.png` | 256×128. 기지와 닿는 방향으로 짧은 미색 충격선과 보라 먼지. 건물 파괴 그림이나 추가 광역 공격 범위는 포함하지 않는다. |

고유 클립은 공통 `AnimationState`에 아직 등록되지 않은 확장 제안이다. 구현 때 별도 클립 매핑과 실제 능력 이벤트를 연결한다. 효과 이미지는 몸체에 합성하지 않고 별도 에셋 키로 등록한다. 오라·파동 이미지는 현재 전투의 실제 범위에 맞춰 화면에서 크기를 정한다.

## 방향·기준점·동작 주의점

일반 유닛 곁을 지나갈 때 공격 포즈를 재생하지 않는다. 실제 기지 타격 때만 attack을 사용하고, 이동 중 고개 숙임이 넉백 방향을 뒤집지 않게 한다.

공격 프레임의 “준비 → 타격/발사 → 회수”는 자세 제작 순서다. 현재 즉시 판정을 유지하는 첫 구현에서는 실제 판정 순간에 타격/발사 자세를 맞추고 앞 준비 프레임은 생략하거나 별도 예고에 사용한다. 피해를 주기 위해 애니메이션 종료를 기다리지 않는다.

추가 스킨의 파일명·클립 구성은 기본 스킨과 맞추고, 경로의 `default/`를 해당 스킨 ID로 바꾼다. 능력·속도·비행 여부·판정은 스킨 때문에 바꾸지 않는다.

## 제작용 설명문

> 한국 민담을 재해석한 요괴 마을 축제 게임용 2D 캐릭터. 둥근 카툰 형태, 굵고 일정한 먹색 외곽선, 단순한 면 채색과 약한 한지 느낌. 큰 둥근 사각 머리와 아주 짧은 목을 가진 고집 센 두억시니, 먹보라 피부와 자주색 조끼, 미색 이마띠, 볼을 부풀리고 앞을 향해 걷는 모습. 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면, 투명 배경, 캐릭터 전체와 소품이 캔버스 안에 들어온다. 한 장에는 한 포즈만 그린다. 프레임 변형 시 확정된 기준 원화의 체형·얼굴·색·소품을 유지한다.

피할 요소: 현실적인 머리 부상, 손에 거대한 무기를 쥔 전사, 다른 적에게 자동 공격하는 장면. 공통 제외 사항은 사실적인 공포·유혈, 화면을 가리는 광원, 배경 풍경, 글자·워터마크, 다른 캐릭터 혼입이다.
