## 식별과 제작 범위

- 분류: 일반 적
- 대상 키: `enemy:gangcheol`
- 기본 스킨: `default`
- 코드 기준: `src/data/enemies.ts`
- 현재 게임의 기준 외형 영역: **34×44px**. 원화 해상도와 구별하며, 실제 충돌·사거리는 변경하지 않는다.
- 원본 PNG 캔버스: **320×384px**, 투명 RGBA, 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면.
- 예정 이미지 경로: `public/assets/characters/enemy/gangcheol/default/`

## 캐릭터 콘셉트

작은 가마처럼 뜨거운 쇠비늘을 두른 땅의 요괴. 불이 닿아도 겁내지 않는 갑옷형 근접 적으로, 보스 이무기 강철이보다 짧고 땅딸막하게 만든다.

- 전투 역할과 읽혀야 할 특징: 갑옷 특성과 불 피해·화상 면역.
- 실루엣: 둥근 도마뱀형 머리, 짧은 굵은 몸통과 다리, 지붕 기와 같은 등비늘, 짧은 꼬리.
- 얼굴과 성격: 반쯤 감긴 느긋한 눈과 작은 콧김 구멍.
- 의상·재질·소품: 먹회색 쇠비늘, 보라색 틈, 희미한 주황색 열기 선. 빛나는 용암 덩어리로 만들지 않는다.
- 기본 팔레트: 쇠 먹 #55515C / 회보라 #85768C / 열 주황 #C28A57 / 미색 #C3B8AC.
- 소형 화면에서 남길 요소: 짧고 굵은 쇠비늘 몸·짧은 꼬리·기와 등판

### 고유 동작·효과 파일

| 파일명 | 이미지와 사용 조건 |
| --- | --- |
| `fx_fire_immune_00.png / fx_fire_immune_01.png` | 128×128. 작은 붉은 불씨가 비늘 앞에서 미색 연기로 꺼짐. 불 공격 면역의 시각 반응이며 회복 숫자·녹색 빛은 넣지 않는다. |

고유 클립은 공통 `AnimationState`에 아직 등록되지 않은 확장 제안이다. 구현 때 별도 클립 매핑과 실제 능력 이벤트를 연결한다. 효과 이미지는 몸체에 합성하지 않고 별도 에셋 키로 등록한다. 오라·파동 이미지는 현재 전투의 실제 범위에 맞춰 화면에서 크기를 정한다.

## 방향·기준점·동작 주의점

면역은 불에 한정되므로 모든 공격을 튕기는 갑옷 효과를 항상 켜지 않는다. 보스처럼 길게 말린 뱀 몸이나 큰 뿔을 넣지 않는다. 보통 피해에는 정상 hit 포즈를 적용한다.

공격 프레임의 “준비 → 타격/발사 → 회수”는 자세 제작 순서다. 현재 즉시 판정을 유지하는 첫 구현에서는 실제 판정 순간에 타격/발사 자세를 맞추고 앞 준비 프레임은 생략하거나 별도 예고에 사용한다. 피해를 주기 위해 애니메이션 종료를 기다리지 않는다.

## 추가 스킨 콘셉트

| 스킨 ID 제안 | 이름 | 기본 외형에서 바꿀 부분 | 유지할 특징 |
| --- | --- | --- | --- |
| `kilnTile` | 기왓가마 강철이 | 청회 기와 비늘과 황토 틈새, 짧은 등판 매듭 추가 | 짧고 굵은 쇠비늘 몸·짧은 꼬리·기와 등판 |

추가 스킨의 파일명·클립 구성은 기본 스킨과 맞추고, 경로의 `default/`를 해당 스킨 ID로 바꾼다. 능력·속도·비행 여부·판정은 스킨 때문에 바꾸지 않는다.

## 제작용 설명문

> 한국 민담을 재해석한 요괴 마을 축제 게임용 2D 캐릭터. 둥근 카툰 형태, 굵고 일정한 먹색 외곽선, 단순한 면 채색과 약한 한지 느낌. 짧고 땅딸막한 귀여운 쇠비늘 요괴 강철이, 둥근 도마뱀 머리, 기와처럼 겹친 먹회색 등판, 짧은 굵은 다리와 짧은 꼬리, 느긋한 눈. 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면, 투명 배경, 캐릭터 전체와 소품이 캔버스 안에 들어온다. 한 장에는 한 포즈만 그린다. 프레임 변형 시 확정된 기준 원화의 체형·얼굴·색·소품을 유지한다.

피할 요소: 모든 피해 면역처럼 보이는 영구 보호막, 회복 연출, 거대한 뱀 몸. 공통 제외 사항은 사실적인 공포·유혈, 화면을 가리는 광원, 배경 풍경, 글자·워터마크, 다른 캐릭터 혼입이다.
