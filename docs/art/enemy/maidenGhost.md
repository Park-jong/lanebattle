## 식별과 제작 범위

- 분류: 일반 적
- 대상 키: `enemy:maidenGhost`
- 기본 스킨: `default`
- 코드 기준: `src/data/enemies.ts`
- 현재 게임의 기준 외형 영역: **22×38px**. 원화 해상도와 구별하며, 실제 충돌·사거리는 변경하지 않는다.
- 원본 PNG 캔버스: **256×320px**, 투명 RGBA, 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면.
- 예정 이미지 경로: `public/assets/characters/enemy/maidenGhost/default/`

## 캐릭터 콘셉트

흰 옷자락을 살짝 끌며 빠르게 새치기하는 축제의 장난꾸러기 귀신. 손각시와 달리 긴 생머리와 세로로 긴 실루엣, 맨손의 가까운 공격이 핵심이다.

- 전투 역할과 읽혀야 할 특징: 근접 전열을 지나 원거리·마법 아군을 먼저 노리는 빠른 근접 적.
- 실루엣: 길고 단순한 검은 머리, 흰 긴 저고리와 치마, 앞으로 뻗는 가는 소매.
- 얼굴과 성격: 머리 사이로 보이는 둥근 눈 두 개와 삐죽한 입. 위협보다 짓궂은 인상.
- 의상·재질·소품: 미색 천과 먹빛 긴 머리, 보라색 허리끈 하나. 얼굴이 가려져도 작은 눈은 남긴다.
- 기본 팔레트: 미색 #EAE6DB / 머리 먹 #35303F / 연보라 #B8A8C6 / 허리 보라 #77608E.
- 소형 화면에서 남길 요소: 긴 생머리·세로로 긴 흰옷·빈손

### 고유 동작·효과 파일

| 파일명 | 이미지와 사용 조건 |
| --- | --- |
| `fx_phase_00.png / fx_phase_01.png` | 128×256. 세로로 흐르는 옅은 보라색 천 잔상. 전열 통과의 시각 보조로만 사용하며 영구 무적·투명화로 오해되지 않게 낮은 강도로 표시. |

고유 클립은 공통 `AnimationState`에 아직 등록되지 않은 확장 제안이다. 구현 때 별도 클립 매핑과 실제 능력 이벤트를 연결한다. 효과 이미지는 몸체에 합성하지 않고 별도 에셋 키로 등록한다. 오라·파동 이미지는 현재 전투의 실제 범위에 맞춰 화면에서 크기를 정한다.

## 방향·기준점·동작 주의점

지상 근접 적이므로 높은 비행 고도나 날개를 넣지 않는다. 통과 중에도 얼굴과 윤곽을 식별할 정도로 남긴다. 손각시의 면사포·부적·원거리 발사 포즈와 구별한다.

공격 프레임의 “준비 → 타격/발사 → 회수”는 자세 제작 순서다. 현재 즉시 판정을 유지하는 첫 구현에서는 실제 판정 순간에 타격/발사 자세를 맞추고 앞 준비 프레임은 생략하거나 별도 예고에 사용한다. 피해를 주기 위해 애니메이션 종료를 기다리지 않는다.

추가 스킨의 파일명·클립 구성은 기본 스킨과 맞추고, 경로의 `default/`를 해당 스킨 ID로 바꾼다. 능력·속도·비행 여부·판정은 스킨 때문에 바꾸지 않는다.

## 제작용 설명문

> 한국 민담을 재해석한 요괴 마을 축제 게임용 2D 캐릭터. 둥근 카툰 형태, 굵고 일정한 먹색 외곽선, 단순한 면 채색과 약한 한지 느낌. 긴 먹빛 생머리와 미색 긴 한복을 입은 장난꾸러기 처녀귀신, 머리 사이로 보이는 둥근 눈, 보라 허리끈, 빈손으로 소매를 뻗는 귀여운 모습. 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면, 투명 배경, 캐릭터 전체와 소품이 캔버스 안에 들어온다. 한 장에는 한 포즈만 그린다. 프레임 변형 시 확정된 기준 원화의 체형·얼굴·색·소품을 유지한다.

피할 요소: 피 묻은 소복, 사실적인 공포 얼굴, 손각시와 같은 부적 투척 소품. 공통 제외 사항은 사실적인 공포·유혈, 화면을 가리는 광원, 배경 풍경, 글자·워터마크, 다른 캐릭터 혼입이다.
