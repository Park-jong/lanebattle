## 캐릭터 콘셉트

촬영 감각이 뛰어난 패션 셀럽. 라일락색 기관단총과 총기 옆 작은 촬영 보조광으로 패션과 원거리 역할을 함께 보여 준다.

- 외모·체형: 7.5등신의 균형 있는 성인 체형, 중간 가슴, 깔끔한 자세
- 얼굴·머리: 헤이즐 눈, 세련된 코랄 메이크업, 한쪽 귀 뒤로 넘긴 애쉬핑크 롱웨이브, 작은 진주 귀걸이
- 의상·재질: 아이보리 크롭 블레이저, 불투명 라일락 탑, 와이드 팬츠, 낮은 굽의 앵클부츠, 작은 크로스백
- 무기·대표 소품: 라일락·백색 소형 기관단총 1정, 총기 옆 소형 원형 보조광 1개. 휴대폰은 본체에 별도 추가하지 않음
- 기본 팔레트: 애쉬핑크 `#BC8E9C` / 아이보리 `#F0E7DF` / 라일락 `#B09ACD` / 코랄 `#DD9A96`
- 실루엣과 축소 식별점: 애쉬핑크 긴 머리·아이보리 재킷·라일락 기관단총과 원형 보조광이 원거리 역할을 드러낸다.
- 표정 세트: 촬영용 미소 / 렌즈 너머 집중 / 깜짝 놀람 / 자신만만

## 기준 포즈와 방향

오른쪽 3/4 전신, 양손으로 소형 기관단총을 낮게 지지하고 얼굴·총구·개머리판을 드러냄

원본은 오른쪽을 보는 약한 3/4 측면이며, 머리부터 발끝·주요 소품까지 캔버스 안에 넣는다. 이동·공격 방향에 맞춰 외형만 반전한다. 체력바·이름·숫자는 반전하지 않는다.

- 기준점: 발바닥 중앙 (0.5, 0.90). 발·신발·바퀴의 접지 위치를 모든 동작에서 맞춘다.
- 얼굴과 몸은 정상적인 성인 비율로 그리고, 기계·장비는 해당 설계 비율을 유지한다.
- 그림자·체력바·문자·투사체·넓은 오라는 본체와 분리한다.
- 손·무기 끝·장비 배출구를 효과 부착점으로 기록한다. 그림의 바깥 여백은 충돌 영역이 아니다.

## 동작별 연기

| 동작 | 자세와 움직임 |
| --- | --- |
| `idle` | 기관단총을 낮게 유지하며 전방 응시. 보조광은 작은 점등 |
| `walk` | 왼발 전진 → 통과 → 오른발 전진 → 통과. 총기와 양손 연결 유지 |
| `attack` | 기관단총 전방 조준 → 빛탄 발사 → 작은 반동 → 준비 자세 |
| `hit` | 기관단총을 양손으로 잡은 채 어깨가 움찔 |
| `spawn` | 라운지에서 나와 기관단총 보조광을 켜고 전방 확인 |
| `exit` | 보조광을 끄고 기관단총을 양손에 유지하며 후퇴 |
| fx_lightshot | 소형 총구에서 라일락·백색 빛탄 |
| fx_afterglow | 실제 지속 피해 대상의 코랄 잔광 |

준비 → 타격·발사 → 회수는 제작상의 자세 순서다. 실제 공격·능력 이벤트에 타격 자세를 맞추고, 애니메이션을 기다리느라 기존 판정을 늦추지 않는다. 문서의 고유 동작·효과가 새 전투 기능을 추가한다는 뜻은 아니다.

### 모든 스킨의 납품 규칙

- 이 목록은 `default`와 같은 캐릭터의 모든 추가 의상 스킨에 적용한다. 스킨마다 자체 프레임 묶음을 제작한다.
- 이동 클립의 파일명은 비행·롤러도 `walk_00.png ~ walk_03.png`를 사용한다. 실제 자세는 아래 전용 포즈를 따른다.
- `exit` 연기의 납품 파일명은 기존 기본 스킨과 같은 `death_00.png ~ death_03.png`다. 다른 동작을 임의로 `fly_`·`exit_`로 중복 납품하지 않는다.
- `reference.png`는 승인된 `idle_00.png`의 복사·별칭이다. 공통 본체 19컷에 한 컷을 더하지 않는다.
- 공통 19컷과 고유 전신 컷은 같은 캔버스·배율·피벗·방향을 유지한다. 효과·상반신 컷인은 별도 규격이다.
- `death_03.png`는 같은 크기의 완전 투명 파일로 내보낸다. 다른 퇴장 컷은 본체와 장비가 함께 사라지게 한다.
- 여성의 `bust_idle_00.png ~ bust_idle_03.png`도 동일한 전신 캔버스를 사용한다. 전투 대기 보조 클립과 선택 화면의 상반신 크롭에 재사용한다.
- 리깅을 사용해도 최종 납품은 아래 동작별 PNG와 프레임 목록이다. 리깅 데이터·파츠는 제작 보조 자료로 둔다.

## 리깅과 보조 모션

- 권장 파츠: 얼굴·눈·입·롱웨이브·귀걸이, 몸통·가슴과 탑·골반·블레이저·팔다리·손·부츠·가방, 기관단총·보조광
- 보조 모션: 탑과 블레이저의 지지력 안에서 가슴·머리·가방이 완만하게 후행한다. 조준 손과 총기의 연결을 유지한다.
- 일시정지 시 본체와 보조 모션을 함께 멈춘다. 재등장·부활 시 흔들림 상태를 초기화한다.
- 연속 피격과 방향 전환에서 진폭을 제한한다. 파츠가 팔·몸통·의상을 뚫지 않도록 회전·변형 범위를 둔다.
- 필수 프레임은 기준 원화를 참조해 동일 얼굴·소품·비율을 유지한다. 낱장 이미지 하나가 자동으로 파츠·물리 리깅이 되는 것은 아니다.
