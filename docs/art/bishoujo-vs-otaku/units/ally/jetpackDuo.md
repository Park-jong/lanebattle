## 캐릭터 콘셉트

자매인 성인 배달 라이더 둘이 소형 제트팩으로 한 편대를 이룬다. 별개의 여성 둘이 보이지만 전투 시스템에서는 하나의 유닛이다.

- 외모·체형: 두 명 모두 7~7.5등신의 날렵한 성인 체형, 작은~중간 가슴. 앞사람이 조금 높고 뒤사람은 아래쪽에 배치
- 얼굴·머리: 앞사람은 검정 단발·청색 눈, 뒤사람은 은회색 짧은 포니테일·짙은 회색 눈. 공통 청색 바이저를 이마 위에 착용
- 의상·재질: 검정·백색 스트리트 라이더 재킷과 긴 기능성 바지, 장갑과 부츠. 각자 작은 청색 백팩형 추진 장비
- 무기·대표 소품: 각 인물의 제트팩 1개씩 총 2개, 각 인물 오른손의 흑백 권총 1정씩 총 2정
- 기본 팔레트: 검정 `#242A34` / 백색 `#E8EDF1` / 청색 `#5DACE1` / 은회색 `#B4C0C9`
- 실루엣과 축소 식별점: 상하 대각선의 여성 두 명·흑백 라이더 재킷·청색 제트팩 두 개로 편대를 구분한다.
- 표정 세트: 둘의 자신만만한 미소 / 앞사람 집중·뒤사람 경계 / 둘의 놀람 / 둘의 승리 미소

## 기준 포즈와 방향

오른쪽을 보는 두 성인 여성의 전신 편대. 앞사람 오른쪽 위·뒤사람 왼쪽 아래, 두 사람 모두 오른손 권총을 전방 아래에 들고 빈손으로 균형

원본은 오른쪽을 보는 약한 3/4 측면이며, 머리부터 발끝·주요 소품까지 캔버스 안에 넣는다. 이동·공격 방향에 맞춰 외형만 반전한다. 체력바·이름·숫자는 반전하지 않는다.

- 기준점: 공중 중심 (0.5, 0.5). 고도는 화면 계층에서 적용한다. 착지 시에도 동일 피벗을 유지한다.
- 얼굴과 몸은 정상적인 성인 비율로 그리고, 기계·장비는 해당 설계 비율을 유지한다.
- 그림자·체력바·문자·투사체·넓은 오라는 본체와 분리한다.
- 손·무기 끝·장비 배출구를 효과 부착점으로 기록한다. 그림의 바깥 여백은 충돌 영역이 아니다.

## 동작별 연기

| 동작 | 자세와 움직임 |
| --- | --- |
| `idle` | 두 사람이 작은 폭으로 부유하며 고도 간격을 유지 |
| `walk` (비행) | 한 편대가 같은 속도로 수평 이동하고 각 인물의 무릎과 추진 장비가 작게 기울어짐 |
| `attack` | 두 사람이 권총을 전방으로 정렬 → 실제 한 유닛 공격 이벤트에 빛탄 발사 연출 → 반동 → 회수. 두 명 때문에 피해를 두 배로 추가하지 않음 |
| `hit` | 두 사람이 잠깐 서로 다른 각도로 기울었다 편대 위치 복귀. 실제로 두 개체로 분리하지 않음 |
| `spawn` | 두 사람이 라운지 쪽에서 같은 편대로 떠올라 진입 |
| `exit` | 추진 방향을 아군 쪽으로 돌려 같은 편대로 퇴장 |
| fx_intercept | 실제 공격 때의 작은 청백색 요격 광선. 발사 수로 추가 피해를 암시하지 않음 |

준비 → 타격·발사 → 회수는 제작상의 자세 순서다. 실제 공격·능력 이벤트에 타격 자세를 맞추고, 애니메이션을 기다리느라 기존 판정을 늦추지 않는다. 문서의 고유 동작·효과가 새 전투 기능을 추가한다는 뜻은 아니다.

### 모든 스킨의 납품 규칙

- 이 목록은 `default`와 같은 캐릭터의 모든 추가 의상 스킨에 적용한다. 스킨마다 자체 프레임 묶음을 제작한다.
- 이동 클립의 파일명은 비행·롤러도 `walk_00.png ~ walk_03.png`를 사용한다. 실제 자세는 아래 전용 포즈를 따른다.
- `exit` 연기의 납품 파일명은 기존 기본 스킨과 같은 `death_00.png ~ death_03.png`다. 다른 동작을 임의로 `fly_`·`exit_`로 중복 납품하지 않는다.
- `reference.png`는 승인된 `idle_00.png`의 복사·별칭이다. 공통 본체 19컷에 한 컷을 더하지 않는다.
- 공통 19컷과 고유 전신 컷은 같은 캔버스·배율·피벗·방향을 유지한다. 효과·상반신 컷인은 별도 규격이다.
- `death_03.png`는 같은 크기의 완전 투명 파일로 내보낸다. 다른 퇴장 컷은 본체와 장비가 함께 사라지게 한다.
- 여성의 `bust_idle_00.png ~ bust_idle_03.png`도 동일한 전신 캔버스를 사용한다. 전투 대기 보조 클립과 선택 화면의 상반신 크롭에 재사용한다.
- 리깅을 사용해도 최종 납품은 아래 동작별 PNG와 프레임 목록이다. 리깅 데이터·파츠는 제작 보조 자료로 둔다.

## 리깅과 보조 모션

- 권장 파츠: 두 인물 각각의 얼굴·눈·입·머리·바이저, 몸통·가슴과 기능성 의상 보정·골반, 팔다리·장갑·부츠·재킷, 제트팩·권총. 각 인물별 하위 리그
- 보조 모션: 가슴은 지지된 기능성 의상에 맞춰 작게 움직인다. 짧은 머리·재킷 끝의 후행과 두 명 사이의 부유 위상 차이를 둔다.
- 일시정지 시 본체와 보조 모션을 함께 멈춘다. 재등장·부활 시 흔들림 상태를 초기화한다.
- 연속 피격과 방향 전환에서 진폭을 제한한다. 파츠가 팔·몸통·의상을 뚫지 않도록 회전·변형 범위를 둔다.
- 필수 프레임은 기준 원화를 참조해 동일 얼굴·소품·비율을 유지한다. 낱장 이미지 하나가 자동으로 파츠·물리 리깅이 되는 것은 아니다.

## 반드시 유지할 특징

- 정확히 두 명의 성인 여성과 두 사람의 전신을 유지한다.
- 앞사람 검정 단발·뒤사람 은회색 포니테일을 유지한다.
- 제트팩 총 2개·오른손 권총 총 2정이며 한 전투 유닛이다.

## 피할 요소와 검수

캐릭터별 제외 사항: 합쳐진 몸, 세 번째 사람, 무인 드론, 아동 자매, 추가 총·손목 발사기

- [ ] 기준 원화와 얼굴·체형·색·소품 수가 일치한다.
- [ ] 상하 대각선의 여성 두 명·흑백 라이더 재킷·청색 제트팩 두 개로 편대를 구분한다.
- [ ] 오른쪽 원본과 왼쪽 반전에서 발·장비 기준점이 유지된다.
- [ ] 손·팔·가슴·의상·장비가 부자연스럽게 겹치거나 관통하지 않는다.
- [ ] 기본 포즈와 공격·피격 사이에 키와 카메라 배율이 달라지지 않는다.
- [ ] 투명 배경, 잘린 소품, 알파 테두리, 문자가 섞이지 않았는지 확인한다.
- [ ] 공통 가이드의 전장 표시 크기에서 얼굴·역할이 구분된다.
- [ ] 제작 출처·이용 조건·참조 원화·수정 이력을 기록한다.
