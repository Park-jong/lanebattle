## 캐릭터 콘셉트

호탕하고 든든한 운동계 언니. 단단한 다리와 넓게 벌린 두 손으로 적을 붙잡아 전선을 되민다.

- 외모·체형: 7.5등신, 넓은 어깨·선명한 팔 근육·튼튼한 허벅지, 중간 가슴의 건강한 성인 운동 체형
- 얼굴·머리: 검은 눈, 짧은 짙은 갈색 포니테일, 넓은 미소, 흰색 스포츠 헤어밴드
- 의상·재질: 버건디색 지지력 있는 스포츠 탑, 검정 트레이닝 팬츠, 발목이 고정되는 트레이닝 슈즈, 손목 보호대
- 무기·대표 소품: 양손의 손가락이 열리는 강화 전투 건틀릿 1쌍. 잡기 가능한 구조, 허리 뒤 짧은 수건
- 기본 팔레트: 버건디 `#9B3D53` / 차콜 `#2D3038` / 갈색 머리 `#49352D` / 아이보리 `#EFE9DA`
- 실루엣과 축소 식별점: 넓은 어깨·버건디 탑·두 손의 잡기 자세가 다른 근접 캐릭터와 구분된다.
- 표정 세트: 호탕한 웃음 / 격려 / 진지한 집중 / 놀람

## 기준 포즈와 방향

발 간격을 넓힌 낮은 중심 자세, 오른쪽을 보며 양 손바닥을 앞에 펼친다. 팔과 손이 얼굴을 가리지 않음

원본은 오른쪽을 보는 약한 3/4 측면이며, 머리부터 발끝·주요 소품까지 캔버스 안에 넣는다. 이동·공격 방향에 맞춰 외형만 반전한다. 체력바·이름·숫자는 반전하지 않는다.

- 기준점: 발바닥 중앙 (0.5, 0.90). 발·신발·바퀴의 접지 위치를 모든 동작에서 맞춘다.
- 얼굴과 몸은 정상적인 성인 비율로 그리고, 기계·장비는 해당 설계 비율을 유지한다.
- 그림자·체력바·문자·투사체·넓은 오라는 본체와 분리한다.
- 손·무기 끝·장비 배출구를 효과 부착점으로 기록한다. 그림의 바깥 여백은 충돌 영역이 아니다.

## 동작별 연기

| 동작 | 자세와 움직임 |
| --- | --- |
| `idle` | 무릎을 풀고 양손을 짧게 털며 호흡 |
| `walk` | 발 간격을 유지한 왼발 전진 → 체중 이동 → 오른발 전진 → 자세 회복 |
| `attack` | 건틀릿을 낀 손으로 전방을 짧게 밀어쳐 타격. 메치기는 실제 세 번째 공격 때만 사용 |
| `hit` | 몸통에 힘을 주고 뒤로 짧게 기울었다 복귀 |
| `spawn` | 손목 보호대를 정리하며 힘차게 전장 진입 |
| `exit` | 양손을 들어 후퇴 신호를 보내고 아군 방향으로 이동 |
| throw | 실제 세 번째 공격의 메치기 이벤트에만 잡기 → 허리 회전 → 전방 밀어내기 |

준비 → 타격·발사 → 회수는 제작상의 자세 순서다. 실제 공격·능력 이벤트에 타격 자세를 맞추고, 애니메이션을 기다리느라 기존 판정을 늦추지 않는다. 문서의 고유 동작·효과가 새 전투 기능을 추가한다는 뜻은 아니다.

### 모든 스킨의 납품 규칙

- 이 목록은 `default`와 같은 캐릭터의 모든 추가 의상 스킨에 적용한다. 스킨마다 자체 프레임 묶음을 제작한다.
- 이동 클립의 파일명은 비행·롤러도 `walk_00.png ~ walk_03.png`를 사용한다. 실제 자세는 아래 전용 포즈를 따른다.
- `exit` 연기의 납품 파일명은 기존 기본 스킨과 같은 `death_00.png ~ death_03.png`다. 다른 동작을 임의로 `fly_`·`exit_`로 중복 납품하지 않는다.
- `reference.png`는 승인된 `idle_00.png`의 복사·별칭이다. 공통 본체 19컷에 한 컷을 더하지 않는다.
- 공통 19컷과 고유 전신 컷은 같은 캔버스·배율·피벗·방향을 유지한다. 효과·상반신 컷인은 별도 규격이다.
- `death_03.png`는 같은 크기의 완전 투명 파일로 내보낸다. 다른 퇴장 컷은 본체와 장비가 함께 사라지게 한다.
- 여성의 `bust_idle_00.png ~ bust_idle_03.png`도 동일한 전신 캔버스를 사용한다. 전투 대기 보조 클립과 선택 화면의 상반신 크롭에 재사용한다.
- 리깅을 사용해도 최종 납품은 아래 동작별 PNG와 프레임 목록이다. 리깅 데이터·파츠는 제작 보조 자료로 둔다.

## 리깅과 보조 모션

- 권장 파츠: 얼굴·눈·입·앞머리·짧은 포니테일·헤어밴드, 몸통·지지된 가슴·골반, 상완·전완·손·손목 보호대, 다리·신발, 허리 수건
- 보조 모션: 가슴 반동은 스포츠 탑 지지력에 맞춰 작게 제한한다. 메치기 때 어깨·골반의 회전과 수건 끝의 후행이 중심이다.
- 일시정지 시 본체와 보조 모션을 함께 멈춘다. 재등장·부활 시 흔들림 상태를 초기화한다.
- 연속 피격과 방향 전환에서 진폭을 제한한다. 파츠가 팔·몸통·의상을 뚫지 않도록 회전·변형 범위를 둔다.
- 필수 프레임은 기준 원화를 참조해 동일 얼굴·소품·비율을 유지한다. 낱장 이미지 하나가 자동으로 파츠·물리 리깅이 되는 것은 아니다.

- 성인 여성의 넓은 어깨와 운동 근육을 유지한다.
- 버건디 스포츠 탑·검정 팬츠·흰 헤어밴드를 유지한다.
- 전투 건틀릿은 양손에 1쌍이며 손가락이 열려 붙잡기 가능하다.

## 피할 요소와 검수

캐릭터별 제외 사항: 남성 격투가, 보디빌딩 대회 의상, 아동 비율, 손가락이 막혀 잡을 수 없는 글러브, 추가 무기

- [ ] 기준 원화와 얼굴·체형·색·소품 수가 일치한다.
- [ ] 넓은 어깨·버건디 탑·두 손의 잡기 자세가 다른 근접 캐릭터와 구분된다.
- [ ] 오른쪽 원본과 왼쪽 반전에서 발·장비 기준점이 유지된다.
- [ ] 손·팔·가슴·의상·장비가 부자연스럽게 겹치거나 관통하지 않는다.
- [ ] 기본 포즈와 공격·피격 사이에 키와 카메라 배율이 달라지지 않는다.
- [ ] 투명 배경, 잘린 소품, 알파 테두리, 문자가 섞이지 않았는지 확인한다.
- [ ] 공통 가이드의 전장 표시 크기에서 얼굴·역할이 구분된다.
- [ ] 제작 출처·이용 조건·참조 원화·수정 이력을 기록한다.
