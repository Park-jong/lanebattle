## 캐릭터 콘셉트

여유롭게 전선을 이끄는 누님. 긴 바렛 계열 저격소총을 침착하게 지지하고 큰 반동 뒤에도 자세를 되찾는 모습으로 존재감을 만든다.

- 외모·체형: 7.5~8등신, 매우 큰 가슴과 볼륨 있는 성인 체형, 안정적인 골반과 긴 팔다리
- 얼굴·머리: 길고 부드럽게 올라간 보라색 눈, 여유 있는 입꼬리, 허리까지 오는 짙은 보라색 긴 웨이브, 한쪽 금색 머리 장식
- 의상·재질: 몸에 맞춘 검정 드레스, 짙은 보라색 재킷, 금색 파이핑, 불투명 스타킹, 넓은 굽의 검정 롱부츠
- 무기·대표 소품: 바렛 계열 대구경 저격소총 1정. 검정·금색 포인트, 긴 총열·큰 총구 제동기·스코프·접힌 양각대가 제작용 식별점
- 기본 팔레트: 보라색 머리 `#38294E` / 재킷 `#6B468E` / 검정 `#22212D` / 금색 `#D9B768`
- 실루엣과 축소 식별점: 긴 보라색 머리·풍만한 성인 상체·길고 큰 바렛 계열 저격소총이 구별된다.
- 표정 세트: 여유로운 미소 / 장난스러운 미소 / 싸늘한 경고 / 만족

## 기준 포즈와 방향

오른쪽 3/4 전신, 두 발을 안정적으로 벌리고 바렛 계열 저격소총을 양손으로 낮게 지지한다. 총구는 오른쪽 앞아래, 긴 총열과 개머리판까지 캔버스에 포함

원본은 오른쪽을 보는 약한 3/4 측면이며, 머리부터 발끝·주요 소품까지 캔버스 안에 넣는다. 이동·공격 방향에 맞춰 외형만 반전한다. 체력바·이름·숫자는 반전하지 않는다.

- 기준점: 발바닥 중앙 (0.5, 0.90). 발·신발·바퀴의 접지 위치를 모든 동작에서 맞춘다.
- 얼굴과 몸은 정상적인 성인 비율로 그리고, 기계·장비는 해당 설계 비율을 유지한다.
- 그림자·체력바·문자·투사체·넓은 오라는 본체와 분리한다.
- 손·무기 끝·장비 배출구를 효과 부착점으로 기록한다. 그림의 바깥 여백은 충돌 영역이 아니다.

## 동작별 연기

| 동작 | 자세와 움직임 |
| --- | --- |
| `idle` | 바렛을 양손으로 안정적으로 지지한 채 느린 호흡과 작은 체중 이동 |
| `walk` | 왼발 접지 → 오른발 통과 → 오른발 접지 → 왼발 통과. 무거운 소총을 지지하는 안정적 보폭, 긴 총열은 전방 유지 |
| `attack` | 바렛을 전방으로 조준 → 단발 발사 → 팔·어깨·소총의 무게감 있는 반동 → 중심과 조준 자세 회복 |
| `hit` | 미소가 잠깐 사라지고 어깨가 짧게 밀린 뒤 바렛과 양손 지지를 유지하며 회복 |
| `spawn` | 바렛을 양손으로 지지한 채 진입하고 전방에 시선 고정 |
| `exit` | 바렛을 양손으로 챙겨 낮게 유지한 채 라운지 쪽으로 물러남 |
| skill_push | 바렛의 금보라 충격탄으로 전방 밀어내기 파동 |
| skill_support | 바렛을 짧은 지지 슬링과 한 손으로 고정하고 빈손으로 금색 회복·강화 신호 |
| skill_ultimate | 바렛을 안정적으로 조준하고 굵은 금보라 궤적의 필살탄 단발 발사 |
| victory | 바렛을 양손으로 낮춰 지지하며 만족스러운 미소 |

준비 → 타격·발사 → 회수는 제작상의 자세 순서다. 실제 공격·능력 이벤트에 타격 자세를 맞추고, 애니메이션을 기다리느라 기존 판정을 늦추지 않는다. 문서의 고유 동작·효과가 새 전투 기능을 추가한다는 뜻은 아니다.

### 모든 스킨의 납품 규칙

- 이 목록은 `default`와 같은 캐릭터의 모든 추가 의상 스킨에 적용한다. 스킨마다 자체 프레임 묶음을 제작한다.
- 이동 클립의 파일명은 비행·롤러도 `walk_00.png ~ walk_03.png`를 사용한다. 실제 자세는 아래 전용 포즈를 따른다.
- `exit` 연기의 납품 파일명은 기존 기본 스킨과 같은 `death_00.png ~ death_03.png`다. 다른 동작을 임의로 `fly_`·`exit_`로 중복 납품하지 않는다.
- `reference.png`는 승인된 `idle_00.png`의 복사·별칭이다. 공통 본체 19컷에 한 컷을 더하지 않는다.
- 공통 19컷과 고유 전신 컷은 같은 캔버스·배율·피벗·방향을 유지한다. 효과·상반신 컷인은 별도 규격이다.
- `death_03.png`는 같은 크기의 완전 투명 파일로 내보낸다. 다른 퇴장 컷은 본체와 장비가 함께 사라지게 한다.
- 여성의 `bust_idle_00.png ~ bust_idle_03.png`도 동일한 전신 캔버스를 사용한다. 전투 대기 보조 클립과 선택 화면의 상반신 크롭에 재사용한다.
- 리깅을 사용해도 최종 납품은 아래 동작별 PNG와 프레임 목록이다. 리깅 데이터·파츠는 제작 보조 자료로 둔다.

## 리깅과 보조 모션

- 권장 파츠: 얼굴·눈·눈썹·입·앞머리·긴 뒷머리·금색 장식, 몸통·골반·좌우 가슴과 드레스·재킷 보정, 팔다리·손·롱부츠·재킷 자락, 바렛 본체·스코프·접힌 양각대·슬링
- 보조 모션: 세 주인공 중 가슴의 후행이 가장 뚜렷하다. 몸통이 먼저 멈춘 뒤 무게감 있게 짧게 감쇠하며, 재킷 지지력과 팔 간격을 지킨다. 긴 머리와 재킷 끝도 별도 후행을 둔다.
- 일시정지 시 본체와 보조 모션을 함께 멈춘다. 재등장·부활 시 흔들림 상태를 초기화한다.
- 연속 피격과 방향 전환에서 진폭을 제한한다. 파츠가 팔·몸통·의상을 뚫지 않도록 회전·변형 범위를 둔다.
- 필수 프레임은 기준 원화를 참조해 동일 얼굴·소품·비율을 유지한다. 낱장 이미지 하나가 자동으로 파츠·물리 리깅이 되는 것은 아니다.

idle_00 승인 → 공통 19컷 → 고유 본체·바스트·효과 컷 → 감상·표정·컷인 → 게임 크기 검수 순서다. 파츠 분리·가림 영역 복원은 리깅을 제작 보조로 사용할 때 추가한다. 위 파일명은 향후 납품 규약이며, 현재 실제 PNG가 있다는 의미는 아니다.

## 반드시 유지할 특징

- 매우 큰 가슴과 성인 7.5~8등신 체형을 유지한다.
- 허리 길이의 짙은 보라 머리와 금색 머리 장식 1개를 유지한다.
- 검정 드레스·보라 재킷·긴 총열과 스코프의 바렛 계열 저격소총 1정을 유지한다.

## 피할 요소와 검수

캐릭터별 제외 사항: 작은 권총·돌격소총으로 변경, 한 손만으로 떠 있는 소총, 잘린 총열·개머리판, 가슴의 크기 변화, 의상 관통, 글자·탄약 UI

- [ ] 기준 원화와 얼굴·체형·색·소품 수가 일치한다.
- [ ] 긴 보라색 머리·풍만한 성인 상체·길고 큰 바렛 계열 저격소총이 구별된다.
- [ ] 오른쪽 원본과 왼쪽 반전에서 발·장비 기준점이 유지된다.
- [ ] 손·팔·가슴·의상·장비가 부자연스럽게 겹치거나 관통하지 않는다.
- [ ] 기본 포즈와 공격·피격 사이에 키와 카메라 배율이 달라지지 않는다.
- [ ] 투명 배경, 잘린 소품, 알파 테두리, 문자가 섞이지 않았는지 확인한다.
- [ ] 공통 가이드의 전장 표시 크기에서 얼굴·역할이 구분된다.
- [ ] 제작 출처·이용 조건·참조 원화·수정 이력을 기록한다.
