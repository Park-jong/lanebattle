ID·경로·모션명은 제작 제안이다. 한 전투에 세 타입 중 한 명을 선택한다. 세 주인공 모두 총기 원거리 발사로 설계하며, 기존 영웅의 근접 판정에서 원거리 판정으로 확장할 작업이 필요하다. 최초 성능은 공통 기준으로 맞추는 방향이며 사거리·탄속·공격 간격·타격 이벤트는 구현 시 별도 확정한다. 무기 종류만으로 임의의 탄약·재장전·연사·관통 규칙을 추가하지 않는다.

## 캐릭터 콘셉트

평소에는 친절하지만 경계를 넘는 상대에게 분명하게 거절하는 주인공. M4 계열 카빈을 안정적으로 다루는 동작과 단호해지는 표정이 핵심이다.

- 외모·체형: 7.5등신의 균형 잡힌 성인 체형, 중간 크기 가슴, 편안한 어깨와 안정적인 자세
- 얼굴·머리: 둥근 아몬드형 갈색 눈, 부드러운 눈썹, 따뜻한 미소, 어깨 아래까지 오는 갈색 미디엄 웨이브와 한쪽 민트 헤어핀
- 의상·재질: 크림 블라우스, 민트 가디건, 코랄색 무릎 위 A라인 스커트, 낮고 넓은 굽의 아이보리 스트랩 슈즈
- 무기·대표 소품: M4 계열 카빈 1정. 검정 몸체·민트색 작은 포인트·상부 레일·분리된 개머리판 실루엣과 완만한 곡선의 탄창이 제작용 식별점
- 기본 팔레트: 갈색 머리 `#805B48` / 민트 `#8FCDBB` / 크림 `#F5ECDD` / 코랄 `#DC8E89`
- 실루엣과 축소 식별점: 민트 가디건·갈색 미디엄 헤어·검정 M4 계열 카빈의 실루엣이 남는다.
- 표정 세트: 따뜻한 미소 / 걱정 / 단호한 경고 / 안도

## 기준 포즈와 방향

두 발을 약간 벌린 오른쪽 3/4 전신. M4 계열 카빈을 양손으로 몸 앞아래에 잡고 총구는 오른쪽 앞아래, 얼굴과 소총 전체를 노출

원본은 오른쪽을 보는 약한 3/4 측면이며, 머리부터 발끝·주요 소품까지 캔버스 안에 넣는다. 이동·공격 방향에 맞춰 외형만 반전한다. 체력바·이름·숫자는 반전하지 않는다.

- 기준점: 발바닥 중앙 (0.5, 0.90). 발·신발·바퀴의 접지 위치를 모든 동작에서 맞춘다.
- 얼굴과 몸은 정상적인 성인 비율로 그리고, 기계·장비는 해당 설계 비율을 유지한다.
- 그림자·체력바·문자·투사체·넓은 오라는 본체와 분리한다.
- 손·무기 끝·장비 배출구를 효과 부착점으로 기록한다. 그림의 바깥 여백은 충돌 영역이 아니다.

| `idle` | M4를 양손으로 낮게 지지하며 작은 호흡과 눈깜빡임, 전방에 편안하게 시선 고정 |

| skill_ultimate | M4를 안정적으로 조준하고 민트·코랄 빛의 광역 필살 발사 |

준비 → 타격·발사 → 회수는 제작상의 자세 순서다. 실제 공격·능력 이벤트에 타격 자세를 맞추고, 애니메이션을 기다리느라 기존 판정을 늦추지 않는다. 문서의 고유 동작·효과가 새 전투 기능을 추가한다는 뜻은 아니다.

- 이 목록은 `default`와 같은 캐릭터의 모든 추가 의상 스킨에 적용한다. 스킨마다 자체 프레임 묶음을 제작한다.
- 이동 클립의 파일명은 비행·롤러도 `walk_00.png ~ walk_03.png`를 사용한다. 실제 자세는 아래 전용 포즈를 따른다.
- `exit` 연기의 납품 파일명은 기존 기본 스킨과 같은 `death_00.png ~ death_03.png`다. 다른 동작을 임의로 `fly_`·`exit_`로 중복 납품하지 않는다.
- `reference.png`는 승인된 `idle_00.png`의 복사·별칭이다. 공통 본체 19컷에 한 컷을 더하지 않는다.
- 공통 19컷과 고유 전신 컷은 같은 캔버스·배율·피벗·방향을 유지한다. 효과·상반신 컷인은 별도 규격이다.
- `death_03.png`는 같은 크기의 완전 투명 파일로 내보낸다. 다른 퇴장 컷은 본체와 장비가 함께 사라지게 한다.
- 여성의 `bust_idle_00.png ~ bust_idle_03.png`도 동일한 전신 캔버스를 사용한다. 전투 대기 보조 클립과 선택 화면의 상반신 크롭에 재사용한다.
- 리깅을 사용해도 최종 납품은 아래 동작별 PNG와 프레임 목록이다. 리깅 데이터·파츠는 제작 보조 자료로 둔다.

## 리깅과 보조 모션

- 권장 파츠: 얼굴·눈·눈썹·입·앞머리·뒷머리·헤어핀, 몸통·골반·좌우 가슴과 블라우스 보정, 가디건·소매·스커트·팔다리·손·신발, M4 본체·슬링
- 보조 모션: 중간 크기 가슴은 몸통을 따라 완만하게 후행하고 빠르게 안정화한다. 머리 끝·가디건은 부드럽게 따라오며 소매와 손이 M4를 관통하지 않게 한다.
- 일시정지 시 본체와 보조 모션을 함께 멈춘다. 재등장·부활 시 흔들림 상태를 초기화한다.
- 연속 피격과 방향 전환에서 진폭을 제한한다. 파츠가 팔·몸통·의상을 뚫지 않도록 회전·변형 범위를 둔다.
- 필수 프레임은 기준 원화를 참조해 동일 얼굴·소품·비율을 유지한다. 낱장 이미지 하나가 자동으로 파츠·물리 리깅이 되는 것은 아니다.

idle_00 승인 → 공통 19컷 → 고유 본체·바스트·효과 컷 → 감상·표정·컷인 → 게임 크기 검수 순서다. 파츠 분리·가림 영역 복원은 리깅을 제작 보조로 사용할 때 추가한다. 위 파일명은 향후 납품 규약이며, 현재 실제 PNG가 있다는 의미는 아니다.
