## 캐릭터 콘셉트

촬영 장비를 과하게 키운 공중 감독. 사람 본인과 탑승 플랫폼을 함께 보여 일반 무인 촬영 드론보다 위협적인 보스로 만든다.

- 외모·체형: 인물은 7.5등신 성인 체형, 큰 사각 플랫폼 위에 선 전신. 플랫폼을 포함한 전체는 정사각형 구성
- 얼굴·머리: 짧은 회색 머리, 사각 선글라스, 얇은 콧수염, 굳게 다문 입
- 의상·재질: 먹보라 감독 재킷, 회색 카고 팬츠, 검정 장갑과 부츠, 가슴 고정 벨트
- 무기·대표 소품: 안전 난간과 발 고정구가 있는 대형 네 로터 촬영 플랫폼 1대, 전방 카메라 1개, 양손 조종기 1개, 전방 하부 소형 회전총좌 1개
- 기본 팔레트: 먹보라 `#3D354D` / 철회색 `#717B89` / 검정 `#272A34` / 렌즈 적색 `#CB6875`
- 실루엣과 축소 식별점: 네 로터 대형 플랫폼·위에 선 남성 감독·큰 전방 렌즈로 일반 드론과 구분한다.
- 표정 세트: 냉정한 감시 / 명령 / 기겁 / 분노

## 기준 포즈와 방향

오른쪽 3/4 시점, 성인 감독이 플랫폼 위 발 고정구에 서서 조종기를 양손으로 잡음. 플랫폼·로터·카메라·인물을 모두 포함

원본은 오른쪽을 보는 약한 3/4 측면이며, 머리부터 발끝·주요 소품까지 캔버스 안에 넣는다. 전장에서는 왼쪽을 향하도록 외형만 반전한다. 체력바·이름·숫자는 반전하지 않는다.

- 기준점: 공중 중심 (0.5, 0.5). 고도는 화면 계층에서 적용한다. 착지 시에도 동일 피벗을 유지한다.
- 얼굴과 몸은 정상적인 성인 비율로 그리고, 기계·장비는 해당 설계 비율을 유지한다.
- 그림자·체력바·문자·투사체·넓은 오라는 본체와 분리한다.
- 손·무기 끝·장비 배출구를 효과 부착점으로 기록한다. 그림의 바깥 여백은 충돌 영역이 아니다.

## 동작별 연기

| 동작 | 자세와 움직임 |
| --- | --- |
| `idle` | 플랫폼이 부유하고 감독은 무릎으로 균형 보정. 전방 카메라는 정면 추적 |
| `walk` (비행) | 플랫폼 수평 이동과 작은 뱅크. 감독의 발은 고정구에 붙인 채 상체만 보정 |
| `attack` | 전방 카메라 추적 → 플랫폼 하부 총좌에서 원거리 빛탄 발사 → 기체 안정화 |
| `hit` | 기체가 짧게 기울고 감독이 조종기를 움켜쥠 |
| `spawn` | 적 기지 위에서 플랫폼과 함께 상승 |
| `exit` | 상태등이 깜빡이며 플랫폼과 감독이 함께 후퇴 |
| descend | 실제 착지 패턴에 플랫폼 전체 고도를 낮추고 하부 범퍼로 강타한 뒤 재상승 |
| fx_landing | 실제 착지 범위·시점에만 먹보라 충격 링 |
| fx_camera | 하부 총좌의 짧은 발사광 |

준비 → 타격·발사 → 회수는 제작상의 자세 순서다. 실제 공격·능력 이벤트에 타격 자세를 맞추고, 애니메이션을 기다리느라 기존 판정을 늦추지 않는다. 문서의 고유 동작·효과가 새 전투 기능을 추가한다는 뜻은 아니다.

### 모든 스킨의 납품 규칙

- 이 목록은 `default`와 같은 캐릭터의 모든 추가 의상 스킨에 적용한다. 스킨마다 자체 프레임 묶음을 제작한다.
- 이동 클립의 파일명은 비행·롤러도 `walk_00.png ~ walk_03.png`를 사용한다. 실제 자세는 아래 전용 포즈를 따른다.
- `exit` 연기의 납품 파일명은 기존 기본 스킨과 같은 `death_00.png ~ death_03.png`다. 다른 동작을 임의로 `fly_`·`exit_`로 중복 납품하지 않는다.
- `reference.png`는 승인된 `idle_00.png`의 복사·별칭이다. 공통 본체 19컷에 한 컷을 더하지 않는다.
- 공통 19컷과 고유 전신 컷은 같은 캔버스·배율·피벗·방향을 유지한다. 효과·상반신 컷인은 별도 규격이다.
- `death_03.png`는 같은 크기의 완전 투명 파일로 내보낸다. 다른 퇴장 컷은 본체와 장비가 함께 사라지게 한다.
- 여성의 `bust_idle_00.png ~ bust_idle_03.png`도 동일한 전신 캔버스를 사용한다. 전투 대기 보조 클립과 선택 화면의 상반신 크롭에 재사용한다.
- 리깅을 사용해도 최종 납품은 아래 동작별 PNG와 프레임 목록이다. 리깅 데이터·파츠는 제작 보조 자료로 둔다.

## 리깅과 보조 모션

- 권장 파츠: 감독 얼굴·선글라스·눈·입·콧수염·머리·몸통·골반·팔다리·장갑·부츠·안전 벨트·조종기, 플랫폼·로터 암 4개·보호링·로터 4개·난간·발 고정구·카메라·하부 범퍼·하부 총좌
- 보조 모션: 인물과 플랫폼을 하나의 고도 노드 아래에 두고 각 로터와 카메라만 별도 회전. 착지해도 피벗을 바꾸지 않고 고도만 조절한다.
- 일시정지 시 본체와 보조 모션을 함께 멈춘다. 재등장·부활 시 흔들림 상태를 초기화한다.
- 연속 피격과 방향 전환에서 진폭을 제한한다. 파츠가 팔·몸통·의상을 뚫지 않도록 회전·변형 범위를 둔다.
- 필수 프레임은 기준 원화를 참조해 동일 얼굴·소품·비율을 유지한다. 낱장 이미지 하나가 자동으로 파츠·물리 리깅이 되는 것은 아니다.

## 반드시 유지할 특징

- 성인 남성 감독 1명과 네 로터 플랫폼 1대를 유지한다.
- 카메라 1개·하부 총좌 1개·조종기 1개·안전 난간을 유지한다.
- 감독은 플랫폼에 붙어 있고 착지 시 전체 장비가 함께 내려온다.

## 피할 요소와 검수

캐릭터별 제외 사항: 무인 드론만 단독 생성, 다수 감독, 날개·헬리콥터 프로펠러 1개, 지면에 두고 별도 사람이 걷는 구성

- [ ] 기준 원화와 얼굴·체형·색·소품 수가 일치한다.
- [ ] 네 로터 대형 플랫폼·위에 선 남성 감독·큰 전방 렌즈로 일반 드론과 구분한다.
- [ ] 오른쪽 원본과 왼쪽 반전에서 발·장비 기준점이 유지된다.
- [ ] 손·팔·가슴·의상·장비가 부자연스럽게 겹치거나 관통하지 않는다.
- [ ] 기본 포즈와 공격·피격 사이에 키와 카메라 배율이 달라지지 않는다.
- [ ] 투명 배경, 잘린 소품, 알파 테두리, 문자가 섞이지 않았는지 확인한다.
- [ ] 공통 가이드의 전장 표시 크기에서 얼굴·역할이 구분된다.
- [ ] 제작 출처·이용 조건·참조 원화·수정 이력을 기록한다.
