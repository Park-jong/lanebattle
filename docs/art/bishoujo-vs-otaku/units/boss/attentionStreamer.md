## 캐릭터 콘셉트

관심과 조명을 독점하려는 과장된 방송인. 지상 이동 방송 카트가 긴 장비 실루엣과 넓은 휩쓸기 패턴을 담당한다.

- 외모·체형: 인물은 7.5등신의 늘씬한 성인 남성. 허리 높이의 이동 카트와 모니터를 포함해 가로로 긴 구성
- 얼굴·머리: 금갈색 포마드, 자신을 과시하는 청색 눈과 웃음, 작은 검정 헤드셋 마이크
- 의상·재질: 광택 있는 청록·먹보라 방송 재킷, 검정 상의와 바지, 흰 운동화
- 무기·대표 소품: 바퀴 네 개의 이동 방송 카트 1대, 모니터 2개, 카메라 1개, 링라이트 1개, 접이식 수평 조명 붐암 겸 파쇄봉 1개
- 기본 팔레트: 청록 `#3F888E` / 먹보라 `#44334F` / 금갈 머리 `#B38B58` / 화면 연보라 `#A48AC7`
- 실루엣과 축소 식별점: 방송인 전신·이중 모니터·링라이트·옆으로 뻗는 붐암과 바퀴 카트가 보스의 긴 외형을 만든다.
- 표정 세트: 자기과시 미소 / 흥분한 진행 / 분노 / 당황

## 기준 포즈와 방향

오른쪽을 보는 방송인 전신이 카트 옆에 서고 한 손은 카트 손잡이, 다른 손은 진행 제스처. 카트 바퀴와 인물 발은 같은 지면

원본은 오른쪽을 보는 약한 3/4 측면이며, 머리부터 발끝·주요 소품까지 캔버스 안에 넣는다. 전장에서는 왼쪽을 향하도록 외형만 반전한다. 체력바·이름·숫자는 반전하지 않는다.

- 기준점: 발바닥 중앙 (0.5, 0.90). 발·신발·바퀴의 접지 위치를 모든 동작에서 맞춘다.
- 얼굴과 몸은 정상적인 성인 비율로 그리고, 기계·장비는 해당 설계 비율을 유지한다.
- 그림자·체력바·문자·투사체·넓은 오라는 본체와 분리한다.
- 손·무기 끝·장비 배출구를 효과 부착점으로 기록한다. 그림의 바깥 여백은 충돌 영역이 아니다.

## 동작별 연기

| 동작 | 자세와 움직임 |
| --- | --- |
| `idle` | 카메라를 향해 작은 진행 제스처. 화면의 추상 밝기 막대는 별도 계층 |
| `walk` | 인물이 카트를 밀며 왼발 전진 → 통과 → 오른발 전진 → 통과. 바퀴 회전과 몸 전진 연결 |
| `attack` | 짧게 카트를 전방으로 밀어 범퍼 타격한 뒤 복귀. 먼 거리 발사 공격을 새로 추가하지 않음 |
| `hit` | 카트 손잡이를 붙잡고 모니터가 짧게 흔들림 |
| `spawn` | 카트를 끌고 적 기지에서 진입해 카메라를 정렬 |
| `exit` | 카메라를 끄고 모니터를 접으며 카트와 함께 후퇴 |
| resource_jam | 실제 자원 충전 감소 동안 카트 안테나에 탁한 방송 링 |
| absorb_light | 스포트라이트 계열 피격 시 링라이트로 빛을 흡수. 실제 회복량과 연결 |
| boom_sweep | 기존 꼬리 휩쓸기 이벤트에 카트의 접이식 붐암을 수평으로 펼쳐 휩쓸기 |

준비 → 타격·발사 → 회수는 제작상의 자세 순서다. 실제 공격·능력 이벤트에 타격 자세를 맞추고, 애니메이션을 기다리느라 기존 판정을 늦추지 않는다. 문서의 고유 동작·효과가 새 전투 기능을 추가한다는 뜻은 아니다.

### 모든 스킨의 납품 규칙

- 이 목록은 `default`와 같은 캐릭터의 모든 추가 의상 스킨에 적용한다. 스킨마다 자체 프레임 묶음을 제작한다.
- 이동 클립의 파일명은 비행·롤러도 `walk_00.png ~ walk_03.png`를 사용한다. 실제 자세는 아래 전용 포즈를 따른다.
- `exit` 연기의 납품 파일명은 기존 기본 스킨과 같은 `death_00.png ~ death_03.png`다. 다른 동작을 임의로 `fly_`·`exit_`로 중복 납품하지 않는다.
- `reference.png`는 승인된 `idle_00.png`의 복사·별칭이다. 공통 본체 19컷에 한 컷을 더하지 않는다.
- 공통 19컷과 고유 전신 컷은 같은 캔버스·배율·피벗·방향을 유지한다. 효과·상반신 컷인은 별도 규격이다.
- `death_03.png`는 같은 크기의 완전 투명 파일로 내보낸다. 다른 퇴장 컷은 본체와 장비가 함께 사라지게 한다.
- 여성의 `bust_idle_00.png ~ bust_idle_03.png`도 동일한 전신 캔버스를 사용한다. 전투 대기 보조 클립과 선택 화면의 상반신 크롭에 재사용한다.
- 리깅을 사용해도 최종 납품은 아래 동작별 PNG와 프레임 목록이다. 리깅 데이터·파츠는 제작 보조 자료로 둔다.

## 리깅과 보조 모션

- 권장 파츠: 인물 얼굴·눈·입·머리·마이크·몸통·골반·팔다리·손·신발·재킷, 카트 프레임·바퀴 4개·손잡이·모니터 2개·카메라·링라이트·붐암
- 보조 모션: 카트는 지면에 붙고 장비 암·모니터만 제한된 진동을 둔다. 케이블은 짧고 고정되어 팔다리에 감기지 않는다.
- 일시정지 시 본체와 보조 모션을 함께 멈춘다. 재등장·부활 시 흔들림 상태를 초기화한다.
- 연속 피격과 방향 전환에서 진폭을 제한한다. 파츠가 팔·몸통·의상을 뚫지 않도록 회전·변형 범위를 둔다.
- 필수 프레임은 기준 원화를 참조해 동일 얼굴·소품·비율을 유지한다. 낱장 이미지 하나가 자동으로 파츠·물리 리깅이 되는 것은 아니다.

## 반드시 유지할 특징

- 성인 남성 방송인과 지상 카트를 한 보스 자산으로 유지한다.
- 모니터 2개·카메라 1개·링라이트 1개·붐암 1개를 유지한다.
- 흡수·휩쓸기는 장비 연출이며 비행·변신·추가 전투원은 없다.

## 피할 요소와 검수

캐릭터별 제외 사항: 실제 방송 플랫폼 로고·채팅, 인스타 셀럽과 같은 핑크 여성 디자인, 뱀 몸통·드래곤·비행 카트, 장비 숫자 증식

- [ ] 기준 원화와 얼굴·체형·색·소품 수가 일치한다.
- [ ] 방송인 전신·이중 모니터·링라이트·옆으로 뻗는 붐암과 바퀴 카트가 보스의 긴 외형을 만든다.
- [ ] 오른쪽 원본과 왼쪽 반전에서 발·장비 기준점이 유지된다.
- [ ] 손·팔·가슴·의상·장비가 부자연스럽게 겹치거나 관통하지 않는다.
- [ ] 기본 포즈와 공격·피격 사이에 키와 카메라 배율이 달라지지 않는다.
- [ ] 투명 배경, 잘린 소품, 알파 테두리, 문자가 섞이지 않았는지 확인한다.
- [ ] 공통 가이드의 전장 표시 크기에서 얼굴·역할이 구분된다.
- [ ] 제작 출처·이용 조건·참조 원화·수정 이력을 기록한다.
