## 캐릭터 콘셉트

무단 촬영을 강행하는 적 군단의 소형 장비. 중앙 카메라가 눈처럼 전방을 추적하며 위협적인 촬영광을 보낸다.

- 외모·체형: 손가방 두 개 정도 폭의 단단한 소형 기체. 중앙 카메라와 네 개 로터를 가진 기계 비율
- 얼굴·머리: 인간 얼굴 없이 전방의 원형 카메라 렌즈 1개와 작은 적색 상태등
- 의상·재질: 먹보라 무광 기체, 회색 금속 로터 암, 보라색 렌즈 테두리. 의상 없음
- 무기·대표 소품: 보호링 로터 4개·하단 카메라 1개·착륙 다리 2개·카메라 옆 소형 총좌 1개
- 기본 팔레트: 먹보라 `#383344` / 금속 회색 `#747B88` / 렌즈 보라 `#9E80BE` / 적색등 `#D36B71`
- 실루엣과 축소 식별점: 네 로터·매달린 카메라·적색 상태등이 아군 여성 비행 유닛과 분명히 구분된다.
- 표정 세트: 정면 추적 / 렌즈 아래 탐색 / 상태등 경고 / 렌즈 흔들림

## 기준 포즈와 방향

오른쪽 3/4 측면으로 부유하는 단일 드론. 카메라 광축은 오른쪽, 네 로터와 양 착륙 다리가 모두 읽히는 구도

원본은 오른쪽을 보는 약한 3/4 측면이며, 기체·로터·총좌·카메라까지 캔버스 안에 넣는다. 전장에서는 왼쪽을 향하도록 외형만 반전한다. 체력바·이름·숫자는 반전하지 않는다.

- 기준점: 공중 중심 (0.5, 0.5). 고도는 화면 계층에서 적용한다. 착지 시에도 동일 피벗을 유지한다.
- 기체와 카메라는 지정된 기계 비율을 유지하고 인체를 추가하지 않는다.
- 그림자·체력바·문자·투사체·넓은 오라는 본체와 분리한다.
- 카메라·총좌·장비 배출구를 효과 부착점으로 기록한다. 그림의 바깥 여백은 충돌 영역이 아니다.

## 동작별 연기

| 동작 | 자세와 움직임 |
| --- | --- |
| `idle` | 작게 부유하며 렌즈를 전방으로 미세 회전 |
| `walk` (비행) | 수평 추진 방향으로 기체가 조금 기울고 카메라 짐벌은 전방 추적 유지 |
| `attack` | 카메라로 목표를 추적하고 옆 소형 총좌에서 짧은 빛탄 발사 후 안정화 |
| `hit` | 로터 회전과 기체 기울기가 짧게 흔들렸다 안정화 |
| `spawn` | 적 부스 위에서 상승해 전장 고도 진입 |
| `exit` | 상태등이 깜빡이며 적 기지 쪽으로 비틀거리다 화면 밖 퇴장 |
| fx_camera_flash | 카메라 옆 소형 총좌에서 나오는 짧은 보라색 발사광 |

준비 → 타격·발사 → 회수는 제작상의 자세 순서다. 실제 공격·능력 이벤트에 타격 자세를 맞추고, 애니메이션을 기다리느라 기존 판정을 늦추지 않는다. 문서의 고유 동작·효과가 새 전투 기능을 추가한다는 뜻은 아니다.

### 모든 스킨의 납품 규칙

- 이 목록은 `default`와 같은 캐릭터의 모든 추가 의상 스킨에 적용한다. 스킨마다 자체 프레임 묶음을 제작한다.
- 이동 클립의 파일명은 비행·롤러도 `walk_00.png ~ walk_03.png`를 사용한다. 실제 자세는 아래 전용 포즈를 따른다.
- `exit` 연기의 납품 파일명은 기존 기본 스킨과 같은 `death_00.png ~ death_03.png`다. 다른 동작을 임의로 `fly_`·`exit_`로 중복 납품하지 않는다.
- `reference.png`는 승인된 `idle_00.png`의 복사·별칭이다. 공통 본체 19컷에 한 컷을 더하지 않는다.
- 공통 19컷과 고유 전신 컷은 같은 캔버스·배율·피벗·방향을 유지한다. 효과·상반신 컷인은 별도 규격이다.
- `death_03.png`는 같은 크기의 완전 투명 파일로 내보낸다. 다른 퇴장 컷은 본체와 장비가 함께 사라지게 한다.
- 여성의 `bust_idle_00.png ~ bust_idle_03.png`도 동일한 전신 캔버스를 사용한다. 전투 대기 보조 클립과 선택 화면의 상반신 크롭에 재사용한다.
- 리깅을 사용해도 최종 납품은 아래 동작별 PNG와 프레임 목록이다. 리깅 데이터·파츠는 제작 보조 자료로 둔다.

## 리깅과 보조 모션

- 권장 파츠: 중앙 기체·로터 암 4개·회전 로터 4개·보호링 4개·카메라 짐벌·렌즈·상태등·착륙 다리 2개·소형 총좌
- 보조 모션: 단단한 기체는 늘이지 않고, 카메라 짐벌이 기체 기울기를 보정한다. 인체 바스트·머리카락 모션은 해당하지 않는다.
- 일시정지 시 본체와 보조 모션을 함께 멈춘다. 재등장·부활 시 흔들림 상태를 초기화한다.
- 연속 피격과 방향 전환에서 진폭을 제한한다. 로터·카메라·총좌가 서로 뚫지 않도록 회전·변형 범위를 둔다.
- 필수 프레임은 기준 원화를 참조해 동일 기체·장비 수·비율을 유지한다. 낱장 이미지 하나가 자동으로 파츠·물리 리깅이 되는 것은 아니다.

## 반드시 유지할 특징

- 로터 4개·카메라 1개·착륙 다리 2개·소형 총좌 1개를 유지한다.
- 조종자·탑승자를 본체에 넣지 않는다.
- 먹보라·적색 상태등의 적 기체다.

## 피할 요소와 검수

캐릭터별 제외 사항: 사람·탑승자, 드론 여러 대, 날개, 추가 로터·총좌, 계속 켜진 큰 광선

- [ ] 기준 원화와 얼굴·체형·색·소품 수가 일치한다.
- [ ] 네 로터·매달린 카메라·적색 상태등이 아군 여성 비행 유닛과 분명히 구분된다.
