## 캐릭터 콘셉트

출입 금지선을 무시하고 목표 기지로 곧장 달려드는 인물. 전방을 향한 숙인 상체와 큰 어깨 가방으로 압박감을 만든다.

- 외모·체형: 7.5등신의 건장한 성인 체형, 넓은 등과 굵은 다리
- 얼굴·머리: 짧은 검정 스포츠컷, 짙은 눈썹, 이를 악문 표정
- 의상·재질: 탁한 적갈색 봄버 재킷, 회색 티셔츠, 검정 카고팬츠, 두꺼운 워커
- 무기·대표 소품: 양손 공성 해머 1개, 등에 밀착한 작은 더플백 1개
- 기본 팔레트: 적갈색 `#8F514F` / 회색 `#7A7B83` / 검정 `#2B2D36` / 가방 `#54474F`
- 실루엣과 축소 식별점: 적갈색 봄버·숙인 상체·밀착 더플백으로 기지 직진형을 구별한다.
- 표정 세트: 이를 악문 돌진 / 짜증 / 놀람 / 허둥댐

## 기준 포즈와 방향

오른쪽으로 중심을 기울인 전신, 해머를 양손으로 앞아래에 지지하고 가방은 등에 밀착

원본은 오른쪽을 보는 약한 3/4 측면이며, 머리부터 발끝·주요 소품까지 캔버스 안에 넣는다. 전장에서는 왼쪽을 향하도록 외형만 반전한다. 체력바·이름·숫자는 반전하지 않는다.

- 기준점: 발바닥 중앙 (0.5, 0.90). 발·신발·바퀴의 접지 위치를 모든 동작에서 맞춘다.
- 얼굴과 몸은 정상적인 성인 비율로 그리고, 기계·장비는 해당 설계 비율을 유지한다.
- 그림자·체력바·문자·투사체·넓은 오라는 본체와 분리한다.
- 손·무기 끝·장비 배출구를 효과 부착점으로 기록한다. 그림의 바깥 여백은 충돌 영역이 아니다.

## 동작별 연기

| 동작 | 자세와 움직임 |
| --- | --- |
| `idle` | 몸을 앞으로 기울인 채 발을 번갈아 짧게 디딤 |
| `walk` | 왼발 강한 접지 → 공중 통과 → 오른발 강한 접지 → 통과. 항상 전방 기지에 시선 |
| `attack` | 기지 앞에서 해머를 낮게 당김 → 전방 기지 타격 → 무게 흡수 → 회수 |
| `hit` | 상체가 짧게 흔들려도 달리는 중심을 다시 전방으로 모음 |
| `spawn` | 적 부스에서 어깨를 낮추고 곧장 뛰어나옴 |
| `exit` | 해머를 양손에 유지하고 등에 가방을 고정한 채 당황하며 후퇴 |
| base_ram | 실제 기지 타격 때만 짧은 적갈색 충돌선 |
| fx_rush | 발뒤의 짧은 먼지와 속도선. 추가 피해 판정 없음 |

준비 → 타격·발사 → 회수는 제작상의 자세 순서다. 실제 공격·능력 이벤트에 타격 자세를 맞추고, 애니메이션을 기다리느라 기존 판정을 늦추지 않는다. 문서의 고유 동작·효과가 새 전투 기능을 추가한다는 뜻은 아니다.

### 모든 스킨의 납품 규칙

- 이 목록은 `default`와 같은 캐릭터의 모든 추가 의상 스킨에 적용한다. 스킨마다 자체 프레임 묶음을 제작한다.
- 이동 클립의 파일명은 비행·롤러도 `walk_00.png ~ walk_03.png`를 사용한다. 실제 자세는 아래 전용 포즈를 따른다.
- `exit` 연기의 납품 파일명은 기존 기본 스킨과 같은 `death_00.png ~ death_03.png`다. 다른 동작을 임의로 `fly_`·`exit_`로 중복 납품하지 않는다.
- `reference.png`는 승인된 `idle_00.png`의 복사·별칭이다. 공통 본체 19컷에 한 컷을 더하지 않는다.
- 공통 19컷과 고유 전신 컷은 같은 캔버스·배율·피벗·방향을 유지한다. 효과·상반신 컷인은 별도 규격이다.
- `death_03.png`는 같은 크기의 완전 투명 파일로 내보낸다. 다른 퇴장 컷은 본체와 장비가 함께 사라지게 한다.
- 여성의 `bust_idle_00.png ~ bust_idle_03.png`도 동일한 전신 캔버스를 사용한다. 전투 대기 보조 클립과 선택 화면의 상반신 크롭에 재사용한다.
- 리깅을 사용해도 최종 납품은 아래 동작별 PNG와 프레임 목록이다. 리깅 데이터·파츠는 제작 보조 자료로 둔다.

## 리깅과 보조 모션

- 권장 파츠: 얼굴·눈·입·짧은 머리, 몸통·골반·봄버·팔다리·손·워커, 더플백·끈·공성 해머
- 보조 모션: 몸통의 전진과 어깨·골반의 상반 회전을 강조한다. 밀착 가방과 재킷 끝은 짧게 뒤따른다.
- 일시정지 시 본체와 보조 모션을 함께 멈춘다. 재등장·부활 시 흔들림 상태를 초기화한다.
- 연속 피격과 방향 전환에서 진폭을 제한한다. 파츠가 팔·몸통·의상을 뚫지 않도록 회전·변형 범위를 둔다.
- 필수 프레임은 기준 원화를 참조해 동일 얼굴·소품·비율을 유지한다. 낱장 이미지 하나가 자동으로 파츠·물리 리깅이 되는 것은 아니다.

## 반드시 유지할 특징

- 성인 남성·검정 스포츠컷·적갈색 봄버를 유지한다.
- 더플백 1개·양손 공성 해머 1개를 유지한다.
- 시선과 달리는 중심은 기지 방향이다.

## 피할 요소와 검수

캐릭터별 제외 사항: 폭발물·군복, 다른 인물 들기, 해머 여러 개, 공중 비행

- [ ] 기준 원화와 얼굴·체형·색·소품 수가 일치한다.
- [ ] 적갈색 봄버·숙인 상체·밀착 더플백으로 기지 직진형을 구별한다.
- [ ] 오른쪽 원본과 왼쪽 반전에서 발·장비 기준점이 유지된다.
- [ ] 손·팔·가슴·의상·장비가 부자연스럽게 겹치거나 관통하지 않는다.
- [ ] 기본 포즈와 공격·피격 사이에 키와 카메라 배율이 달라지지 않는다.
