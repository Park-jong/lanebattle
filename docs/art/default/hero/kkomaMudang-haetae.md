## 제작 목적과 대상

전투 중 동자가 다른 소형 인간형 유닛에 묻히는 문제를 해결한다. 동자가 전용 해태에 탄 모습을 하나의 영웅 이미지로 제작한다. 탈것의 넓은 몸, 위에 앉은 동자, 뒤로 솟은 깃발이 작은 화면에서도 한눈에 보여야 한다.

이 문서의 ‘동자’는 현재 코드의 ‘꼬마 무당’을 가리킨다. 대상 키 `hero:kkomaMudang`과 기존 얼굴·머리매듭·의상을 유지한다. 탑승용 해태는 영웅 외형의 일부이며 새 소환 유닛이 아니다. 기존 `ally:haetae`의 원화와 에셋은 그대로 둔다.

기본 본체·스킬·아이콘과 미리보기 32장, 걷기 GIF, 배포용 아틀라스를 제작했다. 현재 `hero:kkomaMudang`은 탑승형을 사용한다. [실제 생성·적용 기록](../GENERATED.md#동자-해태-탑승형-2026-11-05)과 [실행 프롬프트 목록](../../../../scripts/mounted-hero-generation.json)을 함께 확인한다.

## 확정할 외형 방향

**청백색 해태 + 짙은 청록색 갈기 + 붉은 안장 덮개 + 동자 + 금테 붉은 깃발 한 개.**

| 요소 | 기존 아군 해태 | 동자 전용 탑승 해태 |
| --- | --- | --- |
| 몸과 갈기 | 황토빛 석재 몸, 갈색 소용돌이 갈기 | 밝은 청백색 몸, 큰 세 덩어리의 청록 구름 갈기 |
| 체형 | 머리와 앞가슴이 크고 낮은 수호자 | 몸통이 조금 길고 등 위 안장이 분명한 네발 탈것 |
| 위쪽 윤곽 | 짧은 뿔과 둥근 머리 | 안장 위 동자의 머리와 뒤쪽 깃발 기둥 |
| 장식 | 목의 금색 매듭 | 붉은 안장 덮개, 남청 마구, 가슴 금색 장식, 깃발 |
| 이동 인상 | 묵직하게 버티는 전열 | 동자를 안정적으로 태우고 경쾌하게 걷는 수호 신수 |

색을 빼도 ‘동자 + 안장 + 깃발’의 높은 윤곽으로 구분되어야 한다. 기존 해태 이미지를 복사해서 안장만 얹는 방식 대신 체형과 갈기를 새로 그린다. 해태의 짧은 이마 뿔 하나, 둥근 주둥이, 네 발, 구름 갈기라는 공통 특징은 남긴다.

## 동자와 탑승 자세

- 기존 영웅의 둥근 얼굴, 두 머리매듭, 미색 큰 소매, 적색 옷깃, 남청 바지, 황색 허리 매듭을 유지한다.
- 해태의 머리 뒤, 등 중앙보다 약간 앞에 걸터앉는다. 상체 전체와 가까운 쪽 다리가 보이도록 한다.
- 오른손에는 기존 금빛 방울 하나를 들고, 왼손은 안장 앞 손잡이를 잡는다. 고삐를 입에 물리거나 손에서 여러 줄이 늘어지게 하지 않는다.
- 양 무릎으로 안장을 감싸며 발은 해태 몸 옆에 둔다. 동자의 발과 해태의 다리가 이어진 것처럼 보이지 않게 색과 외곽선을 분리한다.
- 해태 갈기가 동자의 얼굴과 방울을 가리지 않는다. 작은 화면에서 동자의 머리는 해태 머리 너비의 약 55~65%를 확보한다.
- 표정은 씩씩하고 태평한 미소. 동물 머리를 왕관처럼 쓰거나 해태와 몸이 합쳐진 모습으로 만들지 않는다.

## 마구와 깃발

| 부위 | 제작 기준 |
| --- | --- |
| 안장 | 남청색 낮은 안장 하나. 앞 손잡이와 뒤 받침이 보이고 동자의 골반 아래에 고정된다. |
| 안장 덮개 | 붉은 천 한 장을 등 양쪽으로 내린다. 가까운 쪽에는 굵은 금테와 큰 구름 문양 하나만 넣는다. 발을 가리지 않는 길이. |
| 마구 | 가슴띠와 배 둘레띠를 남청색의 넓은 띠로 표현한다. 가슴띠 중앙에 금색 둥근 장식 하나. 몸을 통과하는 끈은 금지. |
| 매듭 | 가까운 쪽 안장 뒤에 큰 금색 매듭 하나와 짧은 술 두 가닥. 작은 장신구를 온몸에 추가하지 않는다. |
| 깃대 | 안장 뒤 받침에 고정한 깃대 하나. 오른쪽을 볼 때 동자의 뒤인 화면 왼쪽에 선다. 동자가 손으로 들지 않는다. |
| 깃발 | 붉은 직사각 천 한 장, 굵은 금테, 가운데 좌우 대칭 금색 매듭 문양 하나. 진행 반대인 왼쪽으로 펼쳐지고 끝에 완만한 물결 두 굽이가 생긴다. |
| 깃발 높이 | 깃대 끝은 동자 머리보다 약 10~14 화면 px 높게 보이는 것을 목표로 한다. 깃천이 동자 얼굴을 덮지 않는다. |

깃발의 문양은 그림으로만 표현한다. 글자·한자·숫자를 넣지 않아 좌우 반전해도 자연스럽게 보이게 한다. 장식의 우선순위는 깃발 → 붉은 덮개 → 넓은 가슴띠이며, 작은 축소본에서는 세부 무늬를 줄인다.

## 걷기 모션: 필수 4프레임

기존 `walk_00`~`walk_03` 이름을 사용한다. 발을 번갈아 드는 실제 자세 네 개를 만들며, 대기 이미지의 위치나 크기만 바꾼 프레임으로 채우지 않는다. 기본 재생은 8fps, `00 → 01 → 02 → 03 → 00` 반복이다. 4프레임 한 주기는 0.5초다. 실제 이동은 게임 좌표가 담당하고 그림 안에서는 제자리 걷기를 한다.

가까운 쪽 다리와 먼 쪽 다리는 카메라 기준이다. 먼 쪽은 조금 어둡게 칠해 구별한다. 네 박의 발 순서는 **가까운 뒷발 → 가까운 앞발 → 먼 뒷발 → 먼 앞발**이며 각 컷에서는 해당 발 하나만 들어 앞으로 옮긴다. 나머지 세 발은 지면을 지지한다. 마지막에서 첫 컷으로도 같은 보행 리듬이 이어져야 한다.

| 파일 | 해태의 다리·체중 | 동자·마구·깃발 |
| --- | --- | --- |
| `walk_00.png` | 가까운 뒷발을 지면에서 들어 앞으로 옮긴다. 가까운 앞발은 앞에서 버티고 먼 두 발은 체중을 받는다. 몸통은 기준 높이. | 동자는 똑바로 앉고 방울은 몸 옆. 깃발 천은 뒤로 완만하게 펴진 중간 형태. |
| `walk_01.png` | 가까운 뒷발을 내려 지지하고 가까운 앞발을 들어 앞으로 옮긴다. 몸통과 머리가 원본 기준 최대 6px 내려간다. | 동자는 안장과 함께 내려가며 무릎이 조금 굽는다. 술과 깃천 끝은 관성으로 한 박 늦게 올라간다. |
| `walk_02.png` | 가까운 앞발을 내려 지지하고 먼 뒷발을 들어 앞으로 옮긴다. 몸통은 기준 높이로 복귀한다. | 동자 상체가 중심으로 돌아온다. 방울 손은 원본 기준 4~6px만 흔들린다. 깃천 끝이 낮아지는 중간 형태. |
| `walk_03.png` | 먼 뒷발을 내려 지지하고 먼 앞발을 들어 앞으로 옮긴다. 몸통과 머리가 원본 기준 최대 6px 내려간다. 다음 컷에서 먼 앞발을 내린다. | 동자는 두 번째 작은 내려앉음. 깃천 끝은 다시 올라오는 중간 형태로 00에 연결된다. |

발 들기 높이는 원본 기준 약 12~20px, 전후 이동 폭은 약 20~28px부터 조정한다. 동자만 해태에서 분리되어 튀거나 안장이 등 위를 미끄러지면 안 된다. 깃대 뿌리는 안장 뒤에 고정하고 끝만 2~3도 이내로 흔든다. 천 끝과 매듭 술만 지연되어 움직인다. 네 발이 동시에 떠 있는 점프나 달리기 자세는 이 걷기 세트에 넣지 않는다.

## 전체 이미지 목록과 동작

첫 제작 묶음은 기준 원화 `idle_00`와 걷기 4장, 총 5장이다. 실제 영웅 외형을 교체할 때는 아래 나머지 동작도 같은 탑승 형태로 완성해 도보 이미지와 섞이지 않게 한다.

| 파일 | 컷 수 | 자세 순서 |
| --- | --- | --- |
| `idle_00`~`idle_01` | 2 | 네 발로 서서 동자가 방울을 듦 → 작은 호흡, 깃천과 술이 조금 가라앉음 |
| `walk_00`~`walk_03` | 4 | 위 걷기 표를 그대로 적용 |
| `attack_00`~`attack_03` | 4 | 동자가 방울을 당김 → 안장 위에서 방울을 앞아래로 흔듦 → 팔을 뻗은 여운 → 기본 자세. 해태는 네 발로 버팀 |
| `hit_00`~`hit_01` | 2 | 해태가 다리를 굽혀 충격을 받고 동자가 손잡이를 붙잡음 → 둘이 함께 자세 회복 |
| `spawn_00`~`spawn_02` | 3 | 둘이 함께 옅게 나타남 → 외형이 완성됨 → 기본 대기. 다른 개체나 배경 효과를 합성하지 않음 |
| `death_00`~`death_03` | 4 | 해태가 낮게 앉고 동자가 방울을 끌어안음 → 함께 웅크림 → 둘의 외형이 옅어짐 → 완전 투명. 동자가 따로 떨어지지 않음 |
| `skill_fan_00`~`skill_fan_03` | 4 | 동자가 안장 위에서 부채를 꺼냄 → 펼침 → 전방으로 부침 → 접음 |
| `skill_blessing_00`~`skill_blessing_02` | 3 | 부적을 가슴 앞에 모음 → 팔을 펼침 → 손잡이와 방울을 원위치. 해태는 고개만 조금 듦 |
| `skill_blade_00`~`skill_blade_03` | 4 | 동자가 안장 위에서 팔을 벌림 → 몸을 왼쪽으로 기울임 → 소매를 오른쪽으로 크게 흔듦 → 기본 자세. 해태는 낮게 버팀 |
| `preview.png` | 1 | 탑승체 전체와 깃발이 보이는 대표 대기 포즈 |
| `icon.png` | 1 | 동자와 해태 얼굴이 함께 보이는 구도 |

본체 기본 19장 + 스킬 본체 11장 + 미리보기·아이콘 2장 = **32장**이다. 파일 확장자를 생략한 표의 이름에는 모두 `.png`를 붙인다. `death_03`만 투명 빈 프레임을 허용한다. 기존 `fx_bell`·`fx_fan`·`fx_blessing`·`fx_blade` 이미지는 재사용 후보로 두고 본체 32장과 분리한다.

탑승 해태의 발톱 공격·붙잡기 동작은 만들지 않는다. 기본 공격과 스킬의 주체는 현재 영웅과 동일하다. 방울 공격 시 손을 해태 얼굴 앞아래로 내밀어 사거리 인상을 유지하고, 새 사거리·돌진·피해 판정을 추가하지 않는다. 부활은 반드시 둘이 함께 등장한다.

이미지 생성 시 참고 원본·도구·일시·사용 프롬프트·프레임별 수정 이력을 기록한다. `skin.json`은 현행 구조에 맞는 `origin`, `clips`를 사용하고, 걷기는 `frames: ["walk_00", "walk_01", "walk_02", "walk_03"]`, `fps: 8`, `loop: true`로 지정한다. 원본 캔버스·몸체 경계·방울과 안장 부착점은 제작 메모에 함께 기록한다.

실제 배포 대상은 `public/assets/characters/runtime/hero-kkomaMudang-mounted-haetae.png`와 대응 JSON, 그리고 `public/assets/characters/manifest.json`이다. 원래 도보형은 `output/art-generation/revisions/mounted-haetae/original-foot-hero/`에 보존했고, 새 세트는 정식 `output/art-generation/source-assets/hero/kkomaMudang/default/`에도 반영했다. 텍스처 키와 대상 키는 유지한다.

이미지는 내장 `image_gen`으로 생성했다. 실제 제작에서는 동작별 시트를 각각 생성한 뒤 Node sharp로 프레임을 분리·정렬했다. 한 클립 안에서는 공통 배율을 쓰며 최종 PNG 한 장에는 한 포즈만 담긴다. 등장 3장은 새 대기 원화의 알파를 단계적으로 올리고, 마지막 퇴장 프레임은 완전 투명으로 제작했다. 최종 프롬프트·원본 경로는 실행 목록에 보존했다.

재구성은 `npm install --prefix output/art-generation/tooling sharp` 후 `node scripts/build-mounted-hero.mjs`로 수행한다. 일반 전체 패킹 스크립트도 새 원본의 `bodyBounds`, `displayHeight`, `displayTop`, `runtimeLimit`을 유지하도록 수정했다.

현재 구현을 읽고 확인한 적용 주의점:

1. `CharacterRenderer.ts`는 `HERO.height / art.bodyHeight`로 표시한다. 지금은 영웅 높이가 40이어서 전체 그림을 교체하기만 하면 동자와 탈것이 함께 작아진다. **동자+해태 몸체의 표시 높이 약 64px, 깃발 포함 전체 높이 약 76~80px**를 첫 조정값으로 삼는다. 실제 전투에서 판독성과 가림 정도를 보고 확정한다.
2. 충돌 크기 `24×40`, 이동 속도, 피해, 공격 사거리, 부활 규칙은 유지한다. 렌더러의 표시 높이를 별도로 두고, 이미지 메타데이터의 실제 몸체 높이를 거짓으로 줄여 확대하지 않는다.
3. `pack-runtime-art.py`는 현재 알파 외접 영역 전체를 `bodyHeight`로 계산한다. 높은 깃발까지 포함되므로 탑승형은 깃발을 제외한 몸체 경계를 별도로 지정하는 처리가 필요하다. 512px 원본을 현행 영웅 제한 128px로 축소한 뒤에도 깃발·눈·손이 남는지 확인한다.
4. `battlefield.ts`의 상단 위치와 머리 위 체력바·피해 숫자 배치도 표시 높이에 맞춰 확인한다. 지면 깊이 정렬과 그림자는 해태의 발 기준점을 따른다. 깃발이 위쪽 레인을 가리는지도 확인한다.
5. 영웅은 현재 빙의 중 `ally:<빙의 대상>` 외형을 사용한다. 기존 빙의 표시 규칙을 유지하며, 빙의가 끝나면 탑승형으로 돌아온다. 부활·방향 전환·일시정지에서도 발과 안장 위치가 튀지 않아야 한다.
6. 기본 공격은 실제 판정 순간 `attack_01`부터 재생하는 현재 동작에 맞춘다. 그림의 준비 포즈 때문에 공격을 지연하지 않는다. 스킬 효과는 기존 이벤트와 분리된 에셋을 사용한다.

## 제작 순서와 검수

1. 기존 영웅과 기존 해태를 참고해 새 `idle_00` 원화 한 장을 만든다. 원화 자체와 기존 영웅 얼굴을 기준으로 정체성을 확인한다.
2. 기존 해태와 새 탑승형을 나란히, 실제 표시 크기와 흑백으로 비교한다. 동자·안장·깃발의 세 윤곽이 남는지 먼저 확인한다.
3. 새 원화를 매번 참조해 걷기 네 장을 만든다. 각 컷을 독립된 새 캐릭터로 다시 해석하지 않는다.
4. 같은 캔버스·기준점으로 정리한 뒤 `00→01→02→03→00`을 8fps로 재생한다. 마지막→첫 컷 연결을 포함해 발 미끄러짐, 안장 이탈, 깃대 떨림을 검사한다.
5. 걷기가 자연스러우면 나머지 27장을 제작한다. 스킬에서도 탑승 상태와 장식 개수가 유지되어야 한다.
6. 실제 적용 시 밝은 배경·어두운 배경·유닛 밀집 상황·좌우 방향·빙의와 부활을 확인하고, 코드 변경에 맞는 테스트와 빌드를 실행한다.

- [ ] 기존 갈색 해태와 색 없이도 구분된다.
- [ ] 동자 1명, 해태 1마리, 다리 4개, 뿔 1개, 꼬리 1개, 깃대·깃발 각 1개다.
- [ ] 방울·가슴 장식·안장 매듭이 프레임마다 복제되거나 사라지지 않는다.
- [ ] 걷기 네 컷의 발 자세가 다르고, 매 컷 세 발이 지면을 지지한다.
- [ ] 발이 땅속으로 들어가거나 프레임마다 루트 좌표가 흔들리지 않는다.
- [ ] 동자의 골반은 안장에 붙어 있고 깃대 뿌리도 고정되어 있다.
- [ ] 오른쪽과 왼쪽 모두 동자 얼굴·방울·해태 얼굴이 읽힌다.
- [ ] 모든 프레임의 가장자리에서 깃발·뿔·꼬리·방울이 잘리지 않는다.
- [ ] 작은 크기에서 깃발과 붉은 안장 덮개가 효과에 묻히지 않는다.
- [ ] 실제 PNG와 걷기 미리보기 검수가 끝난 뒤 제작 상태를 갱신한다.
