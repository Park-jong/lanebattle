# 동자 · 해태 탑승형 이미지 생성 프롬프트

작성일: 2026-11-05 · 상태: 아래 설계를 바탕으로 이미지 생성·적용 완료

[외형·동작·적용 명세](kkomaMudang-haetae.md)

실행한 최종 프롬프트는 [생성 작업 목록](../../../../scripts/mounted-hero-generation.json)에 보존했다. 실제 제작에서는 기준 원화 1장과 동작별 시트 6장, 아이콘 1장을 내장 `image_gen`으로 생성하고 최종 낱장 PNG로 분리했다. 아래 개별 프롬프트는 특정 프레임을 다시 만들 때 사용한다. 등장·퇴장 알파와 최종 정렬 방식은 제작 명세를 따른다.

## 사용 순서와 참고 이미지

기준 원화 한 장을 만든 다음, 확정된 새 원화를 참조해 각 프레임을 편집 생성한다. 처음부터 모든 동작을 한 장짜리 시트로 생성하지 않는다. 다리 자세와 소품을 개별 확인한 뒤 아틀라스로 묶는다.

최초 원화에는 다음 기존 런타임 아틀라스에서 대표 포즈를 참고한다. 기존 해태는 화풍과 구별 대상의 참고이며 새 탈것의 외형을 그대로 복제하는 참조가 아니다.

- 영웅: `public/assets/characters/runtime/hero-kkomaMudang.png`의 `preview` 또는 `idle_00`.
- 기존 해태: `public/assets/characters/runtime/ally-haetae.png`의 `preview` 또는 `idle_00`.
- 각 포즈의 위치는 같은 이름의 JSON 아틀라스로 확인한다. 전체 시트를 참고할 경우에도 출력은 한 포즈만 요구한다.
- 이동·공격·스킬 생성에는 **새 탑승형 `idle_00.png`를 우선 참조**한다. 수정 재생성 시에는 해당 포즈도 함께 참조한다.

아래의 목표 해상도·색상값·픽셀 좌표는 최종 파일 기준이다. 생성 도구가 정확한 크기나 좌표를 지원하지 않으면 출력에서 확인한 뒤 캔버스와 기준점을 정리한다. 프롬프트만으로 일치했다고 간주하지 않는다. 생성 시 실제 투명 배경 옵션을 켠다.

## 5. 미리보기와 아이콘

기준 원화를 참조하고 각 블록을 단독으로 사용한다.

### `preview.png`

```text
참조 이미지와 동일한 동자·전용 해태·마구·깃발을 512×512 투명 PNG용 대표 전신 포즈로 그린다. 오른쪽을 보는 약한 3/4 측면, 네 발로 서서 동자가 방울을 들고 씩씩하게 웃는 기본 자세. 동자 얼굴, 해태 얼굴, 붉은 안장 덮개와 위로 솟은 깃발 한 개가 모두 보인다. 깃발·뿔·꼬리를 포함한 외형 전체에 사방 여백을 둔다. 외형과 색, 장식 개수를 바꾸지 않는다. 배경, 바닥 그림자, 글자, 테두리, UI와 효과는 없다.
```

### `icon.png`

```text
참조 이미지와 동일한 탑승 동자와 청백색 해태의 영웅 아이콘. 목표 128×128 투명 PNG. 동자 얼굴을 위쪽 중앙에, 해태 얼굴을 아래쪽 오른편에 두어 두 얼굴이 함께 크게 보인다. 동자의 두 머리매듭, 미색 소매와 적색 옷깃, 해태의 청록 구름 갈기와 짧은 금빛 뿔, 붉은 안장 덮개 일부를 유지한다. 동자와 해태가 한 탑승 캐릭터임을 알 수 있는 구도. 깃발은 생략하거나 모서리에 붉은 천 일부만 남긴다. 초상화 비율로 구도를 조정하되 캐릭터 디자인은 바꾸지 않는다. 배경, 글자, 테두리, UI와 광원 효과는 없다.
```

## 6. 문제별 수정 프롬프트

문제가 있는 프레임과 기준 원화를 함께 참조하고 필요한 지시 하나를 사용한다.

| 문제 | 수정 지시 |
| --- | --- |
| 기존 해태와 비슷함 | 기준 원화의 동자와 구도를 유지한다. 해태 몸을 청백색, 갈기를 큰 청록 구름 세 덩어리로 수정하고 붉은 덮개·남청 가슴띠·안장 뒤 깃발을 명확하게 한다. 황토색 몸과 갈색 소용돌이 갈기로 돌아가지 않는다. |
| 다리 개수 오류 | 해태의 앞다리 두 개와 뒷다리 두 개, 총 네 다리만 남긴다. 동자의 바지 입은 다리는 안장 옆에 별도로 유지한다. 지정한 한 발만 들고 나머지 세 발은 접지한다. 머리와 장식과 카메라는 유지한다. |
| 탑승자 이탈 | 동자의 골반을 안장 중앙에 붙이고 양 무릎이 해태 몸 옆을 감싸게 수정한다. 해태 등에 안장이 고정되고 동자와 안장 사이에는 빈틈이 없다. 얼굴과 옷, 현재 발 자세는 유지한다. |
| 깃발이 얼굴을 가림 | 깃대 뿌리는 안장 뒤에 유지하고 깃천만 화면 왼쪽 뒤로 펼쳐 동자 얼굴·해태 뿔과 떨어뜨린다. 깃대와 깃발은 각각 하나다. 몸체와 동자 크기는 바꾸지 않는다. |
| 장식이 너무 복잡함 | 작은 구슬·문양·금속 조각을 정리하고 붉은 덮개, 넓은 남청 가슴띠, 금색 둥근 장식 하나, 큰 매듭 하나, 깃발 한 개만 명확하게 남긴다. 캐릭터 윤곽과 포즈는 유지한다. |
| 걷기가 정지 자세 같음 | 지정한 스윙 다리의 관절을 굽히고 발끝을 지면에서 분명히 들어 앞으로 옮기는 중간 자세로 수정한다. 다른 세 발은 몸을 지지하고 얼굴·안장·깃대 뿌리는 유지한다. 이미지 전체를 기울이거나 이동하는 방식으로 대체하지 않는다. |

생성 후에는 [제작 명세의 검수 기준](kkomaMudang-haetae.md#제작-순서와-검수)에 따라 작은 표시 크기와 걷기 반복 재생을 확인한다. 이미지의 외형 검수와 게임 코드 적용 검증은 각각 기록한다.
