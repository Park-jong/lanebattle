## 식별과 제작 범위

- 분류: 아군
- 대상 키: `ally:gumiho`
- 기본 스킨: `default`
- 코드 기준: `src/data/allies.ts`
- 현재 게임의 기준 외형 영역: **24×38px**. 원화 해상도와 구별하며, 실제 충돌·사거리는 변경하지 않는다.
- 원본 PNG 캔버스: **384×320px**, 투명 RGBA, 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면.
- 예정 이미지 경로: `public/assets/characters/ally/gumiho/default/`

## 캐릭터 콘셉트

축제의 붉은 등불을 닮은 여우불을 다루는 우아하고 장난스러운 수호 요괴. 사람 체형을 과하게 강조하지 않고, 아홉 꼬리의 부채꼴 실루엣으로 정예 마법 아군임을 알린다.

- 전투 역할과 읽혀야 할 특징: 범위 여우불과 화상. 단일 꼬리 궁수보다 넓은 존재감.
- 실루엣: 작은 여우 얼굴, 길고 단정한 저고리, 뒤쪽에 층층이 펼친 아홉 꼬리.
- 얼굴과 성격: 가늘게 웃는 눈과 여유 있는 미소. 모든 포즈에서 밝고 친근한 인상.
- 의상·재질·소품: 미색 한복형 겉옷과 적색 옷깃, 큰 매듭 한 개, 미색 꼬리의 적색 끝, 손 위 여우불 구슬.
- 기본 팔레트: 미색 #F5E9D4 / 적 #C64C50 / 살구 #F3B48A / 금 #D8B568 / 먹 #292637.
- 소형 화면에서 남길 요소: 부채꼴 아홉 꼬리·미색 의상·붉은 불구슬

## 이미지 파일과 프레임 설명

아래 파일명은 위 예정 경로 아래의 낱장 PNG다. 같은 행의 파일은 왼쪽부터 설명 순서에 대응한다. 모든 본체 프레임은 같은 캔버스·배율·기준점을 사용한다. 정식 제작 목록이며, 첫 연결은 `idle_00.png`와 `walk_00.png~walk_03.png`부터 시작할 수 있다.

| 파일명 | 프레임 순서와 이미지 설명 |
| --- | --- |
| `idle_00.png` / `idle_01.png` | 손 위에 불구슬을 작게 띄운 자세 → 꼬리 끝이 순차적으로 한 번 흔들림. |
| `walk_00.png` / `walk_01.png` / `walk_02.png` / `walk_03.png` | 옷자락 아래 왼발을 내밀고 꼬리 부채가 뒤로 기움 → 중심이 앞으로 이동하며 꼬리 아래층이 따라옴 → 오른발을 내밀고 꼬리 부채가 원위치로 옴 → 옷자락과 꼬리가 부드럽게 정리됨. 마지막에서 첫 프레임으로 자연스럽게 이어진다. |
| `attack_00.png` / `attack_01.png` / `attack_02.png` / `attack_03.png` | 한 손을 가슴 가까이 당겨 불구슬을 모음 → 손바닥을 정면으로 펼침 → 손끝 앞에서 구슬이 떨어져 나가는 자세 → 손을 낮추고 꼬리를 정리함 |
| `hit_00.png` / `hit_01.png` | 귀가 낮아지고 꼬리 부채가 안쪽으로 조금 오므라듦 → 기준 자세를 회복한다. |
| `spawn_00.png` / `spawn_01.png` / `spawn_02.png` | 아홉 개의 작은 불씨가 꼬리 끝을 이루며 몸체가 나타남 → 실루엣이 완성됨 → 기본 대기 자세. |
| `death_00.png` / `death_01.png` / `death_02.png` / `death_03.png` | 꼬리를 앞쪽으로 모아 몸을 감싸며 놀란 표정이 됨 → 힘이 풀림 → 작은 기운 조각으로 흩어짐 → 몸이 사라짐. |
| `preview.png` | 512×512, 기본 스킨의 전체 외형과 대표 소품이 보이는 오른쪽 방향 대표 포즈. 바닥 그림자·배경·문자 없음. |
| `icon.png` | 128×128, 여우 얼굴 뒤로 펼쳐진 꼬리 부채의 윗부분 중심의 구도. UI 테두리·이름·비용 숫자는 넣지 않는다. |

### 고유 동작·효과 파일

| 파일명 | 이미지와 사용 조건 |
| --- | --- |
| `projectile_orb_00.png / projectile_orb_01.png` | 128×128. 작은 적색 여우불 구슬이 말랑하게 맥동하는 두 프레임. |
| `fx_foxfire_burst_00.png / fx_foxfire_burst_01.png / fx_foxfire_burst_02.png` | 256×256. 불씨 모임 → 꽃처럼 퍼지는 둥근 불꽃 → 잔불. 실제 범위 피해 순간에만 나타낸다. |

고유 클립은 공통 `AnimationState`에 아직 등록되지 않은 확장 제안이다. 구현 때 별도 클립 매핑과 실제 능력 이벤트를 연결한다. 효과 이미지는 몸체에 합성하지 않고 별도 에셋 키로 등록한다. 오라·파동 이미지는 현재 전투의 실제 범위에 맞춰 화면에서 크기를 정한다.

## 방향·기준점·동작 주의점

기준 원화에서 아홉 꼬리의 뿌리와 순서를 확정하고 매 프레임 꼬리가 증감하지 않게 한다. 겹쳐 보이는 꼬리는 원화 검수 시 번호로 확인하되 번호를 납품 이미지에 넣지 않는다. 꼬리 폭은 장식 여백이고 충돌 반경은 그대로다.

공격 프레임의 “준비 → 타격/발사 → 회수”는 자세 제작 순서다. 현재 즉시 판정을 유지하는 첫 구현에서는 실제 판정 순간에 타격/발사 자세를 맞추고 앞 준비 프레임은 생략하거나 별도 예고에 사용한다. 피해를 주기 위해 애니메이션 종료를 기다리지 않는다.

추가 스킨의 파일명·클립 구성은 기본 스킨과 맞추고, 경로의 `default/`를 해당 스킨 ID로 바꾼다. 능력·속도·비행 여부·판정은 스킨 때문에 바꾸지 않는다.

## 제작용 설명문

> 한국 민담을 재해석한 요괴 마을 축제 게임용 2D 캐릭터. 둥근 카툰 형태, 굵고 일정한 먹색 외곽선, 단순한 면 채색과 약한 한지 느낌. 미색 한복형 의상을 입은 친근한 구미호, 확실하게 아홉 개인 큰 꼬리가 부채처럼 펼쳐지고 꼬리 끝은 붉다. 손 위에 작은 붉은 여우불 구슬. 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면, 투명 배경, 캐릭터 전체와 소품이 캔버스 안에 들어온다. 한 장에는 한 포즈만 그린다. 프레임 변형 시 확정된 기준 원화의 체형·얼굴·색·소품을 유지한다.

피할 요소: 선정적인 의상과 체형, 꼬리 개수 변화, 공포스럽게 찢어진 입. 공통 제외 사항은 사실적인 공포·유혈, 화면을 가리는 광원, 배경 풍경, 글자·워터마크, 다른 캐릭터 혼입이다.

## 검수 기준

- [ ] 콘셉트·실루엣·기본 팔레트가 확정된 기준 원화와 일치한다.
- [ ] 작은 게임 표시 크기에서 위의 식별 요소가 남는다.
- [ ] 프레임 간 크기·기준점·소품 개수와 위치가 의도 없이 달라지지 않는다.
- [ ] 좌우 반전해도 문양·소품·실루엣이 깨지지 않는다.
- [ ] 알파 배경에 흰 테두리나 잘린 무기·꼬리·날개가 없다.
- [ ] 파일명·해상도·색상 프로필과 출처·사용 조건 기록을 확인했다.

## 모든 추가 스킨의 동작 컷

이 문서의 `default`와 위 표의 모든 추가 스킨은 각각 **공통 본체 19컷 + 위 고유 동작·효과 컷 전체**를 납품한다. 추가 스킨은 의상·배색을 바꾸어도 기본 동작 목록과 파일명을 줄이지 않는다.

| 동작 | 파일 범위 | 컷 수 |
| --- | --- | --- |
| 대기 | `idle_00.png` ~ `idle_01.png` | 2 |
| 이동·롤러·비행 | `walk_00.png` ~ `walk_03.png` | 4 |
| 기본 공격 | `attack_00.png` ~ `attack_03.png` | 4 |
| 피격 | `hit_00.png` ~ `hit_01.png` | 2 |
| 등장·부활 | `spawn_00.png` ~ `spawn_02.png` | 3 |
| 퇴장 | `death_00.png` ~ `death_03.png` | 4 |
| 공통 본체 합계 | 모든 스킨에 동일하게 적용 | **19** |

- 위의 「이미지 파일과 프레임 설명」 표에 적힌 컷별 자세와 제작 순서를 모든 스킨에 적용한다.
- 고유 스킬·비행·성장·착지·소환·효과도 위 파일 목록대로 스킨별로 준비한다. 본체 의상에 영향 없는 공용 효과는 출처를 명시해 재사용할 수 있다.
- 추가 스킨의 폴더는 기존 경로의 `default/`를 해당 스킨 ID로 바꾼다. 본체는 해당 스킨의 의상을 입은 컷이어야 한다.
- 승인된 해당 스킨의 `idle_00.png`를 항상 참조하고, 이동·공격·피격 컷을 같은 자세의 복사본으로 채우지 않는다.
- 한 PNG에 한 포즈를 그리되 한 스킨은 여러 PNG의 묶음이다. 시트·아틀라스는 이 컷들을 정리하는 형식이다.
- 파츠 리깅은 제작 보조로 사용할 수 있다. 최종 본체 PNG는 동일 캔버스·배율·방향·피벗을 유지한다.
