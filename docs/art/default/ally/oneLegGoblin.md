## 식별과 제작 범위

- 분류: 아군
- 대상 키: `ally:oneLegGoblin`
- 기본 스킨: `default`
- 코드 기준: `src/data/allies.ts`
- 현재 게임의 기준 외형 영역: **22×36px**. 원화 해상도와 구별하며, 실제 충돌·사거리는 변경하지 않는다.
- 원본 PNG 캔버스: **256×320px**, 투명 RGBA, 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면.
- 예정 이미지 경로: `public/assets/characters/ally/oneLegGoblin/default/`

## 캐릭터 콘셉트

바람을 타듯 한 다리로 통통 튀는 축제의 재주꾼. 한쪽 다리가 몸의 정중앙에서 이어지는 초자연적인 도깨비 체형으로, 빠른 돌격을 가볍고 익살스럽게 보여 준다.

- 전투 역할과 읽혀야 할 특징: 빠른 접근과 소환 후 첫 공격의 강한 돌격.
- 실루엣: 길쭉한 물방울 몸, 확실하게 한 개인 다리, 뒤로 뻗은 흰 머리띠, 짧은 나무 몽둥이.
- 얼굴과 성격: 한쪽 눈썹을 치켜든 승부욕 있는 웃음.
- 의상·재질·소품: 청색 민소매 저고리, 흰색 긴 머리띠, 한 발의 짚신, 가벼운 목재 몽둥이.
- 기본 팔레트: 청 #367CC4 / 백 #F1F0E6 / 하늘 #9DD9E5 / 황토 #A67648 / 먹 #292637.
- 소형 화면에서 남길 요소: 한 다리·흰 머리띠·앞으로 기운 몸

## 이미지 파일과 프레임 설명

아래 파일명은 위 예정 경로 아래의 낱장 PNG다. 같은 행의 파일은 왼쪽부터 설명 순서에 대응한다. 모든 본체 프레임은 같은 캔버스·배율·기준점을 사용한다. 정식 제작 목록이며, 첫 연결은 `idle_00.png`와 `walk_00.png~walk_03.png`부터 시작할 수 있다.

| 파일명 | 프레임 순서와 이미지 설명 |
| --- | --- |
| `idle_00.png` / `idle_01.png` | 한 발로 균형을 잡고 선 자세 → 무릎을 조금 굽히며 머리띠가 내려앉음. |
| `walk_00.png` / `walk_01.png` / `walk_02.png` / `walk_03.png` | 한 발이 땅을 짚고 무릎을 깊게 접음 → 다리를 펴며 몸이 위앞으로 튀어 오름 → 유일한 발을 몸 아래로 접고 공중을 지남 → 발을 앞으로 내밀어 다음 착지를 준비함. 마지막에서 첫 프레임으로 자연스럽게 이어진다. |
| `attack_00.png` / `attack_01.png` / `attack_02.png` / `attack_03.png` | 한 발을 단단히 딛고 몸을 앞으로 낮춤 → 머리와 어깨를 앞세워 짧은 몽둥이를 정면으로 내밈 → 몸이 앞으로 쏠리고 머리띠가 뒤로 길게 따라옴 → 한 발로 중심을 회복함 |
| `hit_00.png` / `hit_01.png` | 머리띠가 앞으로 넘어오고 한 발로 비틀거리며 균형을 잡음 → 기준 자세를 회복한다. |
| `spawn_00.png` / `spawn_01.png` / `spawn_02.png` | 바람 매듭처럼 말린 청백색 기운이 풀리며 한 발로 착지함 → 실루엣이 완성됨 → 기본 대기 자세. |
| `death_00.png` / `death_01.png` / `death_02.png` / `death_03.png` | 한 발로 두 번 균형을 잡으려다 둥글게 말려 놀란 표정이 됨 → 힘이 풀림 → 작은 기운 조각으로 흩어짐 → 몸이 사라짐. |
| `preview.png` | 512×512, 기본 스킨의 전체 외형과 대표 소품이 보이는 오른쪽 방향 대표 포즈. 바닥 그림자·배경·문자 없음. |
| `icon.png` | 128×128, 한 다리까지 보이는 상하로 긴 도깨비 실루엣과 흰 머리띠 중심의 구도. UI 테두리·이름·비용 숫자는 넣지 않는다. |

### 고유 동작·효과 파일

| 파일명 | 이미지와 사용 조건 |
| --- | --- |
| `charge_00.png / charge_01.png / charge_02.png` | 본체와 같은 캔버스. 몸 낮추기 → 어깨 돌격의 타격 자세 → 머리띠 회수. 첫 돌격 능력이 실제 발생할 때만 사용. |
| `fx_charge_00.png / fx_charge_01.png` | 256×128. 짧은 청백색 속도 띠가 뒤로 흐르다 사라짐. 본체의 실제 이동은 전투 좌표를 따른다. |

고유 클립은 공통 `AnimationState`에 아직 등록되지 않은 확장 제안이다. 구현 때 별도 클립 매핑과 실제 능력 이벤트를 연결한다. 효과 이미지는 몸체에 합성하지 않고 별도 에셋 키로 등록한다. 오라·파동 이미지는 현재 전투의 실제 범위에 맞춰 화면에서 크기를 정한다.

## 방향·기준점·동작 주의점

네 장의 walk는 좌우 발 교대가 아닌 도약 주기다. 두 번째 다리나 발을 그리지 않는다. 원화의 발 기준점은 일정하게 두고 도약 높이는 포즈 안에서 표현하며 월드 고도와 중복 가산하지 않는다.

공격 프레임의 “준비 → 타격/발사 → 회수”는 자세 제작 순서다. 현재 즉시 판정을 유지하는 첫 구현에서는 실제 판정 순간에 타격/발사 자세를 맞추고 앞 준비 프레임은 생략하거나 별도 예고에 사용한다. 피해를 주기 위해 애니메이션 종료를 기다리지 않는다.

## 제작용 설명문

> 한국 민담을 재해석한 요괴 마을 축제 게임용 2D 캐릭터. 둥근 카툰 형태, 굵고 일정한 먹색 외곽선, 단순한 면 채색과 약한 한지 느낌. 한 다리로 통통 뛰는 가느다란 도깨비, 파란 저고리, 뒤로 날리는 긴 흰 머리띠, 작은 나무 몽둥이와 자신만만한 표정. 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면, 투명 배경, 캐릭터 전체와 소품이 캔버스 안에 들어온다. 한 장에는 한 포즈만 그린다. 프레임 변형 시 확정된 기준 원화의 체형·얼굴·색·소품을 유지한다.

피할 요소: 양다리 보행, 의족이나 상처 묘사, 항상 지면에서 높이 떠 있는 비행 형태. 공통 제외 사항은 사실적인 공포·유혈, 화면을 가리는 광원, 배경 풍경, 글자·워터마크, 다른 캐릭터 혼입이다.

## 검수 기준

- [ ] 콘셉트·실루엣·기본 팔레트가 확정된 기준 원화와 일치한다.
- [ ] 작은 게임 표시 크기에서 위의 식별 요소가 남는다.
- [ ] 프레임 간 크기·기준점·소품 개수와 위치가 의도 없이 달라지지 않는다.
- [ ] 좌우 반전해도 문양·소품·실루엣이 깨지지 않는다.
- [ ] 알파 배경에 흰 테두리나 잘린 무기·꼬리·날개가 없다.
- [ ] 파일명·해상도·색상 프로필과 출처·사용 조건 기록을 확인했다.

## 기본 스킨의 동작 컷

기본 스킨 `default`는 **공통 본체 19컷 + 위 고유 동작·효과 컷 전체**를 납품한다.

| 동작 | 파일 범위 | 컷 수 |
| --- | --- | --- |
| 대기 | `idle_00.png` ~ `idle_01.png` | 2 |
| 이동·롤러·비행 | `walk_00.png` ~ `walk_03.png` | 4 |
| 기본 공격 | `attack_00.png` ~ `attack_03.png` | 4 |
| 피격 | `hit_00.png` ~ `hit_01.png` | 2 |
| 등장·부활 | `spawn_00.png` ~ `spawn_02.png` | 3 |
| 퇴장 | `death_00.png` ~ `death_03.png` | 4 |
| 공통 본체 합계 | 기본 동작 | **19** |

- 위의 「이미지 파일과 프레임 설명」 표에 적힌 컷별 자세와 제작 순서를 기본 스킨에 적용한다.
- 고유 스킬·비행·성장·착지·소환·효과도 위 파일 목록대로 준비한다. 본체 의상에 영향 없는 공용 효과는 출처를 명시해 재사용할 수 있다.
- 승인된 해당 스킨의 `idle_00.png`를 항상 참조하고, 이동·공격·피격 컷을 같은 자세의 복사본으로 채우지 않는다.
- 한 PNG에 한 포즈를 그리되 한 스킨은 여러 PNG의 묶음이다. 시트·아틀라스는 이 컷들을 정리하는 형식이다.
- 파츠 리깅은 제작 보조로 사용할 수 있다. 최종 본체 PNG는 동일 캔버스·배율·방향·피벗을 유지한다.
