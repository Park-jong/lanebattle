## 식별과 제작 범위

- 분류: 아군
- 대상 키: `ally:haetae`
- 기본 스킨: `default`
- 코드 기준: `src/data/allies.ts`
- 현재 게임의 기준 외형 영역: **44×48px**. 원화 해상도와 구별하며, 실제 충돌·사거리는 변경하지 않는다.
- 원본 PNG 캔버스: **384×320px**, 투명 RGBA, 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면.
- 예정 이미지 경로: `public/assets/characters/ally/haetae/default/`

## 캐릭터 콘셉트

서낭당 입구를 지키던 돌사자 같은 신수가 축제 아이들을 보호하러 나온 모습. 무겁고 믿음직하지만 눈썹과 볼은 둥글어 무섭지 않다.

- 전투 역할과 읽혀야 할 특징: 가장 튼튼한 전열과 앞발로 적 붙잡기.
- 실루엣: 큰 머리, 굵은 소용돌이 갈기, 짧은 이마 뿔, 넓은 앞가슴과 네 발.
- 얼굴과 성격: 짙고 둥근 눈썹 아래 선한 눈, 입꼬리가 약간 올라간 수호자 표정.
- 의상·재질·소품: 따뜻한 황토빛 석재 몸과 굵은 갈기 홈, 금색 목매듭. 전신을 세밀한 돌 균열로 덮지 않는다.
- 기본 팔레트: 황 #CDA655 / 돌 미색 #DCCBA5 / 갈기 갈색 #9B7546 / 금 #E3BD62 / 먹 #292637.
- 소형 화면에서 남길 요소: 큰 소용돌이 갈기·짧은 뿔·넓은 앞발

## 이미지 파일과 프레임 설명

아래 파일명은 위 예정 경로 아래의 낱장 PNG다. 같은 행의 파일은 왼쪽부터 설명 순서에 대응한다. 모든 본체 프레임은 같은 캔버스·배율·기준점을 사용한다. 정식 제작 목록이며, 첫 연결은 `idle_00.png`와 `walk_00.png~walk_03.png`부터 시작할 수 있다.

| 파일명 | 프레임 순서와 이미지 설명 |
| --- | --- |
| `idle_00.png` / `idle_01.png` | 고개를 바로 세우고 네 발로 버팀 → 가슴과 갈기가 아주 조금 움직임. |
| `walk_00.png` / `walk_01.png` / `walk_02.png` / `walk_03.png` | 왼앞발과 오른뒷발을 무겁게 디딤 → 머리가 조금 내려가며 체중이 옮겨감 → 오른앞발과 왼뒷발을 디딤 → 가슴과 갈기가 제자리로 돌아옴. 마지막에서 첫 프레임으로 자연스럽게 이어진다. |
| `attack_00.png` / `attack_01.png` / `attack_02.png` / `attack_03.png` | 머리를 조금 당기며 한 앞발을 듦 → 앞발을 정면으로 힘 있게 내밈 → 가슴이 앞으로 실린 자세 → 발을 바닥에 내려 단단히 버팀 |
| `hit_00.png` / `hit_01.png` | 눈을 가늘게 감고 갈기를 움츠리지만 발은 지면을 지킴 → 기준 자세를 회복한다. |
| `spawn_00.png` / `spawn_01.png` / `spawn_02.png` | 황금 매듭 윤곽과 석재 발이 먼저 나타나며 몸이 완성됨 → 실루엣이 완성됨 → 기본 대기 자세. |
| `death_00.png` / `death_01.png` / `death_02.png` / `death_03.png` | 앞발을 접고 앉아 고개를 갸웃하며 놀람 → 힘이 풀림 → 작은 기운 조각으로 흩어짐 → 몸이 사라짐. |
| `preview.png` | 512×512, 기본 스킨의 전체 외형과 대표 소품이 보이는 오른쪽 방향 대표 포즈. 바닥 그림자·배경·문자 없음. |
| `icon.png` | 128×128, 이마 뿔과 소용돌이 갈기가 둘러싼 둥근 얼굴 중심의 구도. UI 테두리·이름·비용 숫자는 넣지 않는다. |

### 고유 동작·효과 파일

| 파일명 | 이미지와 사용 조건 |
| --- | --- |
| `grab_start_00.png / grab_start_01.png` | 본체 캔버스. 앞발을 넓게 벌림 → 정면 아래를 단단히 누르는 자세. |
| `grab_hold_00.png / grab_hold_01.png` | 본체 캔버스. 앞발을 내민 채 가슴의 호흡만 작게 달라지는 유지 동작. 실제 붙잡기 상태 동안만 반복하며 상대 몸은 포함하지 않는다. |

고유 클립은 공통 `AnimationState`에 아직 등록되지 않은 확장 제안이다. 구현 때 별도 클립 매핑과 실제 능력 이벤트를 연결한다. 효과 이미지는 몸체에 합성하지 않고 별도 에셋 키로 등록한다. 오라·파동 이미지는 현재 전투의 실제 범위에 맞춰 화면에서 크기를 정한다.

## 방향·기준점·동작 주의점

발바닥 중심을 고정하고 붙잡기 포즈가 끝나면 일반 상태로 복귀한다. 상대가 사라지거나 해태가 기절·사망하면 유지 자세를 정리한다. 돌갈기는 몸과 연결된 단단한 덩어리로 표현한다.

공격 프레임의 “준비 → 타격/발사 → 회수”는 자세 제작 순서다. 현재 즉시 판정을 유지하는 첫 구현에서는 실제 판정 순간에 타격/발사 자세를 맞추고 앞 준비 프레임은 생략하거나 별도 예고에 사용한다. 피해를 주기 위해 애니메이션 종료를 기다리지 않는다.

## 제작용 설명문

> 한국 민담을 재해석한 요괴 마을 축제 게임용 2D 캐릭터. 둥근 카툰 형태, 굵고 일정한 먹색 외곽선, 단순한 면 채색과 약한 한지 느낌. 한국 축제 마을을 지키는 귀여운 해태 신수, 따뜻한 황토빛 석재 몸, 큰 소용돌이 갈기, 짧은 이마 뿔, 넓은 앞발과 든든한 네 발 자세. 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면, 투명 배경, 캐릭터 전체와 소품이 캔버스 안에 들어온다. 한 장에는 한 포즈만 그린다. 프레임 변형 시 확정된 기준 원화의 체형·얼굴·색·소품을 유지한다.

피할 요소: 날개 달린 서양 사자, 사실적인 맹수 이빨, 실제 갈라진 몸과 파괴 장면. 공통 제외 사항은 사실적인 공포·유혈, 화면을 가리는 광원, 배경 풍경, 글자·워터마크, 다른 캐릭터 혼입이다.

## 검수 기준

- [ ] 콘셉트·실루엣·기본 팔레트가 확정된 기준 원화와 일치한다.
- [ ] 작은 게임 표시 크기에서 위의 식별 요소가 남는다.
- [ ] 프레임 간 크기·기준점·소품 개수와 위치가 의도 없이 달라지지 않는다.
- [ ] 좌우 반전해도 문양·소품·실루엣이 깨지지 않는다.
- [ ] 알파 배경에 흰 테두리나 잘린 무기·꼬리·날개가 없다.
- [ ] 파일명·해상도·색상 프로필과 출처·사용 조건 기록을 확인했다.

## 기본 스킨의 동작 컷

기본 스킨 `default`는 **공통 본체 19컷 + 위 고유 동작·효과 컷 전체**를 납품한다.

| 동작 | 파일 범위 | 컷 수 |
| --- | --- | --- |
| 대기 | `idle_00.png` ~ `idle_01.png` | 2 |
| 이동·롤러·비행 | `walk_00.png` ~ `walk_03.png` | 4 |
| 기본 공격 | `attack_00.png` ~ `attack_03.png` | 4 |
| 피격 | `hit_00.png` ~ `hit_01.png` | 2 |
| 등장·부활 | `spawn_00.png` ~ `spawn_02.png` | 3 |
| 퇴장 | `death_00.png` ~ `death_03.png` | 4 |
| 공통 본체 합계 | 기본 동작 | **19** |

- 위의 「이미지 파일과 프레임 설명」 표에 적힌 컷별 자세와 제작 순서를 기본 스킨에 적용한다.
- 고유 스킬·비행·성장·착지·소환·효과도 위 파일 목록대로 준비한다. 본체 의상에 영향 없는 공용 효과는 출처를 명시해 재사용할 수 있다.
- 승인된 해당 스킨의 `idle_00.png`를 항상 참조하고, 이동·공격·피격 컷을 같은 자세의 복사본으로 채우지 않는다.
- 한 PNG에 한 포즈를 그리되 한 스킨은 여러 PNG의 묶음이다. 시트·아틀라스는 이 컷들을 정리하는 형식이다.
- 파츠 리깅은 제작 보조로 사용할 수 있다. 최종 본체 PNG는 동일 캔버스·배율·방향·피벗을 유지한다.
