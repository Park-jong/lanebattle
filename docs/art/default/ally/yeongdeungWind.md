# 영등 바람 이미지 제작 명세

## 식별과 제작 범위

- 분류: 아군
- 대상 키: `ally:yeongdeungWind`
- 기본 스킨: `default`
- 코드 기준: `src/data/allies.ts`
- 현재 게임의 기준 외형 영역: **24×34px**. 원화 해상도와 구별하며, 실제 충돌·사거리는 변경하지 않는다.
- 원본 PNG 캔버스: **256×320px**, 투명 RGBA, 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면.
- 예정 이미지 경로: `public/assets/characters/ally/yeongdeungWind/default/`

## 캐릭터 콘셉트

축제의 천과 풍경을 흔들며 길을 열어 주는 작은 바람 정령. 영등이라는 이름을 가져온 게임용 캐릭터로, 특정 전승의 정해진 외형이라고 주장하지 않는다.

- 전투 역할과 읽혀야 할 특징: 지상 이동형 마법 지원, 주변 이동·공격 속도와 투사체 빗나감 오라.
- 실루엣: 둥근 물방울 머리, 흰 천 소매 두 개, 아래로 모이는 바람 치맛자락, 작은 발끝.
- 얼굴과 성격: 눈을 초승달처럼 웃고 볼이 둥글게 부풀어 있음.
- 의상·재질·소품: 한지 같은 미색 몸과 청백색 천 띠, 작은 부채. 몸속 소용돌이는 굵은 한 줄만 남긴다.
- 기본 팔레트: 백 #F1EEE0 / 하늘 #B0DCE3 / 청 #67A9C4 / 황 #D7BD78 / 먹 #292637.
- 소형 화면에서 남길 요소: 흰 천 소매·물방울 얼굴·청백색 바람꼬리

## 이미지 파일과 프레임 설명

아래 파일명은 위 예정 경로 아래의 낱장 PNG다. 같은 행의 파일은 왼쪽부터 설명 순서에 대응한다. 모든 본체 프레임은 같은 캔버스·배율·기준점을 사용한다. 정식 제작 목록이며, 첫 연결은 `idle_00.png`와 `walk_00.png~walk_03.png`부터 시작할 수 있다.

| 파일명 | 프레임 순서와 이미지 설명 |
| --- | --- |
| `idle_00.png` / `idle_01.png` | 소매를 펼친 채 조용히 서 있음 → 몸속 소용돌이와 천 끝이 조금 돌아감. |
| `walk_00.png` / `walk_01.png` / `walk_02.png` / `walk_03.png` | 왼쪽 소매가 앞서고 작은 왼발 끝이 나옴 → 아래 천이 앞으로 말리며 중심이 이동함 → 오른 소매가 앞서고 오른발 끝이 나옴 → 천 끝이 뒤로 풀리며 대기 높이로 복귀. 마지막에서 첫 프레임으로 자연스럽게 이어진다. |
| `attack_00.png` / `attack_01.png` / `attack_02.png` / `attack_03.png` | 작은 부채를 몸 옆으로 당김 → 부채를 정면으로 펼침 → 소매가 앞쪽으로 흘러가며 바람을 내보냄 → 부채를 접어 낮춤 |
| `hit_00.png` / `hit_01.png` | 물방울 머리가 납작해졌다 복원되며 두 소매가 움찔함 → 기준 자세를 회복한다. |
| `spawn_00.png` / `spawn_01.png` / `spawn_02.png` | 접힌 흰 천이 펴지며 중앙에 얼굴이 나타남 → 실루엣이 완성됨 → 기본 대기 자세. |
| `death_00.png` / `death_01.png` / `death_02.png` / `death_03.png` | 볼을 부풀린 채 천처럼 작게 접힘 → 힘이 풀림 → 작은 기운 조각으로 흩어짐 → 몸이 사라짐. |
| `preview.png` | 512×512, 기본 스킨의 전체 외형과 대표 소품이 보이는 오른쪽 방향 대표 포즈. 바닥 그림자·배경·문자 없음. |
| `icon.png` | 128×128, 물방울 얼굴과 펼친 흰 소매 중심의 구도. UI 테두리·이름·비용 숫자는 넣지 않는다. |

### 고유 동작·효과 파일

| 파일명 | 이미지와 사용 조건 |
| --- | --- |
| `projectile_wind_00.png / projectile_wind_01.png` | 128×128. 청백색 짧은 소용돌이 바람탄 두 장. 가장자리를 성기게 두어 적 투사체와 구분. |
| `fx_wind_aura_00.png / fx_wind_aura_01.png` | 256×256. 중앙이 비고 바깥에 잎 모양 선 세 개가 흐르는 지원 오라. 실제 범위에 맞춰 낮은 불투명도로 표시. |

고유 클립은 공통 `AnimationState`에 아직 등록되지 않은 확장 제안이다. 구현 때 별도 클립 매핑과 실제 능력 이벤트를 연결한다. 효과 이미지는 몸체에 합성하지 않고 별도 에셋 키로 등록한다. 오라·파동 이미지는 현재 전투의 실제 범위에 맞춰 화면에서 크기를 정한다.

## 방향·기준점·동작 주의점

코드상 비행 아군이 아니므로 새처럼 높은 고도에 띄우지 않는다. 발끝과 천 아래를 지면 기준으로 맞추고, 부유하는 인상은 원화 내부의 작은 흔들림으로 만든다.

공격 프레임의 “준비 → 타격/발사 → 회수”는 자세 제작 순서다. 현재 즉시 판정을 유지하는 첫 구현에서는 실제 판정 순간에 타격/발사 자세를 맞추고 앞 준비 프레임은 생략하거나 별도 예고에 사용한다. 피해를 주기 위해 애니메이션 종료를 기다리지 않는다.

## 제작용 설명문

> 한국 민담을 재해석한 요괴 마을 축제 게임용 2D 캐릭터. 둥근 카툰 형태, 굵고 일정한 먹색 외곽선, 단순한 면 채색과 약한 한지 느낌. 흰 천과 청백색 바람으로 이루어진 작은 둥근 정령, 물방울 얼굴과 웃는 눈, 펼친 한복 소매 같은 천, 작은 부채와 지면 가까운 발끝. 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면, 투명 배경, 캐릭터 전체와 소품이 캔버스 안에 들어온다. 한 장에는 한 포즈만 그린다. 프레임 변형 시 확정된 기준 원화의 체형·얼굴·색·소품을 유지한다.

피할 요소: 항상 공중 높이 떠 있는 비행 유닛 표현, 거대 토네이도, 반투명으로 얼굴이 사라지는 처리. 공통 제외 사항은 사실적인 공포·유혈, 화면을 가리는 광원, 배경 풍경, 글자·워터마크, 다른 캐릭터 혼입이다.

## 검수 기준

- [ ] 콘셉트·실루엣·기본 팔레트가 확정된 기준 원화와 일치한다.
- [ ] 작은 게임 표시 크기에서 위의 식별 요소가 남는다.
- [ ] 프레임 간 크기·기준점·소품 개수와 위치가 의도 없이 달라지지 않는다.
- [ ] 좌우 반전해도 문양·소품·실루엣이 깨지지 않는다.
- [ ] 알파 배경에 흰 테두리나 잘린 무기·꼬리·날개가 없다.
- [ ] 파일명·해상도·색상 프로필과 출처·사용 조건 기록을 확인했다.

## 기본 스킨의 동작 컷

기본 스킨 `default`는 **공통 본체 19컷 + 위 고유 동작·효과 컷 전체**를 납품한다.

| 동작 | 파일 범위 | 컷 수 |
| --- | --- | --- |
| 대기 | `idle_00.png` ~ `idle_01.png` | 2 |
| 이동·롤러·비행 | `walk_00.png` ~ `walk_03.png` | 4 |
| 기본 공격 | `attack_00.png` ~ `attack_03.png` | 4 |
| 피격 | `hit_00.png` ~ `hit_01.png` | 2 |
| 등장·부활 | `spawn_00.png` ~ `spawn_02.png` | 3 |
| 퇴장 | `death_00.png` ~ `death_03.png` | 4 |
| 공통 본체 합계 | 기본 동작 | **19** |

- 위의 「이미지 파일과 프레임 설명」 표에 적힌 컷별 자세와 제작 순서를 기본 스킨에 적용한다.
- 고유 스킬·비행·성장·착지·소환·효과도 위 파일 목록대로 준비한다. 본체 의상에 영향 없는 공용 효과는 출처를 명시해 재사용할 수 있다.
- 승인된 해당 스킨의 `idle_00.png`를 항상 참조하고, 이동·공격·피격 컷을 같은 자세의 복사본으로 채우지 않는다.
- 한 PNG에 한 포즈를 그리되 한 스킨은 여러 PNG의 묶음이다. 시트·아틀라스는 이 컷들을 정리하는 형식이다.
- 파츠 리깅은 제작 보조로 사용할 수 있다. 최종 본체 PNG는 동일 캔버스·배율·방향·피벗을 유지한다.
