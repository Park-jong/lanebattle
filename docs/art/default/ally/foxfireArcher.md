## 식별과 제작 범위

- 분류: 아군
- 대상 키: `ally:foxfireArcher`
- 기본 스킨: `default`
- 코드 기준: `src/data/allies.ts`
- 현재 게임의 기준 외형 영역: **20×32px**. 원화 해상도와 구별하며, 실제 충돌·사거리는 변경하지 않는다.
- 원본 PNG 캔버스: **256×320px**, 투명 RGBA, 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면.
- 예정 이미지 경로: `public/assets/characters/ally/foxfireArcher/default/`

## 캐릭터 콘셉트

등불 사이를 돌아다니며 작은 여우불 화살로 축제를 지키는 꼬마 여우 궁수. 구미호보다 가볍고 소박한 단일 꼬리의 사수로 구분한다.

- 전투 역할과 읽혀야 할 특징: 후방 원거리 공격과 화상 부여.
- 실루엣: 뾰족한 두 귀, 한 개의 짧고 굵은 꼬리, 몸 옆의 반달형 활.
- 얼굴과 성격: 집중할 때 한쪽 눈을 가늘게 뜨는 영리한 표정.
- 의상·재질·소품: 적색 짧은 저고리와 미색 바지, 작은 목궁, 붉은 여우불로 만들어지는 화살. 실체 화살통은 선택 장식으로만 작게 둔다.
- 기본 팔레트: 적 #D75B46 / 크림 #F4E3C3 / 주황 #EE9A51 / 갈색 #895D43 / 먹 #292637.
- 소형 화면에서 남길 요소: 여우 귀·한 꼬리·작은 활

## 이미지 파일과 프레임 설명

| 파일명 | 프레임 순서와 이미지 설명 |
| --- | --- |
| `idle_00.png` / `idle_01.png` | 활을 몸 앞에 낮게 든 자세 → 귀가 쫑긋하고 꼬리 끝이 흔들림. |
| `walk_00.png` / `walk_01.png` / `walk_02.png` / `walk_03.png` | 활을 낮게 유지하며 왼발을 내밈 → 꼬리가 뒤로 따라오며 몸이 내려감 → 오른발을 내밈 → 활과 꼬리가 중심으로 돌아옴. 마지막에서 첫 프레임으로 자연스럽게 이어진다. |

### 고유 동작·효과 파일

| 파일명 | 이미지와 사용 조건 |
| --- | --- |
| `projectile_foxfire_00.png / projectile_foxfire_01.png` | 128×64. 오른쪽을 향한 작은 붉은 화살형 불씨, 꼬리 불꽃 두 장. 발사 후 본체 프레임에 화살을 남기지 않는다. |
| `fx_foxfire_hit_00.png / fx_foxfire_hit_01.png` | 128×128. 작은 꽃잎 모양 불꽃이 열리고 가라앉는 타격 효과. 지속 화상 표시는 별도로 반복. |

고유 클립은 공통 `AnimationState`에 아직 등록되지 않은 확장 제안이다. 구현 때 별도 클립 매핑과 실제 능력 이벤트를 연결한다. 효과 이미지는 몸체에 합성하지 않고 별도 에셋 키로 등록한다. 오라·파동 이미지는 현재 전투의 실제 범위에 맞춰 화면에서 크기를 정한다.

## 방향·기준점·동작 주의점

활을 당기는 팔의 위치와 꼬리 개수를 전 프레임에서 유지한다. 반전하면 활과 손을 함께 반전하고 투사체는 실제 표적 방향으로 회전한다. 긴 꼬리나 활이 기준 영역을 과도하게 키우지 않게 한다.

공격 프레임의 “준비 → 타격/발사 → 회수”는 자세 제작 순서다. 현재 즉시 판정을 유지하는 첫 구현에서는 실제 판정 순간에 타격/발사 자세를 맞추고 앞 준비 프레임은 생략하거나 별도 예고에 사용한다. 피해를 주기 위해 애니메이션 종료를 기다리지 않는다.

## 제작용 설명문

> 한국 민담을 재해석한 요괴 마을 축제 게임용 2D 캐릭터. 둥근 카툰 형태, 굵고 일정한 먹색 외곽선, 단순한 면 채색과 약한 한지 느낌. 여우 귀와 단 하나의 굵은 꼬리를 가진 작은 여우 궁수, 적색 저고리와 나무 활, 따뜻한 붉은 여우불 화살, 영리하고 귀여운 얼굴. 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면, 투명 배경, 캐릭터 전체와 소품이 캔버스 안에 들어온다. 한 장에는 한 포즈만 그린다. 프레임 변형 시 확정된 기준 원화의 체형·얼굴·색·소품을 유지한다.

피할 요소: 구미호처럼 여러 꼬리, 현실적인 불길, 현대식 활과 총기. 공통 제외 사항은 사실적인 공포·유혈, 화면을 가리는 광원, 배경 풍경, 글자·워터마크, 다른 캐릭터 혼입이다.

## 검수 기준

- [ ] 콘셉트·실루엣·기본 팔레트가 확정된 기준 원화와 일치한다.
- [ ] 작은 게임 표시 크기에서 위의 식별 요소가 남는다.
- [ ] 프레임 간 크기·기준점·소품 개수와 위치가 의도 없이 달라지지 않는다.
- [ ] 좌우 반전해도 문양·소품·실루엣이 깨지지 않는다.
- [ ] 알파 배경에 흰 테두리나 잘린 무기·꼬리·날개가 없다.
- [ ] 파일명·해상도·색상 프로필과 출처·사용 조건 기록을 확인했다.

## 기본 스킨의 동작 컷

기본 스킨 `default`는 **공통 본체 19컷 + 위 고유 동작·효과 컷 전체**를 납품한다.

| 동작 | 파일 범위 | 컷 수 |
| --- | --- | --- |
| 대기 | `idle_00.png` ~ `idle_01.png` | 2 |
| 이동·롤러·비행 | `walk_00.png` ~ `walk_03.png` | 4 |
| 기본 공격 | `attack_00.png` ~ `attack_03.png` | 4 |
| 피격 | `hit_00.png` ~ `hit_01.png` | 2 |
| 등장·부활 | `spawn_00.png` ~ `spawn_02.png` | 3 |
| 퇴장 | `death_00.png` ~ `death_03.png` | 4 |
| 공통 본체 합계 | 기본 동작 | **19** |

- 위의 「이미지 파일과 프레임 설명」 표에 적힌 컷별 자세와 제작 순서를 기본 스킨에 적용한다.
- 고유 스킬·비행·성장·착지·소환·효과도 위 파일 목록대로 준비한다. 본체 의상에 영향 없는 공용 효과는 출처를 명시해 재사용할 수 있다.
- 승인된 해당 스킨의 `idle_00.png`를 항상 참조하고, 이동·공격·피격 컷을 같은 자세의 복사본으로 채우지 않는다.
- 한 PNG에 한 포즈를 그리되 한 스킨은 여러 PNG의 묶음이다. 시트·아틀라스는 이 컷들을 정리하는 형식이다.
- 파츠 리깅은 제작 보조로 사용할 수 있다. 최종 본체 PNG는 동일 캔버스·배율·방향·피벗을 유지한다.
