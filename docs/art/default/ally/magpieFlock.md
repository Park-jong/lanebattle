## 식별과 제작 범위

- 분류: 아군
- 대상 키: `ally:magpieFlock`
- 기본 스킨: `default`
- 코드 기준: `src/data/allies.ts`
- 현재 게임의 기준 외형 영역: **20×20px**. 원화 해상도와 구별하며, 실제 충돌·사거리는 변경하지 않는다.
- 원본 PNG 캔버스: **320×320px**, 투명 RGBA, 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면.
- 예정 이미지 경로: `public/assets/characters/ally/magpieFlock/default/`

## 캐릭터 콘셉트

축제 소식을 나르던 작은 까치 한 쌍이 함께 움직이는 바람 아군. 한 전투 개체를 두 마리의 한 묶음 그림으로 표현해 저렴한 소환과 재빠른 군집 느낌을 살린다.

- 전투 역할과 읽혀야 할 특징: 빠른 비행 원거리 공격, 비행 적 상대에 강함.
- 실루엣: 앞아래의 큰 까치 한 마리와 뒤위의 작은 까치 한 마리, 길고 가는 꼬리 두 개.
- 얼굴과 성격: 작은 검은 점눈과 짧은 부리. 앞새는 당차고 뒷새는 호기심 많은 모습.
- 의상·재질·소품: 검은 머리·등과 미색 배, 청백색 날개 하이라이트. 별도 의상 없이 작은 흰 바람 매듭만 선택 장식.
- 기본 팔레트: 백 #EEEDE0 / 깃 먹 #343743 / 하늘 #A4D5E0 / 청 #6798BA / 외곽 먹 #252534.
- 소형 화면에서 남길 요소: 두 마리의 고정 편대·흑백 배색·긴 꼬리

## 이미지 파일과 프레임 설명

| 파일명 | 프레임 순서와 이미지 설명 |
| --- | --- |
| `idle_00.png` / `idle_01.png` | 두 마리가 어긋난 높이에서 날개를 펴고 떠 있음 → 앞새가 날개를 낮추고 뒷새가 높임. |
| `walk_00.png` / `walk_01.png` / `walk_02.png` / `walk_03.png` | 앞새 날개 위, 뒷새 날개 중간 → 앞새 날개 중간, 뒷새 날개 아래 → 앞새 날개 아래, 뒷새 날개 위 → 앞새가 다시 날개를 들며 뒷새가 중간으로 옴. 마지막에서 첫 프레임으로 자연스럽게 이어진다. |

| `hit_00.png` / `hit_01.png` | 두 새가 놀라 날개를 벌리되 편대 중심은 유지함 → 기준 자세를 회복한다. |

### 고유 동작·효과 파일

| 파일명 | 이미지와 사용 조건 |
| --- | --- |
| `projectile_feather_00.png / projectile_feather_01.png` | 128×64. 오른쪽을 향하는 흰 깃털 모양 바람탄 두 장. 전투 로직의 투사체를 장식하며 새 두 마리라는 이유로 탄환 수를 늘리지 않는다. |

고유 클립은 공통 `AnimationState`에 아직 등록되지 않은 확장 제안이다. 구현 때 별도 클립 매핑과 실제 능력 이벤트를 연결한다. 효과 이미지는 몸체에 합성하지 않고 별도 에셋 키로 등록한다. 오라·파동 이미지는 현재 전투의 실제 범위에 맞춰 화면에서 크기를 정한다.

## 방향·기준점·동작 주의점

기본 그림은 항상 두 마리로 고정한다. 현재 소환 데이터는 한 번에 여러 전투 개체를 만들 수 있으므로 떼를 이루는 새 그림의 수와 실제 소환 수를 구별한다. 날갯짓 속도는 비슷하되 두 새에 반 주기 차이를 준다.

공격 프레임의 “준비 → 타격/발사 → 회수”는 자세 제작 순서다. 현재 즉시 판정을 유지하는 첫 구현에서는 실제 판정 순간에 타격/발사 자세를 맞추고 앞 준비 프레임은 생략하거나 별도 예고에 사용한다. 피해를 주기 위해 애니메이션 종료를 기다리지 않는다.

## 제작용 설명문

> 한국 민담을 재해석한 요괴 마을 축제 게임용 2D 캐릭터. 둥근 카툰 형태, 굵고 일정한 먹색 외곽선, 단순한 면 채색과 약한 한지 느낌. 두 마리가 한 편대로 날아가는 한국 마을의 귀여운 까치, 검은 머리와 등, 미색 배, 긴 꼬리, 청백색 날개 강조, 앞아래 한 마리와 뒤위 한 마리. 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면, 투명 배경, 캐릭터 전체와 소품이 캔버스 안에 들어온다. 한 장에는 한 포즈만 그린다. 프레임 변형 시 확정된 기준 원화의 체형·얼굴·색·소품을 유지한다.

피할 요소: 새가 프레임마다 증식하는 것, 날개가 잘려 보이는 군집, 실제 발톱으로 적을 찢는 표현. 공통 제외 사항은 사실적인 공포·유혈, 화면을 가리는 광원, 배경 풍경, 글자·워터마크, 다른 캐릭터 혼입이다.

## 검수 기준

- [ ] 콘셉트·실루엣·기본 팔레트가 확정된 기준 원화와 일치한다.
- [ ] 작은 게임 표시 크기에서 위의 식별 요소가 남는다.
- [ ] 프레임 간 크기·기준점·소품 개수와 위치가 의도 없이 달라지지 않는다.
- [ ] 좌우 반전해도 문양·소품·실루엣이 깨지지 않는다.
- [ ] 알파 배경에 흰 테두리나 잘린 무기·꼬리·날개가 없다.
- [ ] 파일명·해상도·색상 프로필과 출처·사용 조건 기록을 확인했다.

## 기본 스킨의 동작 컷

기본 스킨 `default`는 **공통 본체 19컷 + 위 고유 동작·효과 컷 전체**를 납품한다.

| 동작 | 파일 범위 | 컷 수 |
| --- | --- | --- |
| 대기 | `idle_00.png` ~ `idle_01.png` | 2 |
| 이동·롤러·비행 | `walk_00.png` ~ `walk_03.png` | 4 |
| 기본 공격 | `attack_00.png` ~ `attack_03.png` | 4 |
| 피격 | `hit_00.png` ~ `hit_01.png` | 2 |
| 등장·부활 | `spawn_00.png` ~ `spawn_02.png` | 3 |
| 퇴장 | `death_00.png` ~ `death_03.png` | 4 |
| 공통 본체 합계 | 기본 동작 | **19** |

- 위의 「이미지 파일과 프레임 설명」 표에 적힌 컷별 자세와 제작 순서를 기본 스킨에 적용한다.
- 고유 스킬·비행·성장·착지·소환·효과도 위 파일 목록대로 준비한다. 본체 의상에 영향 없는 공용 효과는 출처를 명시해 재사용할 수 있다.
- 승인된 해당 스킨의 `idle_00.png`를 항상 참조하고, 이동·공격·피격 컷을 같은 자세의 복사본으로 채우지 않는다.
- 한 PNG에 한 포즈를 그리되 한 스킨은 여러 PNG의 묶음이다. 시트·아틀라스는 이 컷들을 정리하는 형식이다.
- 파츠 리깅은 제작 보조로 사용할 수 있다. 최종 본체 PNG는 동일 캔버스·배율·방향·피벗을 유지한다.
