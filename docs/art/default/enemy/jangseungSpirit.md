## 식별과 제작 범위

- 분류: 일반 적
- 대상 키: `enemy:jangseungSpirit`
- 기본 스킨: `default`
- 코드 기준: `src/data/enemies.ts`
- 현재 게임의 기준 외형 영역: **36×52px**. 원화 해상도와 구별하며, 실제 충돌·사거리는 변경하지 않는다.
- 원본 PNG 캔버스: **320×384px**, 투명 RGBA, 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면.
- 예정 이미지 경로: `public/assets/characters/enemy/jangseungSpirit/default/`

## 캐릭터 콘셉트

고개를 지키던 오래된 나무 장승이 축제 소동에 휘말려 느릿하게 걸어오는 모습. 나무 기둥의 두꺼운 몸으로 갑옷형 적임을 보여 준다.

- 전투 역할과 읽혀야 할 특징: 느리고 단단한 근접 탱커.
- 실루엣: 세로로 긴 통나무 몸, 직사각형 얼굴, 작은 가지 팔, 짧은 뿌리 발 두 개.
- 얼굴과 성격: 장승식 큰 둥근 눈과 넓은 네모 입을 카툰으로 단순화. 코는 튀어나온 나무 덩어리.
- 의상·재질·소품: 거친 갈색 목재, 먹보라 홈, 밑동 뿌리와 미색 마모 면. 몸에 글자를 새기지 않는다.
- 기본 팔레트: 나무 #8C6C56 / 마모 미색 #C5A17D / 먹보라 #5A4867 / 먹 #302A35.
- 소형 화면에서 남길 요소: 통나무 기둥·네모 얼굴·뿌리 발

## 이미지 파일과 프레임 설명

| 파일명 | 프레임 순서와 이미지 설명 |
| --- | --- |

### 고유 동작·효과 파일

| 파일명 | 이미지와 사용 조건 |
| --- | --- |
| `fx_wood_guard_00.png / fx_wood_guard_01.png` | 128×128. 작은 목재 조각과 둔한 보라 파문. 실제 피해·저항 결과에 맞추며 추가 방어 버프 발생을 뜻하는 반짝임은 넣지 않는다. |

고유 클립은 공통 `AnimationState`에 아직 등록되지 않은 확장 제안이다. 구현 때 별도 클립 매핑과 실제 능력 이벤트를 연결한다. 효과 이미지는 몸체에 합성하지 않고 별도 에셋 키로 등록한다. 오라·파동 이미지는 현재 전투의 실제 범위에 맞춰 화면에서 크기를 정한다.

## 방향·기준점·동작 주의점

목재 몸통은 매 프레임 길이가 늘어나지 않는 단단한 물체다. 보스 철갑 장승왕과 달리 철판·왕관을 달지 않는다. 좌우 반전에서 장승 문자 문제가 없도록 문자 대신 기하 홈을 쓴다.

공격 프레임의 “준비 → 타격/발사 → 회수”는 자세 제작 순서다. 현재 즉시 판정을 유지하는 첫 구현에서는 실제 판정 순간에 타격/발사 자세를 맞추고 앞 준비 프레임은 생략하거나 별도 예고에 사용한다. 피해를 주기 위해 애니메이션 종료를 기다리지 않는다.

## 추가 스킨 콘셉트

| 스킨 ID 제안 | 이름 | 기본 외형에서 바꿀 부분 | 유지할 특징 |
| --- | --- | --- | --- |
| `mossPass` | 이끼고개 장승 | 나무 윗부분에 넓은 회녹색 이끼 면과 보라 밧줄 추가 | 통나무 기둥·네모 얼굴·뿌리 발 |
| `oldGate` | 옛문 장승 | 어두운 목재와 미색 밧줄, 몸 중앙에 큰 마름모 홈 추가 | 통나무 기둥·네모 얼굴·뿌리 발 |

추가 스킨의 파일명·클립 구성은 기본 스킨과 맞추고, 경로의 `default/`를 해당 스킨 ID로 바꾼다. 능력·속도·비행 여부·판정은 스킨 때문에 바꾸지 않는다.

## 제작용 설명문

> 한국 민담을 재해석한 요괴 마을 축제 게임용 2D 캐릭터. 둥근 카툰 형태, 굵고 일정한 먹색 외곽선, 단순한 면 채색과 약한 한지 느낌. 통나무 기둥이 걸어다니는 귀여운 장승 망령, 큰 둥근 눈과 넓은 네모 입, 갈색 나무 몸, 짧은 가지 팔과 두 뿌리 발, 보라색 그늘. 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면, 투명 배경, 캐릭터 전체와 소품이 캔버스 안에 들어온다. 한 장에는 한 포즈만 그린다. 프레임 변형 시 확정된 기준 원화의 체형·얼굴·색·소품을 유지한다.

피할 요소: 세밀한 한자 문구, 철갑 장승왕과 같은 왕관, 실제 목재 인체 절단. 공통 제외 사항은 사실적인 공포·유혈, 화면을 가리는 광원, 배경 풍경, 글자·워터마크, 다른 캐릭터 혼입이다.

## 검수 기준

- [ ] 콘셉트·실루엣·기본 팔레트가 확정된 기준 원화와 일치한다.
- [ ] 작은 게임 표시 크기에서 위의 식별 요소가 남는다.
- [ ] 프레임 간 크기·기준점·소품 개수와 위치가 의도 없이 달라지지 않는다.
- [ ] 좌우 반전해도 문양·소품·실루엣이 깨지지 않는다.
- [ ] 알파 배경에 흰 테두리나 잘린 무기·꼬리·날개가 없다.
- [ ] 파일명·해상도·색상 프로필과 출처·사용 조건 기록을 확인했다.

## 모든 추가 스킨의 동작 컷

이 문서의 `default`와 위 표의 모든 추가 스킨은 각각 **공통 본체 19컷 + 위 고유 동작·효과 컷 전체**를 납품한다. 추가 스킨은 의상·배색을 바꾸어도 기본 동작 목록과 파일명을 줄이지 않는다.

| 동작 | 파일 범위 | 컷 수 |
| --- | --- | --- |
| 대기 | `idle_00.png` ~ `idle_01.png` | 2 |
| 이동·롤러·비행 | `walk_00.png` ~ `walk_03.png` | 4 |
| 기본 공격 | `attack_00.png` ~ `attack_03.png` | 4 |
| 피격 | `hit_00.png` ~ `hit_01.png` | 2 |
| 등장·부활 | `spawn_00.png` ~ `spawn_02.png` | 3 |
| 퇴장 | `death_00.png` ~ `death_03.png` | 4 |
| 공통 본체 합계 | 모든 스킨에 동일하게 적용 | **19** |

- 위의 「이미지 파일과 프레임 설명」 표에 적힌 컷별 자세와 제작 순서를 모든 스킨에 적용한다.
- 고유 스킬·비행·성장·착지·소환·효과도 위 파일 목록대로 스킨별로 준비한다. 본체 의상에 영향 없는 공용 효과는 출처를 명시해 재사용할 수 있다.
- 추가 스킨의 폴더는 기존 경로의 `default/`를 해당 스킨 ID로 바꾼다. 본체는 해당 스킨의 의상을 입은 컷이어야 한다.
- 승인된 해당 스킨의 `idle_00.png`를 항상 참조하고, 이동·공격·피격 컷을 같은 자세의 복사본으로 채우지 않는다.
- 한 PNG에 한 포즈를 그리되 한 스킨은 여러 PNG의 묶음이다. 시트·아틀라스는 이 컷들을 정리하는 형식이다.
- 파츠 리깅은 제작 보조로 사용할 수 있다. 최종 본체 PNG는 동일 캔버스·배율·방향·피벗을 유지한다.
