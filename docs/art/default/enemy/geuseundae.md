# 그슨대 이미지 제작 명세

## 식별과 제작 범위

- 분류: 일반 적
- 대상 키: `enemy:geuseundae`
- 기본 스킨: `default`
- 코드 기준: `src/data/enemies.ts`
- 현재 게임의 기준 외형 영역: **28×46px**. 원화 해상도와 구별하며, 실제 충돌·사거리는 변경하지 않는다.
- 원본 PNG 캔버스: **320×384px**, 투명 RGBA, 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면.
- 예정 이미지 경로: `public/assets/characters/enemy/geuseundae/default/`

## 캐릭터 콘셉트

축제 인파의 그림자를 먹으며 조금씩 커지는 허풍쟁이 요괴. 긴 팔과 위쪽이 넓은 몸을 갖되 성장해도 같은 개체로 보이는 단순한 구조를 쓴다.

- 전투 역할과 읽혀야 할 특징: 살아 있는 시간이 길수록 체력·공격력·몸집이 커지는 지상 근접 적.
- 실루엣: 둥근 어깨가 넓고 아래가 좁은 몸, 무릎 아래로 내려오는 긴 팔, 작은 발과 흐트러진 머리 솟음.
- 얼굴과 성격: 처음에는 자신 없는 눈썹과 큰 미소, 성장 때 잠깐 우쭐한 표정.
- 의상·재질·소품: 먹보라 솜구름 같은 몸과 짧은 누더기 조끼. 성장 표시용 작은 안개 매듭 하나.
- 기본 팔레트: 먹보라 #65516F / 자주 #8A658B / 회미색 #C7BDCB / 먹 #302939.
- 소형 화면에서 남길 요소: 긴 팔·넓은 둥근 어깨·좁은 하체

## 이미지 파일과 프레임 설명

아래 파일명은 위 예정 경로 아래의 낱장 PNG다. 같은 행의 파일은 왼쪽부터 설명 순서에 대응한다. 모든 본체 프레임은 같은 캔버스·배율·기준점을 사용한다. 정식 제작 목록이며, 첫 연결은 `idle_00.png`와 `walk_00.png~walk_03.png`부터 시작할 수 있다.

| 파일명 | 프레임 순서와 이미지 설명 |
| --- | --- |
| `idle_00.png` / `idle_01.png` | 긴 팔을 늘어뜨리고 어깨를 웅크림 → 어깨를 살짝 펴며 우쭐한 표정. |
| `walk_00.png` / `walk_01.png` / `walk_02.png` / `walk_03.png` | 왼발을 내밀고 오른팔을 크게 앞세움 → 긴 팔이 몸 아래를 스치며 몸이 내려감 → 오른발과 왼팔을 앞으로 내밈 → 둥근 어깨가 제자리로 돌아옴. 마지막에서 첫 프레임으로 자연스럽게 이어진다. |
| `attack_00.png` / `attack_01.png` / `attack_02.png` / `attack_03.png` | 긴 팔을 뒤로 당김 → 손바닥을 정면 아래로 휘두름 → 어깨가 앞으로 기울고 팔이 내려옴 → 팔을 다시 늘어뜨림 |
| `hit_00.png` / `hit_01.png` | 큰 어깨가 안으로 움츠러들고 긴 팔이 몸을 감쌈 → 기준 자세를 회복한다. |
| `spawn_00.png` / `spawn_01.png` / `spawn_02.png` | 세로로 늘어난 그림자 기운이 어깨와 긴 팔로 뭉침 → 실루엣이 완성됨 → 기본 대기 자세. |
| `death_00.png` / `death_01.png` / `death_02.png` / `death_03.png` | 허풍이 빠지듯 어깨가 내려앉고 눈썹이 축 처짐 → 힘이 풀림 → 작은 기운 조각으로 흩어짐 → 몸이 사라짐. |
| `preview.png` | 512×512, 기본 스킨의 전체 외형과 대표 소품이 보이는 오른쪽 방향 대표 포즈. 바닥 그림자·배경·문자 없음. |
| `icon.png` | 128×128, 넓은 어깨와 우쭐한 얼굴 중심의 구도. UI 테두리·이름·비용 숫자는 넣지 않는다. |

### 고유 동작·효과 파일

| 파일명 | 이미지와 사용 조건 |
| --- | --- |
| `grow_00.png / grow_01.png / grow_02.png` | 본체 캔버스. 두 팔을 모음 → 가슴을 펴고 우쭐함 → 기본 자세. 그림 자체의 크기는 동일하게 유지하고 실제 성장 배율은 전투의 sizeScale을 따른다. |
| `fx_growth_00.png / fx_growth_01.png` | 256×256. 위로 흐르는 보라 안개띠 두 장. 실제 성장 이벤트마다 짧게 재생. |

고유 클립은 공통 `AnimationState`에 아직 등록되지 않은 확장 제안이다. 구현 때 별도 클립 매핑과 실제 능력 이벤트를 연결한다. 효과 이미지는 몸체에 합성하지 않고 별도 에셋 키로 등록한다. 오라·파동 이미지는 현재 전투의 실제 범위에 맞춰 화면에서 크기를 정한다.

## 방향·기준점·동작 주의점

성장 단계별로 별도 확대 PNG를 만들지 않는다. 기본 원화와 포즈를 공유하고 코드의 실제 배율을 한 번만 적용한다. 최종 성장에서도 긴 팔과 작은 발 비율이 유지되어야 한다.

공격 프레임의 “준비 → 타격/발사 → 회수”는 자세 제작 순서다. 현재 즉시 판정을 유지하는 첫 구현에서는 실제 판정 순간에 타격/발사 자세를 맞추고 앞 준비 프레임은 생략하거나 별도 예고에 사용한다. 피해를 주기 위해 애니메이션 종료를 기다리지 않는다.

## 추가 스킨 콘셉트

| 스킨 ID 제안 | 이름 | 기본 외형에서 바꿀 부분 | 유지할 특징 |
| --- | --- | --- | --- |
| `nightMarket` | 장터 그림자 | 누더기 조끼를 회보라 조각천으로 바꾸고 큰 천 매듭 추가 | 긴 팔·넓은 둥근 어깨·좁은 하체 |
| `cloudBoaster` | 먹구름 허풍쟁이 | 더 둥근 구름 가장자리와 연보라 어깨 무늬, 짙은 보라 조끼 | 긴 팔·넓은 둥근 어깨·좁은 하체 |

추가 스킨의 파일명·클립 구성은 기본 스킨과 맞추고, 경로의 `default/`를 해당 스킨 ID로 바꾼다. 능력·속도·비행 여부·판정은 스킨 때문에 바꾸지 않는다.

## 제작용 설명문

> 한국 민담을 재해석한 요괴 마을 축제 게임용 2D 캐릭터. 둥근 카툰 형태, 굵고 일정한 먹색 외곽선, 단순한 면 채색과 약한 한지 느낌. 살아 있을수록 커지는 허풍쟁이 요괴 그슨대, 넓고 둥근 어깨와 아주 긴 팔, 작은 발, 먹보라 솜구름 몸과 짧은 조끼, 우쭐한 귀여운 표정. 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면, 투명 배경, 캐릭터 전체와 소품이 캔버스 안에 들어온다. 한 장에는 한 포즈만 그린다. 프레임 변형 시 확정된 기준 원화의 체형·얼굴·색·소품을 유지한다.

피할 요소: 실제 근육 파열과 변신 공포, 성장 단계별 팔다리 수 변화, 항상 떠 있는 비행 모습. 공통 제외 사항은 사실적인 공포·유혈, 화면을 가리는 광원, 배경 풍경, 글자·워터마크, 다른 캐릭터 혼입이다.

## 검수 기준

- [ ] 콘셉트·실루엣·기본 팔레트가 확정된 기준 원화와 일치한다.
- [ ] 작은 게임 표시 크기에서 위의 식별 요소가 남는다.
- [ ] 프레임 간 크기·기준점·소품 개수와 위치가 의도 없이 달라지지 않는다.
- [ ] 좌우 반전해도 문양·소품·실루엣이 깨지지 않는다.
- [ ] 알파 배경에 흰 테두리나 잘린 무기·꼬리·날개가 없다.
- [ ] 파일명·해상도·색상 프로필과 출처·사용 조건 기록을 확인했다.

## 모든 추가 스킨의 동작 컷

이 문서의 `default`와 위 표의 모든 추가 스킨은 각각 **공통 본체 19컷 + 위 고유 동작·효과 컷 전체**를 납품한다. 추가 스킨은 의상·배색을 바꾸어도 기본 동작 목록과 파일명을 줄이지 않는다.

| 동작 | 파일 범위 | 컷 수 |
| --- | --- | --- |
| 대기 | `idle_00.png` ~ `idle_01.png` | 2 |
| 이동·롤러·비행 | `walk_00.png` ~ `walk_03.png` | 4 |
| 기본 공격 | `attack_00.png` ~ `attack_03.png` | 4 |
| 피격 | `hit_00.png` ~ `hit_01.png` | 2 |
| 등장·부활 | `spawn_00.png` ~ `spawn_02.png` | 3 |
| 퇴장 | `death_00.png` ~ `death_03.png` | 4 |
| 공통 본체 합계 | 모든 스킨에 동일하게 적용 | **19** |

- 위의 「이미지 파일과 프레임 설명」 표에 적힌 컷별 자세와 제작 순서를 모든 스킨에 적용한다.
- 고유 스킬·비행·성장·착지·소환·효과도 위 파일 목록대로 스킨별로 준비한다. 본체 의상에 영향 없는 공용 효과는 출처를 명시해 재사용할 수 있다.
- 추가 스킨의 폴더는 기존 경로의 `default/`를 해당 스킨 ID로 바꾼다. 본체는 해당 스킨의 의상을 입은 컷이어야 한다.
- 승인된 해당 스킨의 `idle_00.png`를 항상 참조하고, 이동·공격·피격 컷을 같은 자세의 복사본으로 채우지 않는다.
- 한 PNG에 한 포즈를 그리되 한 스킨은 여러 PNG의 묶음이다. 시트·아틀라스는 이 컷들을 정리하는 형식이다.
- 파츠 리깅은 제작 보조로 사용할 수 있다. 최종 본체 PNG는 동일 캔버스·배율·방향·피벗을 유지한다.
