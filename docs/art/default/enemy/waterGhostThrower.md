# 물귀신 투척병 이미지 제작 명세

## 식별과 제작 범위

- 분류: 일반 적
- 대상 키: `enemy:waterGhostThrower`
- 기본 스킨: `default`
- 코드 기준: `src/data/enemies.ts`
- 현재 게임의 기준 외형 영역: **20×32px**. 원화 해상도와 구별하며, 실제 충돌·사거리는 변경하지 않는다.
- 원본 PNG 캔버스: **256×320px**, 투명 RGBA, 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면.
- 예정 이미지 경로: `public/assets/characters/enemy/waterGhostThrower/default/`

## 캐릭터 콘셉트

축제 우물가에서 물장난을 치는 젖은 보자기 요괴. 물방울이 맺힌 머리와 작은 물바가지로 원거리 둔화 공격을 바로 이해하게 한다.

- 전투 역할과 읽혀야 할 특징: 물덩이를 던져 아군 이동을 느리게 하는 원거리 적.
- 실루엣: 아래로 처진 물방울 머리, 둥근 물바가지, 길게 늘어진 젖은 소매.
- 얼굴과 성격: 졸린 반달눈과 장난스러운 작은 입. 머리카락으로 얼굴 전체를 가리지 않는다.
- 의상·재질·소품: 청회색 젖은 저고리, 보라빛 밑단, 목재 바가지, 단순한 반짝임 두세 개.
- 기본 팔레트: 청회 #7FADB7 / 먹보라 #655574 / 물 하늘 #B4DCE0 / 미색 #DCE4DA / 먹 #2E293B.
- 소형 화면에서 남길 요소: 물방울 머리·바가지·젖은 긴 소매

## 이미지 파일과 프레임 설명

아래 파일명은 위 예정 경로 아래의 낱장 PNG다. 같은 행의 파일은 왼쪽부터 설명 순서에 대응한다. 모든 본체 프레임은 같은 캔버스·배율·기준점을 사용한다. 정식 제작 목록이며, 첫 연결은 `idle_00.png`와 `walk_00.png~walk_03.png`부터 시작할 수 있다.

| 파일명 | 프레임 순서와 이미지 설명 |
| --- | --- |
| `idle_00.png` / `idle_01.png` | 바가지를 가슴 앞에 들고 있음 → 물방울 한 개가 소매 끝에 맺힘. |
| `walk_00.png` / `walk_01.png` / `walk_02.png` / `walk_03.png` | 왼발을 끌듯 내밀고 바가지를 수평으로 유지 → 젖은 소매가 뒤따라 내려옴 → 오른발을 짧게 내밈 → 바가지를 중심으로 되돌리고 몸이 펴짐. 마지막에서 첫 프레임으로 자연스럽게 이어진다. |

| `hit_00.png` / `hit_01.png` | 머리의 물방울 끝이 찌그러지고 바가지를 움켜쥠 → 기준 자세를 회복한다. |
| `spawn_00.png` / `spawn_01.png` / `spawn_02.png` | 물웅덩이 모양 기운이 위로 모여 젖은 천 몸을 이룸 → 실루엣이 완성됨 → 기본 대기 자세. |
| `death_00.png` / `death_01.png` / `death_02.png` / `death_03.png` | 깜짝 놀라 바가지를 머리 위로 올리고 몸이 축 처짐 → 힘이 풀림 → 작은 기운 조각으로 흩어짐 → 몸이 사라짐. |

| `icon.png` | 128×128, 물방울 머리와 목재 바가지 중심의 구도. UI 테두리·이름·비용 숫자는 넣지 않는다. |

### 고유 동작·효과 파일

| 파일명 | 이미지와 사용 조건 |
| --- | --- |
| `projectile_water_00.png / projectile_water_01.png` | 128×128. 오른쪽으로 흐르는 큰 물방울 한 개와 작은 꼬리방울 두 개. |
| `fx_water_splash_00.png / fx_water_splash_01.png` | 128×128. 낮은 물꽃이 퍼지는 두 프레임. 둔화 상태는 별도 청색 표시로 유지. |

고유 클립은 공통 `AnimationState`에 아직 등록되지 않은 확장 제안이다. 구현 때 별도 클립 매핑과 실제 능력 이벤트를 연결한다. 효과 이미지는 몸체에 합성하지 않고 별도 에셋 키로 등록한다. 오라·파동 이미지는 현재 전투의 실제 범위에 맞춰 화면에서 크기를 정한다.

## 방향·기준점·동작 주의점

물방울 낙하나 장식 물결 때문에 실제 지상 위치를 흔들지 않는다. 바가지와 손의 연결을 유지하고 발사 후 탄환이 본체 손에 중복으로 남지 않게 한다.

공격 프레임의 “준비 → 타격/발사 → 회수”는 자세 제작 순서다. 현재 즉시 판정을 유지하는 첫 구현에서는 실제 판정 순간에 타격/발사 자세를 맞추고 앞 준비 프레임은 생략하거나 별도 예고에 사용한다. 피해를 주기 위해 애니메이션 종료를 기다리지 않는다.

추가 스킨의 파일명·클립 구성은 기본 스킨과 맞추고, 경로의 `default/`를 해당 스킨 ID로 바꾼다. 능력·속도·비행 여부·판정은 스킨 때문에 바꾸지 않는다.

## 제작용 설명문

> 한국 민담을 재해석한 요괴 마을 축제 게임용 2D 캐릭터. 둥근 카툰 형태, 굵고 일정한 먹색 외곽선, 단순한 면 채색과 약한 한지 느낌. 졸린 눈으로 물장난을 하는 작은 물귀신, 물방울 모양 머리와 젖은 청회색 저고리, 보라 밑단, 둥근 목재 바가지. 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면, 투명 배경, 캐릭터 전체와 소품이 캔버스 안에 들어온다. 한 장에는 한 포즈만 그린다. 프레임 변형 시 확정된 기준 원화의 체형·얼굴·색·소품을 유지한다.

피할 요소: 익사한 실제 사람, 부패한 피부, 해양 괴물 촉수. 공통 제외 사항은 사실적인 공포·유혈, 화면을 가리는 광원, 배경 풍경, 글자·워터마크, 다른 캐릭터 혼입이다.

## 검수 기준

- [ ] 콘셉트·실루엣·기본 팔레트가 확정된 기준 원화와 일치한다.
- [ ] 작은 게임 표시 크기에서 위의 식별 요소가 남는다.
- [ ] 프레임 간 크기·기준점·소품 개수와 위치가 의도 없이 달라지지 않는다.
- [ ] 좌우 반전해도 문양·소품·실루엣이 깨지지 않는다.
- [ ] 알파 배경에 흰 테두리나 잘린 무기·꼬리·날개가 없다.
- [ ] 파일명·해상도·색상 프로필과 출처·사용 조건 기록을 확인했다.

## 모든 추가 스킨의 동작 컷

이 문서의 `default`와 위 표의 모든 추가 스킨은 각각 **공통 본체 19컷 + 위 고유 동작·효과 컷 전체**를 납품한다. 추가 스킨은 의상·배색을 바꾸어도 기본 동작 목록과 파일명을 줄이지 않는다.

| 동작 | 파일 범위 | 컷 수 |
| --- | --- | --- |
| 대기 | `idle_00.png` ~ `idle_01.png` | 2 |
| 이동·롤러·비행 | `walk_00.png` ~ `walk_03.png` | 4 |
| 기본 공격 | `attack_00.png` ~ `attack_03.png` | 4 |
| 피격 | `hit_00.png` ~ `hit_01.png` | 2 |
| 등장·부활 | `spawn_00.png` ~ `spawn_02.png` | 3 |
| 퇴장 | `death_00.png` ~ `death_03.png` | 4 |
| 공통 본체 합계 | 모든 스킨에 동일하게 적용 | **19** |

- 위의 「이미지 파일과 프레임 설명」 표에 적힌 컷별 자세와 제작 순서를 모든 스킨에 적용한다.
- 고유 스킬·비행·성장·착지·소환·효과도 위 파일 목록대로 스킨별로 준비한다. 본체 의상에 영향 없는 공용 효과는 출처를 명시해 재사용할 수 있다.
- 추가 스킨의 폴더는 기존 경로의 `default/`를 해당 스킨 ID로 바꾼다. 본체는 해당 스킨의 의상을 입은 컷이어야 한다.
- 승인된 해당 스킨의 `idle_00.png`를 항상 참조하고, 이동·공격·피격 컷을 같은 자세의 복사본으로 채우지 않는다.
- 한 PNG에 한 포즈를 그리되 한 스킨은 여러 PNG의 묶음이다. 시트·아틀라스는 이 컷들을 정리하는 형식이다.
- 파츠 리깅은 제작 보조로 사용할 수 있다. 최종 본체 PNG는 동일 캔버스·배율·방향·피벗을 유지한다.
