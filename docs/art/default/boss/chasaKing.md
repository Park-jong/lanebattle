## 식별과 제작 범위

- 분류: 5장 보스
- 대상 키: `boss:chasaKing`
- 기본 스킨: `default`
- 코드 기준: `src/data/bosses.ts`
- 현재 게임의 기준 외형 영역: **100×150px**. 원화 해상도와 구별하며, 실제 충돌·사거리는 변경하지 않는다.
- 원본 PNG 캔버스: **640×768px**, 투명 RGBA, 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면.
- 예정 이미지 경로: `public/assets/characters/boss/chasaKing/default/`

## 캐릭터 콘셉트

축제의 마지막 문을 가로막는 저승 행렬의 우두머리. 거대한 도포와 넓은 의장관으로 권위를 만들되, 명부를 놓치면 당황하는 익살스러운 마지막 보스로 그린다.

- 전투 역할과 읽혀야 할 특징: 느린 근접 최종 보스, 주기적 전체 피해·버프 억제 맥동. 영웅 공격에 약함.
- 실루엣: 높은 의장관, 넓은 어깨, 아래로 벌어지는 큰 검은 도포, 한 손의 큰 홀과 다른 손의 명부.
- 얼굴과 성격: 굵고 곧은 눈썹과 작은 미색 눈, 단단히 다문 입. 해골이 아닌 둥근 요괴 얼굴.
- 의상·재질·소품: 먹색 겉도포, 자주색 넓은 안감, 탁한 금색 어깨 매듭, 명부와 둥근 머리의 의장 홀. 왕의 위계는 큰 면 배색으로 표시.
- 기본 팔레트: 먹 #34303C / 자주 #7C4D73 / 탁금 #C4A368 / 미색 #E5D7C3 / 보라 #5E476B.
- 소형 화면에서 남길 요소: 높은 의장관·넓은 도포·큰 홀과 명부

## 이미지 파일과 프레임 설명

아래 파일명은 위 예정 경로 아래의 낱장 PNG다. 같은 행의 파일은 왼쪽부터 설명 순서에 대응한다. 모든 본체 프레임은 같은 캔버스·배율·기준점을 사용한다. 정식 제작 목록이며, 첫 연결은 `idle_00.png`와 `walk_00.png~walk_03.png`부터 시작할 수 있다.

| 파일명 | 프레임 순서와 이미지 설명 |
| --- | --- |
| `idle_00.png` / `idle_01.png` | 홀을 세우고 명부를 몸 앞에 듦 → 넓은 어깨와 도포 안감이 조금 움직임. |
| `walk_00.png` / `walk_01.png` / `walk_02.png` / `walk_03.png` | 도포 아래 왼발을 느리게 내밈 → 넓은 소매가 뒤로 따라오고 홀이 기움 → 오른발을 내밈 → 홀을 수직으로 되돌리고 도포가 정리됨. 마지막에서 첫 프레임으로 자연스럽게 이어진다. |
| `attack_00.png` / `attack_01.png` / `attack_02.png` / `attack_03.png` | 의장 홀을 몸 뒤로 짧게 당김 → 홀의 둥근 끝을 정면으로 내려침 → 큰 소매가 앞으로 펴진 자세 → 홀을 세워 중심 회복 |
| `hit_00.png` / `hit_01.png` | 눈썹이 치켜올라가고 명부를 꽉 쥐며 도포가 움찔함 → 기준 자세를 회복한다. |
| `spawn_00.png` / `spawn_01.png` / `spawn_02.png` | 명부가 크게 펼쳐진 기운 뒤로 관과 넓은 도포가 나타남 → 실루엣이 완성됨 → 기본 대기 자세. |
| `death_00.png` / `death_01.png` / `death_02.png` / `death_03.png` | 명부를 놓칠 듯 허둥대며 관을 한 손으로 붙잡음 → 힘이 풀림 → 작은 기운 조각으로 흩어짐 → 몸이 사라짐. |
| `preview.png` | 512×512, 기본 스킨의 전체 외형과 대표 소품이 보이는 오른쪽 방향 대표 포즈. 바닥 그림자·배경·문자 없음. |
| `icon.png` | 128×128, 높은 의장관 아래 굵은 눈썹과 탁금 어깨 매듭 중심의 구도. UI 테두리·이름·비용 숫자는 넣지 않는다. |

### 고유 동작·효과 파일

| 파일명 | 이미지와 사용 조건 |
| --- | --- |
| `suppress_00.png / suppress_01.png / suppress_02.png / suppress_03.png` | 본체 캔버스. 명부와 홀을 들어 올림 → 명부를 정면으로 펼침 → 넓은 소매를 양쪽으로 폄 → 기본 자세. 실제 억제 맥동에 연결. |
| `fx_suppress_00.png / fx_suppress_01.png / fx_suppress_02.png` | 256×256. 중앙이 빈 자주색 원과 매듭 조각이 퍼졌다 사라짐. 실제 전역 효과 연출용이며 몸 원화에 전체 화면 효과를 합성하지 않는다. |

고유 클립은 공통 `AnimationState`에 아직 등록되지 않은 확장 제안이다. 구현 때 별도 클립 매핑과 실제 능력 이벤트를 연결한다. 효과 이미지는 몸체에 합성하지 않고 별도 에셋 키로 등록한다. 오라·파동 이미지는 현재 전투의 실제 범위에 맞춰 화면에서 크기를 정한다.

## 방향·기준점·동작 주의점

일반 저승사자와 차이는 높은 관·큰 어깨·넓은 도포 면이다. 홀과 명부는 전 프레임에서 같은 손에 유지한다. 억제 맥동이 진행되는 동안에도 화면의 피해 숫자·체력바를 가리지 않는 강도로 효과를 조절한다.

공격 프레임의 “준비 → 타격/발사 → 회수”는 자세 제작 순서다. 현재 즉시 판정을 유지하는 첫 구현에서는 실제 판정 순간에 타격/발사 자세를 맞추고 앞 준비 프레임은 생략하거나 별도 예고에 사용한다. 피해를 주기 위해 애니메이션 종료를 기다리지 않는다.

## 제작용 설명문

> 한국 민담을 재해석한 요괴 마을 축제 게임용 2D 캐릭터. 둥근 카툰 형태, 굵고 일정한 먹색 외곽선, 단순한 면 채색과 약한 한지 느낌. 저승 행렬의 귀여운 최종 우두머리 차사왕, 높은 의장관과 넓은 먹색 도포, 자주색 안감, 둥근 끝 의장 홀과 큰 명부, 엄격하지만 익살스러운 둥근 얼굴. 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면, 투명 배경, 캐릭터 전체와 소품이 캔버스 안에 들어온다. 한 장에는 한 포즈만 그린다. 프레임 변형 시 확정된 기준 원화의 체형·얼굴·색·소품을 유지한다.

피할 요소: 서양 해골 왕과 낫, 사실적인 폭군, 과도한 금빛으로 아군 신수처럼 보이는 배색. 공통 제외 사항은 사실적인 공포·유혈, 화면을 가리는 광원, 배경 풍경, 글자·워터마크, 다른 캐릭터 혼입이다.

## 검수 기준

- [ ] 콘셉트·실루엣·기본 팔레트가 확정된 기준 원화와 일치한다.
- [ ] 작은 게임 표시 크기에서 위의 식별 요소가 남는다.
- [ ] 프레임 간 크기·기준점·소품 개수와 위치가 의도 없이 달라지지 않는다.
- [ ] 좌우 반전해도 문양·소품·실루엣이 깨지지 않는다.
- [ ] 알파 배경에 흰 테두리나 잘린 무기·꼬리·날개가 없다.
- [ ] 파일명·해상도·색상 프로필과 출처·사용 조건 기록을 확인했다.

## 기본 스킨의 동작 컷

기본 스킨 `default`는 **공통 본체 19컷 + 위 고유 동작·효과 컷 전체**를 납품한다.

| 동작 | 파일 범위 | 컷 수 |
| --- | --- | --- |
| 대기 | `idle_00.png` ~ `idle_01.png` | 2 |
| 이동·롤러·비행 | `walk_00.png` ~ `walk_03.png` | 4 |
| 기본 공격 | `attack_00.png` ~ `attack_03.png` | 4 |
| 피격 | `hit_00.png` ~ `hit_01.png` | 2 |
| 등장·부활 | `spawn_00.png` ~ `spawn_02.png` | 3 |
| 퇴장 | `death_00.png` ~ `death_03.png` | 4 |
| 공통 본체 합계 | 기본 동작 | **19** |

- 위의 「이미지 파일과 프레임 설명」 표에 적힌 컷별 자세와 제작 순서를 기본 스킨에 적용한다.
- 고유 스킬·비행·성장·착지·소환·효과도 위 파일 목록대로 준비한다. 본체 의상에 영향 없는 공용 효과는 출처를 명시해 재사용할 수 있다.
- 승인된 해당 스킨의 `idle_00.png`를 항상 참조하고, 이동·공격·피격 컷을 같은 자세의 복사본으로 채우지 않는다.
- 한 PNG에 한 포즈를 그리되 한 스킨은 여러 PNG의 묶음이다. 시트·아틀라스는 이 컷들을 정리하는 형식이다.
- 파츠 리깅은 제작 보조로 사용할 수 있다. 최종 본체 PNG는 동일 캔버스·배율·방향·피벗을 유지한다.
