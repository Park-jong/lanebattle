# 어둑시니 대왕 이미지 제작 명세

## 식별과 제작 범위

- 분류: 4장 보스
- 대상 키: `boss:eodduksiniKing`
- 기본 스킨: `default`
- 코드 기준: `src/data/bosses.ts`
- 현재 게임의 기준 외형 영역: **90×90px**. 원화 해상도와 구별하며, 실제 충돌·사거리는 변경하지 않는다.
- 원본 PNG 캔버스: **640×640px**, 투명 RGBA, 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면.
- 예정 이미지 경로: `public/assets/characters/boss/eodduksiniKing/default/`

## 캐릭터 콘셉트

대숲의 그림자를 한데 모아 왕관처럼 머리에 얹은 거대한 먹구름 요괴. 일반 어둑시니의 둥근 구름 형태를 확장하되 큰 손과 세 갈래 그림자 관으로 보스 위계를 만든다.

- 전투 역할과 읽혀야 할 특징: 비행 원거리 보스, 주기적 착지 범위 충격과 재상승. 원거리·비행 공격자에 약하고 근접에 저항.
- 실루엣: 큰 둥근 구름 머리, 세 갈래 그림자 관, 몸 옆의 큰 천 손 두 개, 짧은 안개 꼬리.
- 얼굴과 성격: 큰 미색 눈과 근엄하게 다문 입. 피격 시 왕관까지 움찔하는 허세 있는 표정.
- 의상·재질·소품: 먹보라 구름의 불투명 면, 짙은 자주 안감, 관 끝 미색 점 세 개. 왕관은 금속보다 그림자 천 형태.
- 기본 팔레트: 먹 #363043 / 먹보라 #5F4B74 / 자주 #8D6C96 / 미색 #E5D8C0.
- 소형 화면에서 남길 요소: 세 갈래 그림자 관·큰 천 손·거대한 먹구름

## 이미지 파일과 프레임 설명

아래 파일명은 위 예정 경로 아래의 낱장 PNG다. 같은 행의 파일은 왼쪽부터 설명 순서에 대응한다. 모든 본체 프레임은 같은 캔버스·배율·기준점을 사용한다. 정식 제작 목록이며, 첫 연결은 `idle_00.png`와 `walk_00.png~walk_03.png`부터 시작할 수 있다.

| 파일명 | 프레임 순서와 이미지 설명 |
| --- | --- |
| `idle_00.png` / `idle_01.png` | 두 손을 벌리고 둥글게 떠 있음 → 구름 아래가 오므라들고 손끝이 내려옴. |
| `walk_00.png` / `walk_01.png` / `walk_02.png` / `walk_03.png` | 양손을 조금 위로 듦 → 몸이 앞으로 기울며 손이 옆으로 펴짐 → 손을 아래로 밀어 안개 끝이 뒤로 흐름 → 구름 몸이 둥글게 복귀. 마지막에서 첫 프레임으로 자연스럽게 이어진다. |
| `attack_00.png` / `attack_01.png` / `attack_02.png` / `attack_03.png` | 양손을 입 근처로 모음 → 입 앞에 큰 먹방울을 모음 → 한 손을 앞으로 펼치며 방울을 발사하는 자세 → 양손을 다시 벌림 |
| `hit_00.png` / `hit_01.png` | 그림자 관 끝이 휘고 큰 눈이 동그랗게 변함 → 기준 자세를 회복한다. |
| `spawn_00.png` / `spawn_01.png` / `spawn_02.png` | 세 갈래 관이 안개 위로 솟고 두 큰 손이 양옆으로 펼쳐짐 → 실루엣이 완성됨 → 기본 대기 자세. |
| `death_00.png` / `death_01.png` / `death_02.png` / `death_03.png` | 관 끝이 축 처지고 두 손으로 얼굴을 가림 → 힘이 풀림 → 작은 기운 조각으로 흩어짐 → 몸이 사라짐. |
| `preview.png` | 512×512, 기본 스킨의 전체 외형과 대표 소품이 보이는 오른쪽 방향 대표 포즈. 바닥 그림자·배경·문자 없음. |
| `icon.png` | 128×128, 세 갈래 그림자 관과 큰 미색 눈 중심의 구도. UI 테두리·이름·비용 숫자는 넣지 않는다. |

### 고유 동작·효과 파일

| 파일명 | 이미지와 사용 조건 |
| --- | --- |
| `descend_00.png / descend_01.png / descend_02.png` | 본체 캔버스. 몸과 손을 좁힘 → 낙하용 아래로 길어진 자세 → 바닥에서 납작하게 퍼진 자세. 실제 고도 변화는 View가 적용. |
| `ground_idle_00.png / ground_idle_01.png` | 본체 캔버스. 지면에 납작하게 퍼진 몸과 옆으로 놓인 두 손. 실제 착지 상태 동안만 반복. |
| `ascend_00.png / ascend_01.png` | 본체 캔버스. 두 손을 아래로 모음 → 구름 몸을 둥글게 회복. 착지 종료 후 상승 상태에 연결. |
| `projectile_king_shadow_00.png / projectile_king_shadow_01.png` | 128×128. 미색 윤곽 일부가 있는 굵은 보라 먹방울. |
| `fx_land_ring_00.png / fx_land_ring_01.png / fx_land_ring_02.png` | 256×256. 지면을 따라 넓어지는 보라 충격 원. 실제 착지 범위 피해 순간에만 사용. |

고유 클립은 공통 `AnimationState`에 아직 등록되지 않은 확장 제안이다. 구현 때 별도 클립 매핑과 실제 능력 이벤트를 연결한다. 효과 이미지는 몸체에 합성하지 않고 별도 에셋 키로 등록한다. 오라·파동 이미지는 현재 전투의 실제 범위에 맞춰 화면에서 크기를 정한다.

## 방향·기준점·동작 주의점

비행과 착지는 실제 보스 패턴 상태와 liftOf()를 따른다. 원화에 고도를 미리 넣지 않는다. 일반 어둑시니의 비행 특성과 동일하다고 추측해 전투 수치를 바꾸지 않는다. 착지 중에도 관과 손의 정체성을 유지한다.

공격 프레임의 “준비 → 타격/발사 → 회수”는 자세 제작 순서다. 현재 즉시 판정을 유지하는 첫 구현에서는 실제 판정 순간에 타격/발사 자세를 맞추고 앞 준비 프레임은 생략하거나 별도 예고에 사용한다. 피해를 주기 위해 애니메이션 종료를 기다리지 않는다.

## 제작용 설명문

> 한국 민담을 재해석한 요괴 마을 축제 게임용 2D 캐릭터. 둥근 카툰 형태, 굵고 일정한 먹색 외곽선, 단순한 면 채색과 약한 한지 느낌. 세 갈래 그림자 관을 쓴 거대한 둥근 먹구름 요괴 왕, 큰 미색 두 눈과 천 같은 큰 손 두 개, 짧은 안개 꼬리, 허세 있고 귀여운 표정. 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면, 투명 배경, 캐릭터 전체와 소품이 캔버스 안에 들어온다. 한 장에는 한 포즈만 그린다. 프레임 변형 시 확정된 기준 원화의 체형·얼굴·색·소품을 유지한다.

피할 요소: 새 날개와 발을 가진 불사조, 본체가 안 보이는 반투명 안개, 영구 비행 포즈만 납품하는 것. 공통 제외 사항은 사실적인 공포·유혈, 화면을 가리는 광원, 배경 풍경, 글자·워터마크, 다른 캐릭터 혼입이다.

## 검수 기준

- [ ] 콘셉트·실루엣·기본 팔레트가 확정된 기준 원화와 일치한다.
- [ ] 작은 게임 표시 크기에서 위의 식별 요소가 남는다.
- [ ] 프레임 간 크기·기준점·소품 개수와 위치가 의도 없이 달라지지 않는다.
- [ ] 좌우 반전해도 문양·소품·실루엣이 깨지지 않는다.
- [ ] 알파 배경에 흰 테두리나 잘린 무기·꼬리·날개가 없다.
- [ ] 파일명·해상도·색상 프로필과 출처·사용 조건 기록을 확인했다.

## 기본 스킨의 동작 컷

기본 스킨 `default`는 **공통 본체 19컷 + 위 고유 동작·효과 컷 전체**를 납품한다.

| 동작 | 파일 범위 | 컷 수 |
| --- | --- | --- |
| 대기 | `idle_00.png` ~ `idle_01.png` | 2 |
| 이동·롤러·비행 | `walk_00.png` ~ `walk_03.png` | 4 |
| 기본 공격 | `attack_00.png` ~ `attack_03.png` | 4 |
| 피격 | `hit_00.png` ~ `hit_01.png` | 2 |
| 등장·부활 | `spawn_00.png` ~ `spawn_02.png` | 3 |
| 퇴장 | `death_00.png` ~ `death_03.png` | 4 |
| 공통 본체 합계 | 기본 동작 | **19** |

- 위의 「이미지 파일과 프레임 설명」 표에 적힌 컷별 자세와 제작 순서를 기본 스킨에 적용한다.
- 고유 스킬·비행·성장·착지·소환·효과도 위 파일 목록대로 준비한다. 본체 의상에 영향 없는 공용 효과는 출처를 명시해 재사용할 수 있다.
- 승인된 해당 스킨의 `idle_00.png`를 항상 참조하고, 이동·공격·피격 컷을 같은 자세의 복사본으로 채우지 않는다.
- 한 PNG에 한 포즈를 그리되 한 스킨은 여러 PNG의 묶음이다. 시트·아틀라스는 이 컷들을 정리하는 형식이다.
- 파츠 리깅은 제작 보조로 사용할 수 있다. 최종 본체 PNG는 동일 캔버스·배율·방향·피벗을 유지한다.
