## 식별과 제작 범위

- 분류: 3장 보스
- 대상 키: `boss:imugiGangcheol`
- 기본 스킨: `default`
- 코드 기준: `src/data/bosses.ts`
- 현재 게임의 기준 외형 영역: **120×110px**. 원화 해상도와 구별하며, 실제 충돌·사거리는 변경하지 않는다.
- 원본 PNG 캔버스: **768×640px**, 투명 RGBA, 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면.
- 예정 이미지 경로: `public/assets/characters/boss/imugiGangcheol/default/`

## 캐릭터 콘셉트

가뭄 든 강바닥에 웅크리고 축제의 열기를 집어먹는 커다란 쇠비늘 이무기. 긴 몸을 원형으로 말아 가로로 무한히 길어지지 않게 하고 꼬리치기 동작에 집중한다.

- 전투 역할과 읽혀야 할 특징: 지상 근접 보스, 불 피해를 흡수해 회복, 가뭄과 범위 꼬리치기. 바람·근접에 약함.
- 실루엣: 큰 둥근 머리, 짧은 뒤굽은 뿔 두 개, 아래로 둥글게 감긴 긴 뱀 몸, 옆으로 나온 큰 꼬리.
- 얼굴과 성격: 반쯤 감긴 눈과 자신만만한 넓은 입. 수염은 짧은 두 가닥.
- 의상·재질·소품: 먹회색 쇠비늘 큰 덩어리, 황토 배판, 보라색 등 능선, 불을 먹을 때만 켜지는 주황 틈.
- 기본 팔레트: 쇠 먹 #585463 / 보라 #806183 / 배 황토 #B59361 / 열 주황 #CF9055 / 먹 #302A3B.
- 소형 화면에서 남길 요소: 말린 긴 뱀 몸·큰 쇠비늘 머리·굵은 꼬리

### 고유 동작·효과 파일

| 파일명 | 이미지와 사용 조건 |
| --- | --- |
| `tail_00.png / tail_01.png / tail_02.png / tail_03.png` | 본체 캔버스. 꼬리를 옆으로 듦 → 몸 앞쪽으로 크게 휩씀 → 꼬리가 반대쪽에 놓임 → 기본 고리로 회수. 실제 범위 꼬리치기에 연결. |
| `absorb_00.png / absorb_01.png` | 본체 캔버스. 불씨를 향해 고개를 들고 입을 오므림 → 만족스럽게 눈을 감음. 실제 불 흡수 회복 때만 사용. |
| `fx_heat_absorb_00.png / fx_heat_absorb_01.png` | 256×256. 주황 불씨가 입 방향으로 빨려드는 짧은 곡선. 실제 회복 여부는 전투 결과를 따른다. |
| `fx_drought_00.png / fx_drought_01.png` | 256×128. 얇은 황토 열기선 두 장. 배경 보조 효과이며 새로운 지형 균열이나 추가 피해 장판을 만들지 않는다. |

고유 클립은 공통 `AnimationState`에 아직 등록되지 않은 확장 제안이다. 구현 때 별도 클립 매핑과 실제 능력 이벤트를 연결한다. 효과 이미지는 몸체에 합성하지 않고 별도 에셋 키로 등록한다. 오라·파동 이미지는 현재 전투의 실제 범위에 맞춰 화면에서 크기를 정한다.

## 방향·기준점·동작 주의점

기본 비행 보스가 아니다. 감긴 몸의 바닥 접점을 유지하고 꼬리 휩쓸기는 그림 범위와 실제 판정 범위를 구별한다. 일반 강철이의 불 면역과 달리 이 보스는 실제 불 흡수 회복 반응을 보여 준다.

공격 프레임의 “준비 → 타격/발사 → 회수”는 자세 제작 순서다. 현재 즉시 판정을 유지하는 첫 구현에서는 실제 판정 순간에 타격/발사 자세를 맞추고 앞 준비 프레임은 생략하거나 별도 예고에 사용한다. 피해를 주기 위해 애니메이션 종료를 기다리지 않는다.

## 제작용 설명문

> 한국 민담을 재해석한 요괴 마을 축제 게임용 2D 캐릭터. 둥근 카툰 형태, 굵고 일정한 먹색 외곽선, 단순한 면 채색과 약한 한지 느낌. 몸을 둥글게 말고 지상에 웅크린 거대한 쇠비늘 이무기, 큰 둥근 머리와 짧은 뿔 두 개, 황토색 배판, 보라 등 능선, 두꺼운 꼬리와 자신만만한 표정. 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면, 투명 배경, 캐릭터 전체와 소품이 캔버스 안에 들어온다. 한 장에는 한 포즈만 그린다. 프레임 변형 시 확정된 기준 원화의 체형·얼굴·색·소품을 유지한다.

피할 요소: 하늘을 나는 긴 용, 무한히 긴 수평 몸, 불 공격을 받으면 항상 아파하는 포즈. 공통 제외 사항은 사실적인 공포·유혈, 화면을 가리는 광원, 배경 풍경, 글자·워터마크, 다른 캐릭터 혼입이다.

## 검수 기준

- [ ] 콘셉트·실루엣·기본 팔레트가 확정된 기준 원화와 일치한다.
- [ ] 작은 게임 표시 크기에서 위의 식별 요소가 남는다.
- [ ] 프레임 간 크기·기준점·소품 개수와 위치가 의도 없이 달라지지 않는다.
- [ ] 좌우 반전해도 문양·소품·실루엣이 깨지지 않는다.
- [ ] 알파 배경에 흰 테두리나 잘린 무기·꼬리·날개가 없다.
- [ ] 파일명·해상도·색상 프로필과 출처·사용 조건 기록을 확인했다.

## 기본 스킨의 동작 컷

기본 스킨 `default`는 **공통 본체 19컷 + 위 고유 동작·효과 컷 전체**를 납품한다.

| 동작 | 파일 범위 | 컷 수 |
| --- | --- | --- |
| 대기 | `idle_00.png` ~ `idle_01.png` | 2 |
| 이동·롤러·비행 | `walk_00.png` ~ `walk_03.png` | 4 |
| 기본 공격 | `attack_00.png` ~ `attack_03.png` | 4 |
| 피격 | `hit_00.png` ~ `hit_01.png` | 2 |
| 등장·부활 | `spawn_00.png` ~ `spawn_02.png` | 3 |
| 퇴장 | `death_00.png` ~ `death_03.png` | 4 |
| 공통 본체 합계 | 기본 동작 | **19** |

- 위의 「이미지 파일과 프레임 설명」 표에 적힌 컷별 자세와 제작 순서를 기본 스킨에 적용한다.
- 고유 스킬·비행·성장·착지·소환·효과도 위 파일 목록대로 준비한다. 본체 의상에 영향 없는 공용 효과는 출처를 명시해 재사용할 수 있다.
- 승인된 해당 스킨의 `idle_00.png`를 항상 참조하고, 이동·공격·피격 컷을 같은 자세의 복사본으로 채우지 않는다.
- 한 PNG에 한 포즈를 그리되 한 스킨은 여러 PNG의 묶음이다. 시트·아틀라스는 이 컷들을 정리하는 형식이다.
- 파츠 리깅은 제작 보조로 사용할 수 있다. 최종 본체 PNG는 동일 캔버스·배율·방향·피벗을 유지한다.
