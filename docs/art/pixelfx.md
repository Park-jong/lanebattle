# pixelfx 전투 이펙트

pixelfx를 제작 도구로 사용하고, 게임에서는 추출한 PNG 아틀라스만 재생한다. 전투 판정·공격 주기·피해량·전투 난수는 바꾸지 않는다.

## 적용 범위

| 상황 | 연출 |
| --- | --- |
| 일반 근접 공격 | 공격 방향에 맞춘 검격, 접촉 지점의 둔격 |
| 원거리 공격 | 군사 스킨 총구 섬광, 실제 명중 시 탄착 불꽃 |
| 마법·범위 공격 | 발사 입자, 명중 폭발; 범위 피해의 중복 폭발 제한 |
| 약점·저항·면역 | 약점은 강조, 저항·면역은 작은 방어 반응 |
| 부채 바람 | 방향성 바람 궤적 |
| 축원 | 바닥 회복 고리, 실제 회복한 대상의 입자 |
| 작두 타기 | 교차 검격, 후속 검격, 바닥 충격파 |
| 빙의 스킬 | 유닛 태그에 따른 공격 색·형태; 소환·버프 기술은 별도 지원 연출 |
| 빙의 상태 | 시작 입자와 약한 발밑 룬 |
| 보스 | 등장·착지·타격 충격파와 사망 폭발 |
| 화상·기절·버프 | 대상에 따라 이동하는 지속 효과. 기절 > 화상 > 버프 순으로 하나만 표시 |

기존 체력바·상태 아이콘·공격 범위 도형은 유지한다. 범위 도형의 밝기는 낮추고, 기존 캐릭터 아틀라스의 `fx_*` 스킬 이미지는 중복 재생하지 않는다.

## 제작 및 재생

- 원본: <https://github.com/patch-gg/pixelfx>
- 고정 커밋: `a84159688af3ca37a4be05a0d422b94451b2e24e`
- 고정 시드: `19`
- 기본·군사 스킨별 14개 클립. 색상과 가산광을 별도 프레임으로 추출한다.
- 스킨별 공유 아틀라스 하나, 2048×2048 RGBA. PNG는 스킨별 약 1.64 MiB, 디코딩된 텍스처는 16 MiB이다.
- 최초에는 선택한 스킨만 읽는다. 타이틀에서 다른 스킨으로 바꾸면 다음 전투 로딩에서 해당 아틀라스를 읽으며, 이전 스킨은 Phaser 캐시에 남을 수 있다.
- 원본 애니메이션의 준비 구간과 긴 잔향을 잘라 실제 게임 타격에 맞춘다. 프레임별 투명 여백을 줄여도 공통 캔버스와 접촉 기준점을 보존한다.
- 바닥 효과와 공중 효과는 별도 깊이를 사용한다. 빛은 `ADD`로 합성하며 일반 색상 프레임은 정상 합성한다.

Node와 Git이 있는 환경에서 재생성:

```powershell
node scripts/build-pixelfx.mjs
```

처음에는 `output/pixelfx-source`에 원본을 받아 고정 커밋을 체크아웃한다. 다른 체크아웃을 사용하려면 경로를 첫 인수로 전달한다. 커밋이 다르거나 원본 `src`/`tools`에 수정이 있으면 생성을 중단한다. 추가 npm 의존성은 없다.

레시피·색상은 `scripts/build-pixelfx.mjs`에서 수정한다. 생성 결과:

- `public/assets/effects/`: PNG, Phaser 아틀라스 JSON, 레시피가 포함된 manifest, 라이선스 고지
- `src/render/pixelfxManifest.ts`: 재생 시간·기준점·프레임 참조

생성 파일을 직접 수정하지 않는다. 라이선스는 MIT이며 `LICENSE.txt`와 `NOTICE.txt`를 에셋과 함께 배포한다. 갤러리 폰트나 기본 더미 캐릭터 이미지는 포함하지 않는다.

## 이벤트와 수명 관리

`DamageEvent`에 공격 유형·태그·공격자·명중 시점의 x·범위 반경·처치 여부를 기록한다. 투사체는 발사 시점의 섬광과 실제 명중 시점의 피격을 분리한다. 넉백 후에도 명중 x를 바꾸지 않는다. 치유는 `Body.visualHealing`의 실제 회복량만 확인하므로 회복 차단·체력 최대·작은 자연 재생에 입자가 반복되지 않는다.

`EffectRenderer`가 공격·시전·상태·출현·사망을 표시하고 `EffectPlayback`이 표시 시간과 예산을 관리한다.

- 전체 64개 효과, 일반 효과 36개, 지속 효과 16개, 일반 효과는 프레임당 12개까지.
- 영웅·보스 기술을 위한 용량을 남기며, 전체 한도에서는 낮은 우선순위의 일회성 효과를 먼저 회수한다.
- 효과 하나당 색·빛 이미지 한 쌍. 종료 시 재사용하여 생성된 이미지 쌍도 64개를 넘지 않는다.
- 화면 밖의 새로운 효과를 생략하고, 지속 효과는 대상이 죽거나 제거되거나 상태가 해제되면 정리한다.
- 일시정지·결과 화면에서는 표시 시간과 흔들림도 정지한다.
- 탭 복귀 후 따라잡는 프레임에서는 과거 효과·피해 숫자를 버리고, 마지막 공격 번호를 동기화하여 재생 폭주를 막는다.
- 씬 종료 때 표시 객체와 대상 참조를 정리한다.

## 검증

```powershell
npm test
npm run build
python scripts/verify-pixelfx.py --url http://127.0.0.1:5188
```

마지막 명령은 Python Playwright와 실행 중인 Vite 개발 서버가 필요하다. 개발 중 자동 새로고침이 측정을 방해하지 않도록 HMR을 끈 서버를 사용하는 편이 좋다. 테스트 브라우저의 진입 모듈만 교체하여 검사하므로 제품 코드에는 검사 전용 전역 객체를 추가하지 않는다.

동일 시드·18 아군·25 적·고정 전투 시간으로 두 스킨에서 효과 켬/끔을 비교한다. 평균·95백분위 프레임 처리 시간, 프레임 간격, 활성 효과 수, 이미지 수, 텍스처 메모리를 기록하고 체력·자원 결과가 동일한지 확인한다. 측정 중 준비 30프레임은 제외한다. 결과와 화면은 `output/pixelfx-verification/`에 저장한다.

`?vfx=off`는 비교 검증용으로 아틀라스 로딩과 새 효과를 끈다. 플레이어용 설정 UI에는 노출하지 않는다. 헤드리스 브라우저 측정은 해당 PC의 개발 빌드 기준이며 모바일 성능이나 GPU 전체 처리 시간을 보장하지 않는다.

추가 화면 검증은 `--smoke-only`로 별도 실행할 수 있다. 비행 대상의 상태 효과 높이, 기지 피격, 빙의 지원 기술과 좌향 공격, 보스 착지·사망, 씬 재시작 시 이미지 정리와 다른 스킨의 에셋 로딩을 확인한다.

### 2026-11-06 검증 기록

- 단위·회귀 테스트 54개 파일, 809개 테스트 통과. TypeScript 검사와 프로덕션 빌드 통과.
- 두 스킨 모두 브라우저 오류·에셋 누락 없음. 효과 켬/끔의 동일 시드 전투에서 체력·자원 결과 일치.
- 일시정지 시 효과 시간 정지, 따라잡기 시 과거 효과 제거, 비행·기지·빙의·보스·재시작·스킨 전환 검사 통과.
- 프로덕션 `dist/`를 하위 경로로 제공하여 두 스킨의 아틀라스 로딩과 스킬 입력 확인.
- PNG 재생성 전후 SHA-256 동일.

로컬 헤드리스 Chromium, 개발 빌드, 18 아군·25 적, 준비 30프레임 이후 150프레임의 단회 측정:

| 스킨 | 효과 | 평균 프레임 처리 | 95백분위 처리 | 최대 활성 효과 / 이미지 쌍 |
| --- | --- | ---: | ---: | ---: |
| 군사 | 끔 | 7.89 ms | 9.90 ms | 0 / 0 |
| 군사 | 켬 | 8.69 ms | 10.90 ms | 41 / 41 |
| 기본 | 끔 | 18.29 ms | 21.50 ms | 0 / 0 |
| 기본 | 켬 | 18.59 ms | 21.80 ms | 40 / 40 |

측정은 전투 업데이트와 렌더 명령 제출 시간을 포함한다. 환경 부하와 소프트웨어 GPU의 영향을 받으며 실제 기기의 FPS를 뜻하지 않는다. 효과를 켰을 때 선택한 스킨의 디코딩된 아틀라스 16 MiB가 추가된다. 상세 수치와 검증 화면은 `output/pixelfx-verification/report.json` 및 같은 폴더의 PNG에 있다.
