- 분류: 아군

- 기본 스킨: `default`

- 예정 이미지 경로: `public/assets/characters/ally/sumoGoblin/default/`

## 캐릭터 콘셉트

마을 씨름판에서 신나게 힘자랑하던 둥근 도깨비 장사. 일본 스모 선수가 아니라 축제 씨름꾼이라는 인상을 허리와 허벅지를 잇는 샅바로 명확히 한다.

- 전투 역할과 읽혀야 할 특징: 두꺼운 전열과 주기적인 메치기·넉백.
- 실루엣: 넓은 어깨와 둥근 배, 낮은 중심, 굵은 두 팔, 작게 솟은 두 뿔.
- 얼굴과 성격: 순박하게 웃는 넓은 입과 힘줄 때 모이는 눈썹.
- 의상·재질·소품: 청색 짧은 바지, 미색 소매 없는 적삼, 청색 허리·허벅지 샅바, 맨발. 금속 갑옷은 쓰지 않는다.
- 기본 팔레트: 청 #2F67AC / 미색 #F2E2C7 / 살구 #D6AB83 / 황토 #B98B53 / 먹 #292637.
- 소형 화면에서 남길 요소: 둥근 배·청색 샅바·맨손 두 팔

### 고유 동작·효과 파일

| 파일명 | 이미지와 사용 조건 |
| --- | --- |
| `throw_00.png / throw_01.png / throw_02.png / throw_03.png` | 본체 캔버스. 두 팔을 낮게 뻗음 → 빈 상대를 잡는 손모양 → 허리를 돌려 위앞으로 메침 → 중심 회복. 상대 몸은 그림에 포함하지 않고 세 번째 공격의 실제 능력 이벤트에 연결. |

고유 클립은 공통 `AnimationState`에 아직 등록되지 않은 확장 제안이다. 구현 때 별도 클립 매핑과 실제 능력 이벤트를 연결한다. 효과 이미지는 몸체에 합성하지 않고 별도 에셋 키로 등록한다. 오라·파동 이미지는 현재 전투의 실제 범위에 맞춰 화면에서 크기를 정한다.

## 방향·기준점·동작 주의점

씨름 샅바의 색면이 반전 후에도 허리와 허벅지를 이어야 한다. 일반 공격과 메치기를 구별하고 외형의 허리 회전이 충돌 중심을 바꾸지 않게 한다.

공격 프레임의 “준비 → 타격/발사 → 회수”는 자세 제작 순서다. 현재 즉시 판정을 유지하는 첫 구현에서는 실제 판정 순간에 타격/발사 자세를 맞추고 앞 준비 프레임은 생략하거나 별도 예고에 사용한다. 피해를 주기 위해 애니메이션 종료를 기다리지 않는다.

## 추가 스킨 콘셉트

| 스킨 ID 제안 | 이름 | 기본 외형에서 바꿀 부분 | 유지할 특징 |
| --- | --- | --- | --- |
| `champion` | 축제 장사 | 샅바에 황색 끝장식과 작은 매듭 추가, 미색 적삼을 남청색으로 변경 | 둥근 배·청색 샅바·맨손 두 팔 |
| `riverside` | 강변 씨름꾼 | 연청 바지와 갈색 허리천, 머리에 짧은 흰 수건 추가 | 둥근 배·청색 샅바·맨손 두 팔 |

추가 스킨의 파일명·클립 구성은 기본 스킨과 맞추고, 경로의 `default/`를 해당 스킨 ID로 바꾼다. 능력·속도·비행 여부·판정은 스킨 때문에 바꾸지 않는다.

## 제작용 설명문

> 한국 민담을 재해석한 요괴 마을 축제 게임용 2D 캐릭터. 둥근 카툰 형태, 굵고 일정한 먹색 외곽선, 단순한 면 채색과 약한 한지 느낌. 작은 두 뿔과 둥근 배를 가진 한국 축제 씨름꾼 도깨비, 청색 샅바와 짧은 바지, 미색 적삼, 맨손으로 넓게 선 친근한 장사. 오른쪽을 바라보는 전신 측면 또는 약한 3/4 측면, 투명 배경, 캐릭터 전체와 소품이 캔버스 안에 들어온다. 한 장에는 한 포즈만 그린다. 프레임 변형 시 확정된 기준 원화의 체형·얼굴·색·소품을 유지한다.

피할 요소: 스모 마와시, 상투를 스모 선수 형태로 강조하는 표현, 무기, 잔인한 관절 꺾기. 공통 제외 사항은 사실적인 공포·유혈, 화면을 가리는 광원, 배경 풍경, 글자·워터마크, 다른 캐릭터 혼입이다.
