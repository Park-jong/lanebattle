# 게임 스킨·캐릭터 애니메이션 구조

최종 수정: 2026-11-06

타이틀·지도·빌드 화면의 **게임 스킨** 버튼으로 `default`와 `military`를 전환한다. 선택은 `lane-defense.game-skin`에 별도로 저장하며 캠페인 기록·빌드·전투 수치는 유지한다. `?skin=military`로 새 테마를 바로 확인할 수 있다.

밀리터리는 영웅 1종·아군 10종·일반 적 10종·보스 5종, 5개 장의 전장 배경과 40개 기지 파손 상태를 사용한다. 시온은 전류 대검 v2의 74장·16클립을 적용하며 타이틀·소환 초상화·Q/W/E 아이콘과 스킬 효과도 선택한 테마를 따른다. 시작·정지·회전 클립은 표시 전용이며 이동이나 공격 판정을 지연시키지 않는다. 빙의 시에는 해당 병과의 텍스처와 스킬로 전환한다.

새 테마도 기존 비행·상성·강화 규칙을 유지한다. 종류별 외형과 PNG 제작 규격은 [캐릭터 이미지 제작 가이드](art/default/README.md)를 따른다.

## 데이터와 에셋

캐릭터는 `hero:kkomaMudang`, `ally:clubGoblin`, `enemy:eggGhost` 같은 대상 키로 구분한다. 실제 ID는 각 데이터 파일과 에셋 목록을 기준으로 한다.

| 경로 | 역할 |
| --- | --- |
| `src/data/hero.ts`, `allies.ts`, `enemies.ts`, `bosses.ts` | 캐릭터 ID와 전투 수치 |
| `public/assets/characters/manifest.json` | 대상 키·텍스처·아틀라스 경로·기준점·몸체 크기·클립 |
| `public/assets/characters/military-manifest.json` | 26종 밀리터리의 표시 크기·클립·아틀라스 |
| `public/assets/characters/runtime/military/` | 새 테마의 배포용 PNG·JSON, 시온 v2 포함 |
| `public/assets/military/` | 장별 배경·기지 파손 이미지·시온 타이틀 |
| `src/game/skin.ts` | 공통 선택·저장·URL 미리보기 |
| `public/assets/characters/runtime/` | 배포용 PNG·JSON 아틀라스 26쌍 |
| `src/scenes/BootScene.ts` | 에셋 목록과 아틀라스 로딩 |
| `src/render/art.ts` | 에셋 목록 검증·대상 조회·클립 프레임 계산 |
| `src/render/CharacterRenderer.ts` | 전투 캐릭터·투사체·효과와 UI 이미지 표시 |
| `src/render/battlefield.ts` | 캐릭터별 발 위치·깊이·비행 높이·투사체 표시 좌표 |
| `src/scenes/battlefieldDecor.ts` | 레인 지면·앞뒤 풀 가장자리·디딤돌 |
| `scripts/pack-runtime-art.py` | 보관 원본을 배포용 아틀라스로 패킹 |
| `scripts/pack-military-runtime.py` | 생성된 밀리터리 원본과 시온 패키지를 배포용으로 패킹 |

원본은 `output/art-generation/source-assets/<분류>/<종류ID>/default/`에 보관한다. `skin.json`에는 캔버스·기준점·클립 정보를 기록한다. 원본과 생성 기록은 Git과 배포에서 제외하며, 자세한 경로는 [생성 기록](art/default/GENERATED.md)을 참고한다.

## 프레임과 제작 규칙

| 동작 | 파일명 | 기본 컷 수 |
| --- | --- | --- |
| 대기 | `idle_00.png` ~ `idle_01.png` | 2 |
| 이동·비행 | `walk_00.png` ~ `walk_03.png` | 4 |
| 공격 | `attack_00.png` ~ `attack_03.png` | 4 |
| 피격 | `hit_00.png` ~ `hit_01.png` | 2 |
| 등장·부활 | `spawn_00.png` ~ `spawn_02.png` | 3 |
| 퇴장 | `death_00.png` ~ `death_03.png` | 4 |

공통 본체는 19컷이며 미리보기·아이콘·고유 동작·효과는 별도다. 아틀라스 프레임 키는 파일 확장자를 뺀 이름을 사용한다. 개별 명세는 최종 제작 기준이며 모든 고유 포즈가 게임에 연결됐다는 의미는 아니다.

- 투명 RGBA PNG를 사용하고 같은 캐릭터의 본체 캔버스·배율·기준점을 통일한다.
- 원본은 오른쪽을 바라보며 실제 방향에 따라 좌우 반전한다.
- 몸체 기준 높이에 맞춰 균일 배율로 표시한다. 무기·꼬리·소매의 투명 여백은 충돌 크기에 포함하지 않는다.
- 지면 그림자·체력바·이름·숫자·큰 오라·투사체는 본체와 분리한다.
- 공격의 준비·타격·회수 포즈는 기존 전투 판정 시점에 맞춘다. 그림 재생을 위해 피해·공격 간격·사거리·이동 속도를 바꾸지 않는다.

## 전투 표시

전투는 팔라독의 넓은 길 구도를 참고해 지면을 살짝 내려다보는 형태로 표시한다. 지형의 뒤·앞 경계와 캐릭터의 발 위치를 분리하고, 같은 길 안에서 개체마다 고정된 앞뒤 배치를 부여한다. 발 위치로 본체 겹침 순서를 정하며, 체력바·피해 숫자·그림자·투사체는 같은 좌표 변환을 사용한다. 바닥 오라·범위 효과·정예·보스 표식은 납작한 타원으로 표시한다. 앞뒤 배치는 화면 표현이며 기존 가로축 전투 판정과 수치·저장 형식을 유지한다.

`CharacterRenderer`는 전투 모델의 이동·공격·피격·생존 상태를 읽어 대기·이동·공격·피격·등장·퇴장 클립을 표시한다. 실제 공격 이벤트에 타격 포즈를 맞추며, 퇴장 중인 화면 개체는 잠시 유지한 뒤 정리한다.

영웅은 현재 시선에 맞춰 반전한다. 빙의 중에는 해당 아군의 선택한 스킨 이미지를 사용한다. 비행 높이·그슨대 성장·보스 착지·정예 배율은 전투 상태를 반영한다. 영웅 부활 시 퇴장과 피격 표시를 초기화한다.

표시 시간은 수동으로 진행하므로 일시정지와 결과 화면에서 애니메이션도 멈춘다. 피격 색상은 짧게 적용한 뒤 복구하며 영웅 스킬 포즈·효과·종류별 투사체는 실제 전투 이벤트에 연결한다.

## 이미지 누락과 검증

에셋 목록·텍스처·프레임을 사용할 수 없으면 기존 도형이나 UI 텍스트로 표시한다. 클립 이름을 찾을 수 없을 때는 대기 클립을 조회한다. 이미지 로딩 실패가 전투 판정이나 진행 저장을 막지 않도록 한다.

기본 이미지 검수에서는 좌우 방향·발 위치·이동 연결·공격 시점·피격·퇴장·부활·비행·성장·일시정지를 확인한다. 작은 표시 크기에서 캐릭터 식별이 가능하고, 밝고 어두운 배경에서 알파 테두리와 잘린 소품이 없는지 확인한다.

기술 변경 시 `npm test`와 `npm run build`로 기존 동작과 타입·빌드를 검증한다. 프레임 내용과 생성 이미지에 남은 검수 사항은 [아트 생성 기록](art/default/GENERATED.md)을 따른다.
