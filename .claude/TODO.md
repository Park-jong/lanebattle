# 꼬마 무당 대소동 (가제) 작업 목록

횡스크롤 라인 디펜스 웹 게임. 설계 문서는 `docs/design.md`.
기술 스택: Phaser 4 + TypeScript + Vite, 테스트 vitest. 5737 포트는 다른 프로젝트가 쓰므로 사용하지 않는다.

진행 원칙:
- 사용자가 시작하라고 한 항목만 진행하고, 항목이 끝나면 멈추고 보고한다.

- 커밋·push는 요청 전에는 하지 않는다.

## 3단계 A에서 코드가 정한 해석
- 화상: 공격력 버프·공격 유형 배율·최소 피해 1 제외, 불 태그 배율과 받는 피해 증감만 적용. 재적용 시 초당 피해는 큰 쪽 유지
- 방어 파괴의 받는 피해 증가는 감소 상한 70%와 별개로 합산: 1 + 증가 − min(감소, 0.7)
- 오라는 매 틱 다시 적용, 같은 종류도 합산, 영웅도 아군 오라를 받음. 투사체 공격력 버프는 발사 시점 값
- 마법 범위는 `|dx| − 대상 반지름 ≤ 반경`, 기지는 주 대상일 때만 맞음. 기절 중에도 공격 쿨타임은 줄어듦

## 3단계 B에서 코드가 정한 해석
- 해태: 소환 직후 바로 사용 가능, 이후 8초 쿨타임. "가장 앞" = 사거리 안 x가 가장 큰 적, 비행 제외, 기절 중 미사용
- 영등 빗나감: 투사체 도착 시점에 1회 판정, 영등·대상이 해제 중이면 무효, 영웅 포함·서낭당 제외, 여러 영등은 최고 확률 하나만
- 저승사자: 범위에 대상이 없어도 6초마다 발동, 기절 중엔 대기
- 그슨대: 몸집 ×1.08/단계(반지름도), 성장은 기절과 무관
- 신수의 축복: 최대 체력만 늘리고 현재 체력은 올리지 않음
- 백귀야행·수호의 맹세 Ⅱ: 영웅 포함 (수호의 맹세 Ⅱ는 신수 본인도 회복)
- 불바람 확산 값 = 맞은 적의 가장 센 화상(불씨 Ⅰ 반영), 강철이에게는 확산 안 됨
- 공격자 쪽 배율(외다리, 까치, 도깨비불, 두억시니 서낭당 ×2)은 모두 곱셈, `strike`에서 한곳에 적용
- 연계 확인용: URL `?synergy=all` 또는 `?synergy=id1,id2`

## 4단계에서 코드가 정한 해석
- 스킬 피해는 고정 수치: 공격력 버프·연계 효과 미적용, `strike`를 거치지 않고 `calcDamage` 직접 호출 (연계를 스킬에 붙일지는 8단계에서 결정)
- 스킬 공격 정보: 유형 마법, 태그 hero(부채 바람은 wind 추가). 비행 적도 맞고 기지는 무피해, 스킬 적중은 신력 +2 없음, 처치 시 부적 보상은 지급
- facing = 마지막 이동 방향, 시작·부활 시 오른쪽, 기절 중 고정
- 태그 면역으로 피해 0이면 넉백·기절도 미적용
- 범위 판정은 `|dx| − 대상 반지름 ≤ 반경`

## 1·2단계에서 코드가 정한 해석 (설계 확인 필요 시 참고)
- 유닛끼리는 서로 막지 않고 겹쳐 지나감
- 사거리 = 중심 거리 − 대상 반지름, 가장 가까운 대상 선택. 영웅도 원귀의 성을 때릴 수 있고 기지 타격에도 신력 +2
- 이전 장의 적은 다음 장 1번째 스테이지부터 등장
- 소환 위치 아군 x=130, 적 성 앞 40px, 투사체 속도 420 (`data/combat.ts`)
- 부활 시간은 사망 시점의 위협 단계로 고정, 부활 위치 x=130
- 소환 실패 시 쿨타임 소모 없음. 일시정지 중 입력 무시, 창 포커스 잃어도 자동 일시정지 없음
- 스테이지는 URL `?stage=N`(0~24)으로 바꿀 수 있음
